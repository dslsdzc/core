# 概念:程序 = 一张图

> 定位:受众 = 开发者;状态 = active。

## 图是什么

Core 编译后的程序不是"指令序列",而是一张**数据流图**:节点是操作(取址、解引用、算术、调用),边是值的流动。控制流不是另加的机制,而是图的结构:

| 代码 | 图上 |
|---|---|
| 顺序语句 | 值沿依赖链流动(不依赖的互不阻塞) |
| if/else | 两条候选路径,条件选择一条 |
| loop/for | 一条环:值绕环流动,每圈=一次迭代 |
| go | 运行时从当前节点长出并行子图 |

## 对写代码意味着什么

**不需要"模式"概念。** 没有 debug/release/并发模式切换——代码写了什么,图就反映什么。学习、单步、并发是同一张图的不同看法:

- 单步调试 = 沿图走值
- 并发 = 图上有并行的子图
- 惰性 = 没被需要的路径不求值

## 表达力上限

图的表达不限于经典机器能执行的顺序:非因果/概率/模糊语义在图上都有标注位置(设计态,超出本文范围;术语见 `../../glossary.md`)。
