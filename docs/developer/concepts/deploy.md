# 概念:部署配置与代码分离

> 定位:受众 = 开发者;状态 = active(部分落地,见注)。

## 一条原则

**代码描述计算;物理世界不进代码。**

内存能否动态分配、有几个核、有没有 OS——这些不属于程序语义,属于部署目标。Core 用部署配置(TOML)声明它们:

```toml
[deploy.mcu]
target = "cortex-m4"
allocation = "static"          # 禁止动态分配:所有大小必须编译期可定

[deploy.server]
target = "x86-64-linux"
allocation = "dynamic"
```

同一份代码:

- 教学环境 → 解释执行,可单步
- 桌面 → 原生二进制(ELF)
- 裸机 → 静态分配,零运行时
- (设计态)集群 → 图跨机部署

代码不改。语义不变。部署配置不同。

## 平台接口同理

I/O、时钟、随机、哈希在语言层是**语义接口**——程序的 I/O 语义是"流变换"(输入流 → 输出流),系统调用是后端按部署目标实现的物理细节。验证意义上 I/O 是一等公民,不是黑洞。
