# 概念：部署配置与代码分离

> 定位：受众 = 开发者；状态 = active（部分实现，见注）。

## 代码与部署目标分离

代码只描述计算，物理世界的内容不进代码。

内存能否动态分配、有几个核、有没有操作系统，这些不属于程序语义，属于部署目标。Core 用部署配置（TOML）声明它们：

```toml
[deploy.mcu]
target = "cortex-m4"
allocation = "static"          # 禁止动态分配：所有大小必须能在编译期确定

[deploy.server]
target = "x86-64-linux"
allocation = "dynamic"
```

同一份代码可以用于不同环境：

- 教学环境：解释执行，可单步
- 桌面：原生二进制（ELF）
- 裸机：静态分配，无运行时
- （设计态）集群：图跨机部署

代码不变，语义不变，只有部署配置不同。

## 平台接口遵循同一原则

I/O、时钟、随机和哈希在语言层是语义接口。程序的 I/O 语义是流变换，即从输入流得到输出流；系统调用是后端按部署目标实现的物理细节。在验证意义上，I/O 与语言中的其他构造同等重要，不是无法验证的部分。
