### T3 前置探针

T3 前置探针为零源码改动，日期 2026-09-16。

U10 结案：`f := @addr(main); return f();` 的 `func_node` 为 `EXPR_IDENT`，但解析不到函数。结果为 `check` rc=1，`error[N06]: Undefined function 'f'`，`build` rc=1 且无产物。前端硬错拦停，N06 是 fail-closed 门，该形态不可达。表 ④ 末行由“登记”改为“不可达”，附探针。U10 解除。

U11 实测可达且错值，根因比“3 处候选写点”更宽。按硬条件 3 停下上报，不接线。探针 u11 为 `d : dex, apx = 7.0; x : dex? = d;`，再 `match x { Some(v) => @raw_int(v)/1e6 … }`，ELF 15，interp 15，期望 7，判定 RED，可达且双路径同错。u11b 为精确形对照，`d : dex = 7.0;`，ELF 7，interp 7，期望 7，绿，对照成立。

根因由读码和实测一致得到。`dex_store_adjust` 的触发门是 `declared_ti == TI_DEX`，位置为 `ir_gen.cr:2389-2393` 和 `:2423-2424`。`dex?` 的 `declared_ti` 是 `TYP_OPTIONAL` 类型索引，不等于 `TI_DEX=1`。因此可选 dex 的 LET 和赋值写点整段跳过转换。随后装箱路径 `emit_box_some` 的 `:463` 把 bits 原样塞进载荷槽，读回按 scaled 解释，所以 `4619567317775286272 / 10⁶` 的低 8 位为 15，与 T1 是同一条数值自洽链。

这不是“3 处候选写点是否接线”的问题，而是一条独立的正交轴：可选 dex 整族，是形式转换面和可选表示（`rep`）面的交集。其检查体系须同时覆盖“裸与装箱”和“bits 与 scaled”四态。

三个选项供维护者裁：

- (a) 本次并入。把触发门从 `declared_ti == TI_DEX` 升级为 dex-ness 判定，内层覆盖 `TYP_OPTIONAL`。改动面为一个判定函数加 3 处候选接线。该选项直接碰 `rep` 不变量交界，四态检查体系须同阶段建立。
- (b) 单列，本计划推荐。本次只做非可选的 8 个写点和环覆盖面重写。`dex?` 整族另立条目，附本实测证据、根因和 `file:line`。零影响检查（canary 和 `.ccr` 四条 IDENTICAL）不受影响。`dex?` 现状本就是错的，不是本次引入，无阻塞关系。
- (c) 只接线不深挖。4 处写点过漏斗，但不建 `dex?` 检查体系。不推荐，因为碰了交界却不给检查。

推荐 (b) 有三条理由：① `dex?` 四态检查体系是独立阶段体量；② 本次零影响检查建立在非可选程序逐字节不变上，并入会扩大 T3 影响范围；③ 硬条件 3 的本意是碰交界要谨慎，实测把它从 3 处写点升级为一整族，更该单列。

若裁 (b)，本次对 `dex?` 的处置为零影响标记值。把现状值 u11 红 15/15 固定进 T5 套件，明确标注“该值不是期望语义，只是本次的零影响标记值，修复归 U11 单列条目”。作用是若 T3 的漏斗意外改动了 `dex?` 行为，当场变红，防止顺手改坏。这与 TODO #2026-09-16-14 把 B04 现状固化成检查同体例。U11 因此不解除，转为“已实测、待裁、未修”，并附完整证据：探针源、双路径读数、根因坐标、数值自洽链。

### T1 数值自洽校验

`d` 的 bits(7.0) 约为 `4619567317775286272`，来自 lexer 文档化的约 2ulp 截断。读点定型为 `TI_INT`，因此 `@raw_int` 原样返回该整数。除以 1000000 后，return 的低 8 位为 `4619567317775 mod 256 = 15`。b1b、b3a、b3b、b4a、b4b、b4c、b5、b6、b13 的 interp 实测均为 15，与该值完全一致。因此这些探针走的正是“bits 原样入槽，读点定型 `TI_INT`，`@raw_int` 无转换”这条链，即 L2 至 L8 无漏斗加 L9 读丢型的合成像。该自洽校验是“读数不是巧合”的正据。
