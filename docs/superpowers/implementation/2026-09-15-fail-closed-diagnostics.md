`--diag-gate-report` 的报告面只覆盖前端类型面检查，即 `g_diag_count > 0` 块。解析阶段检查（`main.cr:134/:135`，例如 P21）和安全检查面检查（`:594-603`，例如 TU03）的诊断不出现在报告行。实测 TU03 档在开启和关闭两态下为 0 行差异。因此 T3 重放对表时，“T1 有而重放无”的 2 行（`at_test_mini4/6`）由此约定解释。

- 裁-FC-1 采用 (C) 终局，同机制加 scope 字段。check 基线不换代。(B) 不是活选项。
- 裁-FC-2 采用码级表加位点作证据，实现方式写在源码内。
- 裁-FC-3 销项。保持 `ptr_arith` 实现方式，B04 带退出条件豁免。数据自解：B04 不豁免则 `test_ccr_types` 必红。

- 裁-FC-5 采用 (b) 和 (c) 的最强形式。
- 裁-FC-6 零产物只删本次写下者，报告写明边界。
