# 实施记录

> 定位：受众 = 维护者与实施者；状态 = active。

本目录存放计划的实施记录。计划本身放在 `docs/superpowers/plans/`。

划分方式：

- 计划文档保留目标、背景、现状调查、设计决定、任务步骤、验收条件、约束、风险和待定问题。
- 实施记录存放实际执行的步骤、实测结果、命令输出、提交号、偏差、完成状态和事后说明。
- 一份计划对应一份同名实施记录。计划开头链接到实施记录，实施记录开头链接回计划。
- 实施记录沿用原计划的章节编号，因此计划文档可能出现编号跳号。这是为了让“见第 X 节”的引用仍能对应。
- 计划没有进入实施时，不建立实施记录。
- 文档中的事实、数字、路径、`file:line`、提交号和链接目标在移动时保持不变。
