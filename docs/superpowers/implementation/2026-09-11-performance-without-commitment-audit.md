## 0. 范围与决定

### 0.0 论题：Performance without implementation commitment

现状（各语言的常见问题）：为了性能，程序员不断把机器知识写回源码，SIMD intrinsic、CUDA / NPU 各一套方言、硬件换代重写内核。Core 的立场：

> 程序意义里不含机器形状（承既有定案：宽度移出语言 / 地址 = 映射 / 表示层归处 = 映射参数）。因此性能决策 = 映射实例的选择，不是程序的一部分。

关键同构（本文的论题展开）：单 CPU 上的 SIMD / cache / NUMA / inlining / layout / parallelization 与异构 placement（GPU / NPU / 加速器）是同一个问题，在「图 + 目标描述」上选择事件组合与资源绑定。差别只在目标描述的表内容（HIT 运行条目 / hw-map 设备表）：机制同一，无第二条性能路线。禁止为 SIMD / CUDA / NPU 各开特判通道（与 1.2.2 节「禁止内建特判」同构）。

### 0.1 本文的决策面

- 决策对象：从格到编码映射的选择/放置/调度（内联、放置、并行分派、事件选择、布局）。
- 不修改：值流、state edges、region 语义（图本体），承「执行/副作用/内存的命令式下限不改变」（契约 1.2.5 节）；先例 = 寄存器分配 = 缓存语义映射实例（已定稿）。
- 检查基调：合法性可判定、收益启发式；任何变换的缺失都可接受（直接形态恒合法）。

## 1. 标注面

总原则：

1. 自动推导优先，能从图结构/显式边推导的一律不要求用户写（依赖、纯度/效应、使用计数、索引来源）。
2. 显式仅在意图不可推导处，精度（apx）/ 资源约束（意图）类；显式面恒为可选提示或策略数据：缺失不改变合法性，被忽略只改变性能（= 无承诺的机制保证）。

## 2. 优化器与决策

### 2.1 流程（六段）

```
1 事实推导（图 pass）      依赖闭包 / 效应集 / 使用计数 / 索引来源 / 生命周期
2 候选生成（可判定性门）    每条变换附合法性前提清单；前提不可判 到 候选缺席（保守）
3 成本评分（成本模型接口，输入为表成本事实和资源约束）
4 选择（策略数据：目标描述 + 阈值/约束）
5 记录（决策记录见 5 节）
6 发射（实例层：编码 / 布局 / 调度）
```

各段失效语义（全部有向退化，无无提示改义）：1 unknown 到按最保守事实（有依赖 / 有效应 / 索引未知）；2 前提不成立或不可判到 不选该变换；3 成本缺失/未知到 退化用默认形态；4 无候选或超约束到 直接形态；56 与语义无关（记录缺失不影响判定）。

### 2.2 可判定性与启发式的分界（本文的关键墙）

| 层 | 检查 | 性质 | 失效后果 |
|---|---|---|---|
| 合法性 soundness | 图前提：无依赖路径（并行）/ 无效应（memo，按 1 节单一依据：含任何效应 opcode 或未证纯/不可解析调用即视为有效应；2026-09-11 修复后可使用真纯度，时点见 2.2 节 C2）/ 索引仿射可证（向量化）/ 无递归 + 无逃逸（内联）/ 单使用位置（惰性下沉）/ 汇合点确定性（并行类变换：S-E 1.5 节决策序，可判定性 + 确定性判定两个条件，决定 D21/B 线 I2） | 可判定（保守：unknown = 否） | 该变换不选，语义不变 |
| 收益 profitability | 成本估计 + 阈值（调度开销 vs 收益；代码膨胀 vs 调用开销） | 启发式（可错，待确定） | 只影响性能，绝不影响语义 |

- 关键属性（已定 L3）：任何变换的缺失都可接受，直接形态恒合法。这与安全线的「义务不会无提示消失」正交：那是义务，这是可选性。
- 要求：候选门的判定输出必须引用图事实（哪条边 / 哪个效应 / 哪个索引来源），为 5 节记录与 S-D 解释提供证据面。
- 效应门规则（B 线 C2，2026-09-11 修复后修订）：纯度事实已可靠（`compute_all_purity`，`762bd429`+`c9099d73`；见 1 节回填记录），因此首切片与实施批可以 `fi_ispure` 旗标 / state 链边为真值，"无效应"结论的检查 = 「无 store 家族 ∧ 无效应 opcode（1 节单一依据清单）∧ 调用全被真纯度证纯（不可解析调用恒计效应）」。时点约束（硬性）：该字段在 IR 生成期仍是 checker 的冻结乐观默认值（`ir_gen.cr:1590` 的 lazy 判定有意不解冻），因此使用必须发生在 `compute_all_purity` 写回之后（IR 生成 + `df_state_finalize`）；生成期使用 = 读到恒 1（即修复前的老行为）。

### 2.3 成本模型接口（接 hw-map）

设计已定 = 接口形态；待确定 = 精度与量纲。

- 输入 1（表成本事实）：事件条目 + 运行时条目（调用/存储/系统边界/宽度形状，HIT 3.3 节）+ hw-map 设备层事实。事实随表走到 换表换输入。
- 输入 2（形状上下文）：宽度 / 布局 / 嵌套 / 访问模式（来自 1 节事实）。
- 输入 3（约束）：资源约束（1 节），约束由 S-D 判定/证明为上界；本模型只做满足检查。
- 输出：相对成本估计 + 必填四项：`band`（不确定带，单点数字给人"精确"错觉 = 过度承诺）/ `model_id` / `model_ver` / `assumptions[]`（接口形态以 S-D 1.7.3 节的 `cost_model_query` 为准，本文不另立）；不输出任何语义事实。注（B 线 N5）：早稿并列的「约束满足判定」不在 S-D 1.7.3 节的返回面，约束满足检查是使用侧（优化器 4 选择段）的内部动作，其结论经决策记录的 `choice` / `alternatives` / `evidence` 呈现（5 节 R1），不属成本模型返回字段；本文不要求模型返回它。

契约六条：

1. 事实/模型分离：成本事实 = 表条目字段（材料属性）；「如何用成本事实决策」= 编译器侧可替换件（HIT 3.3 节「表只描述材料，不描述放置策略」保持）。
2. 缺失 = 保守退化，不作推断。
3. 相对量纲，不承诺绝对值、不承诺最优（7 节）。
4. 模型可替换：多目标/多范式各一套实例，机制不换。
5. 模型非证明（硬性，承契约 1.4 节；B 线 C1/决定 D24）：估计值不得呈现为 WCET 证明 / 时间上界，`MODELED` 渲染必须明标「模型估计，非证明」（S-D 1.7.2 节）；`band` 必填；模型不可用（未实现 / 预算耗尽），因此使用方按 `UNKNOWN`，不得以"经验常数"回退为 `MODELED`（S-D 1.7.3 节禁令）。
6. 与上界不混报（B 线 C1/决定 D24）：成本估计只进 `MODELED` 层；与 S-D 结构层 `PROVED` 数字（分配次数/进行中任务数/通信量）不得合并/覆盖/相减，三层不可混报（S-D 2.1 节）；同层内冲突取保守（更宽界）。`phase_ver` 含 `model_ver`，因此模型换代，因此相关记录与报告自动失效（S-D 3.3 节）。

### 2.4 与义务/安全性的交互（硬规则，承 L4）

- 变换不得消除 enforcement（运行时检查/强制通道），除非按四档义务判定提升为 prove 档（消除流程 = 义务判定通道，非成本模型）。
- volatile / MMIO：不消除、不重排、不合并（hw-map 2 节既有规则在本文重申为约束）。
- 效应序：state edges 是顺序唯一来源；重排/并行只在无依赖证明下允许，这正是自动并发「非依赖猜测」的机制根据（TODO auto-parallel 条：区别于四十年失败史的根源）。
- 物理不能推出语义：沿用 S-E 2.2 节的三个检查面（B 线 I2/决定 D21）：本文任何移动/重排/合并（自动并发 lowering、CSE、LICM、惰性下沉等）须同时满足，1 发射层：lowering 不得引入序依赖（含把非结合算子降低为序敏感实现）；2 调度器：就绪队列/线程 id 不得成为 tie-break 并影响 `obs`；3 编译器 pass：不得改变 merge 点的输入到达集合或引入序依赖，CSE 合并两个 `race` 点 = 改变 `Obs(M)` 基数，因此禁止（除非按 S-E 1.4 节(i) 已证观测等价）。可陈述不变量：每个变换都保 `obs`（S-E 2.2 节）。
- 自动并发的两个条件（承 S-E L7；互引 `2026-09-11-merge-semantics-design.md` 4.3 节）：依赖门（可判定性）与汇合点确定性门（S-E 1.5 节决策序）两道都过才移动；只过依赖门即分派 = 该次分派非法。移动集合含 `merge_ordered` 保序并行（S-E Q5 已确定：纳入），其 lowering 须证明「state 边序 = 观测序」。

## 3. 目标描述

### 3.1 形态（数据，非代码）

编译器持有通用机制 + 实例参数（x86 实例 spec 0 节同构原则）：

```
目标描述 = 三轴组合（架构 × 格式 × OS）
         + 表：语义表（事件签名）+ 投影条目（经典编码 / 通道映射 / 连续类演化描述…）
              + 运行时条目（call/ret 机制、地址语义、系统边界、宽度/形状）
         + 设备/投影表（hw-map：device id 映射到物理基址）
         + 架构特化参数（machine / reloc 等，波 2 机制）
         + 成本事实（2.3 节 输入1，实现方式 = `.ccr`新段，随 R2 P4 同波：段 tag 空间可扩展（`2026-09-09-lattice-ir-v7-format.md:44`的`7+`未固定分配，既有注明用途 = 驱逐标注段 / 证书段，新段名随实施批定）；策略随产物分发，决定 D4 裁决。B 线 N8）
```

- 表是唯一允许出现机器名词的地方（L1 的实现方式）；图的语义完整性不依赖任何表（换表可重建语义）。
- 表的三种范式形态（编码 / 接通 / 演化）与「无实现：条目缺失到 编译期拒绝或 unsafe 外部入口」承 HIT 3.2 节，不重新定义。

### 3.2 检查：换目标不改语义（可迁移检查）

1. 观测等价：同程序 + 不同目标描述到 值 / 效应序 / rc / 输出一致（检查形式：双目标运行比对，精确 rc；外部效应按登记比对）。
2. 源码零改动：换目标不得要求改源码，这是「无实现承诺」的操作性检查（要改源码 = 机器形状漏进程序意义，违反 L1）。
3. 义务判定不变：换目标后 S-A 的义务档位/判定结果不变（安全不因目标而弱化）。
4. 决策自由：映射选择（内联 / 向量化 / 并行 / 布局 / placement）可完全不同，检查只约束语义，不约束决策。
5. 可移植子集：只用最小核事件的程序 = 可在任意表下运行（HIT 4 节既有规则，本文沿用为可移植检查的基线）。

反向（泄漏检测，用 lattice-encoding-boundary G3「可换性」检查）：a) 换目标需改源码；b) 决策结果被写回图/源码语义；c) 源/图中出现机器名词，三项任一 = 违反，登记为「泄漏待归一」。

## 7. 不承诺

承共享契约 1.3 节（逐字引用）：

> - 错误 specification：Core 只能证明"程序忠实实现了规则"，不能证明规则本身正确。
> - 恶意/失陷外部实体：供应链、编译机、密钥、硬件后门，用可复现构建/签名/provenance/最小权限缩小，不能用语言语义证明。
> - 需求本身允许危险行为：shell/browser/kernel/JIT 必须执行外来代码，目标不是禁止能力，而是证明隔离边界。

本族逐条实现位置：

- 错误 specification：优化器不修复错误的算法，「忠实实现规则」包含「忠实地慢」；本文承诺的是「不把机器写回程序」，不是「程序一定快」。
- 恶意/失陷外部实体：表与剖析数据是外部输入，恶意/损坏的目标描述或 PGO 数据可改变性能甚至改变所选映射；用 provenance / 签名 / 最小权限缩小，语言语义不证明；信任归治理层（与 M1 定论一致）。
- 需求本身允许危险行为：unsafe / extern 边界内手写机器相关代码（HIT extern 事件 / unsafe 外部入口）不被禁止，本文不管理它，只保证它不污染其它部分的程序意义（机器相关区域须显式留在边界内）。

本文自有不承诺（成本模型 / 启发式）：

- 模型非证明（承契约 1.4 节，硬性），成本估计是启发式，不得呈现为 WCET 证明 / 时间上界；`MODELED` 数字必带 `band` + `model_id`/`model_ver` + `assumptions[]`（2.3 节契约第 5 条），且与 `PROVED` 层不混报（第 6 条）；模型不可用，因此 `UNKNOWN`，不得以经验常数回退。
- 成本模型不保证最优，选择 = 启发式；最优性证书 = 远期独立项，不在本文。
- 启发式可退化，退化 = 回退语义直接形态；不承诺任何程序变快，不承诺优化一定发生。
- 不承诺性能可移植，语义可移植（3.2 节）是承诺；不同目标的性能表现可完全不同（决策自由是其推论）。
- 不承诺自动推断意图，精度（apx）等意图类标注永远显式；无法推断的局部性事实不作推断。
