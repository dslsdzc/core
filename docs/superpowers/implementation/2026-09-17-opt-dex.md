### G4 前置盘点

枚举约定是：全仓 `irv_type(` 消费点，命令为 `grep -rn 'irv_type' src/`，加三处点名文件逐门实读，加两个「零判定点」负证。

| # | 判定点（`file:line`） | 判定式 | 现（`dex?` 槽为 `TI_INT`） | 改后（`TI_DEX_S`） | 改判？ | 性质 |
|---|---|---|---|---|---|---|
| 1 | `callseq.cr:70`，寄存器分派 | `== TI_DEX`，所以走 XMM | 否，所以走 GP | 否，所以走 GP | 否 | 槽面不变。真改判在调用点实参 var。W4 转换后 bits var 由 `TI_DEX` 改为 `TI_DEX_S`，所以 XMM 改为 GP，这正是修复目标本身。 |
| 2 | `callseq.cr:99`、`101`、`127`，落栈判定和压栈 | 同上 | GP 类 | GP 类 | 否，同上，实参侧改判就是修复 | ABI 一致性由此闭合。 |
| 3 | `callseq.cr:167`、`179`，返回值通道 | 同上 | — | — | 否 | 返回值形式由 ir_gen 侧的转换决定，即 W5。 |
| 4 | `frame.cr:118`、`125`，形参保存 | `pty == TI_DEX`，所以用 `movsd` 存 XMM | 否，所以用 GP 存 | 否，所以用 GP 存 | 否 | 必须与第 1 条一致。修后调用点也发 GP，所以一致。 |

| 16 | `monomorph.cr` | 克隆形参节点：`alloc_node(EXPR_PARAM, …, orig_type_val, new_type_node, …)`，见 `ir_gen.cr:3620` | `type_val` 同源 0 | 同源 | 否，而且被覆盖 | 克隆保留 `data = new_type_node`，所以 W3 的节点级检查在实例体内同样成立。 |

盘点结论是干净，放行 T2 的条件满足。

1. ABI 面（`callseq` 和 `frame`）全部以 `== TI_DEX` 为门，所以槽型改判不移动任何一个门的取值。真正改变发射的是实参 var 的形式，即 W4，这是修复意图。调用点和被调方两侧同时移动，方向一致，都是 GP 到 GP。
2. 唯一的「真改判对」是 tag 闭包（第 6 条）和 prologue tag 卫生（第 5 条）。两者判定式相同，都是 `== TI_INT`，所以成对移动，自洽，没有「半边清、半边不清」的残留窗。
3. `regalloc`（第 7 条）和 `dex_scale_int`（第 14 条）的改判分别属于性能面和修复方向，都不是回归。
4. `ptr_analysis` 和 `interp` 没有判定点，负证已经给出。
5. 语料外可执行影响面为无。全仓可执行 `dex?` 语料实核只有 `tests/selfhost/test_apx_conversion.py` 一处。`tests/suite/` 为 0，`tests/probes/` 为 0，`src/` 为 0。`src/ci/run.sh` 的命中是注释。因此影响面闭合在该档，G9 的同步更新面也在这里。

### T2 步骤 3：R1 写点门和槽型随声明

改动文件是 `src/compiler/ir_gen.cr`。

| # | 位置 | 改法 |
|---|---|---|
| R1-a | 新 helper，位于 `dex_slot_norm` 之后 | `dex_opt_type_node(tn)` 做节点级零 alloc，条件是 `EXPR_OPTIONAL` 且内层 `ast_kind==0 && ast_type_val==TY_DEX` |
| R1-b | LET 的 `target_ti` 分支 | `else if dex_opt != 0 { target_ti = TI_DEX_S; irv_set_type(var, TI_DEX_S); }`，槽型由声明给定 |
| R1-c | LET 初值分支 | `else if dex_opt != 0 { val_var = dex_slot_norm(val_var); }`，bits 改为 scaled |
| R1-d | LET 值型采纳 | 增加 `&& dex_opt == 0` 守卫，否则 `Some(...)` 的箱对象型会覆盖声明型 |
| R1-e | `reg_one_global` 门 | `else if dex_opt_type_node(ltn) != 0 { gtype = TI_DEX_S; }`。`is_dex_global` 不置 1，其唯一消费者 `:3320` 只服务 apx 位模式全局 |

设计要点是：不需要逐点补接线。赋值、指针写、聚合写、全局赋值全部是「目标槽型驱动」，`dex_store_adjust` 按 `irv_type(target)` 分派。所以槽型一改，这些路径自动获得转换。R1 只把「形式决定权」从「值型」搬回「声明型」。第 3 节 W1、W2、W6 的本质就是这一行。
