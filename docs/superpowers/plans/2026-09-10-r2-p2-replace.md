**Goal:** 把 `type_equal` 的判定从「结构判等」替换为「P0 引擎语义判定」，并按 P1 findings 的两个前置（F1 同名 named 表格去重、F2 数组长度转长度约束）保证替换**不留静默缺口**。

**Architecture:** 三步：① **F1**（用户裁决 = 类型表建表去重）：`TYP_NAMED` 同名归一行（唯一分配点 `alloc_type` 加名字去重侧表），消除 P1 观察到的 9 条 unknown 根因；② **F2**（用户裁决 = 落常量档长度约束）：`[T;N]` 的 N 从「类型身份」迁为**显式长度约束检查**（保持现状拒绝语义，不静默通过）；③ **替换**：`type_equal` 的判定改走引擎（旧实现保留为 `type_equal_legacy` 供本轮对拍复跑，P5 收尾删除）。

**Tech Stack:** Core 自举栈；P0 引擎（`type_terms.cr`/`type_engine.cr`）；P1 桥接与影子通道（`ty_shadow.cr`：`sh_term_of_ti` / `--type-shadow` / 分类计数）；检查器 `checker.cr`。

**Spec:** `docs/superpowers/specs/2026-09-10-type-interface-unification-design.md` §4 步 3（逐点替换）+ §5.1（定长退役：常量档长度约束）+ §9 P2。**P1 交接**：`docs/superpowers/specs/2026-09-10-type-shadow-findings.md`（F1 硬前置 / F2 待裁决 / 站点覆盖须同报 / unknown 政策）。

**范围**：本批 = **P2a**（F1 + F2 + `type_equal` 替换 + 对拍复跑 + 收紧清单）。**P2b**（本批不做、另立计划）：`infer_expr` 公理区 → `iface_ops` 查表（本质条目表 + 操作许可 + 字面量定型）、`res_type_node` 双份 TY→TI 映射合一。

```core
// globals.cr
g_named_dedup : string, mut;      g_named_dedup_cap : int, mut;    g_named_dedup_count : int, mut;

// checker.cr：侧表 = 开放寻址（16B/条 {name_idx, ti}），与影子侧表同式（含装填守卫 + 重建重放 + 回写前重探）
fn alloc_named_type(name_idx: int) -> int {
    slot := named_dedup_slot(name_idx);          // 含守卫/重放，见下
    if r64(g_named_dedup, slot * 16) == name_idx { return r64(g_named_dedup, slot * 16 + 8); }
    ti := alloc_type(TYP_NAMED, name_idx, 0);
    w64(g_named_dedup, slot * 16, name_idx);
    w64(g_named_dedup, slot * 16 + 8, ti);
    g_named_dedup_count = g_named_dedup_count + 1;
    return ti;
}

fn named_dedup_rows(name_idx: int) -> int {   // 自测用：该名字在 g_types 里的行数
    n : ., mut = 0;
    i : ., mut = 0;
    loop {
        if i >= g_type_count { break; }
        if get_type_kind(i) == TYP_NAMED && get_type_data(i) == name_idx { n = n + 1; }
        i = i + 1;
    }
    return n;
}
```
（`named_dedup_slot` = 开放寻址探测，**必须有装填因子守卫 + 重建重放 + 回写前重探**——照 `ty_shadow.cr` 的 `sh_map_*` 先例，勿重蹈 P0/P1 的表满死循环。）

```core
fn type_equal(t1: int, t2: int) -> bool {
    if t1 == t2 { return true; }                       // 同一行快路径
    a := sh_term_of_ti(t1);
    b := sh_term_of_ti(t2);
    if a < 0 || b < 0 { return type_equal_legacy(t1, t2); }   // 桥接不了 → 回落 legacy（登记）
    ty_budget_reset(200000);
    e := ty_equiv(a, b);
    ty_budget_reset(200000);
    if e == 1 { return true; }
    if e == 0 { return false; }
    // e == -1（未知）：**不静默**——回落 legacy 并计数（unknown 政策），报告里单列
    g_replace_unknown = g_replace_unknown + 1;
    return type_equal_legacy(t1, t2);
}
```
