# V2.0 IF Split Implementation Plan

> 状态：已实现（2026-10-29）。验证：test_region_plan 8/8、region_escape 64/64、byte_permission 13/13、alloc_at 11/11、pointer_safety、region_cfg 22/22、borrow 7/7、suite ALL PASS、canary 5/5。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give an `if` its own arena when every allocation directly inside it stays inside, so the arena is reset at the merge instead of waiting for the enclosing loop/function exit.

**Architecture:** Phase A generates the v1 IR and runs PointerAnalysis + RegionCheck. A plan pass inspects each SG_IF's direct allocations and marks it splittable only when no pointer escapes and no non-local exit exists. Phase B regenerates the whole IR with the plan, emitting `IR_ARENA_NEW` at the IF entry and `IR_ARENA_RESET` at the merge for marked IFs. No merge copy, no early clear, no cache plan yet.

**Tech Stack:** Core self-hosted compiler (`src/compiler`), Python regression tests.

**Spec:** `docs/superpowers/specs/2026-10-29-early-reclamation-v2-design.md` (V2.0 only)

## Global Constraints

- No split when an allocation escapes the IF, when the IF contains `return`/`break`/`continue`, or when the IF contains `unsafe`.
- No split of allocations that belong to a nested LOOP/FOR/UNSAFE arena.
- A program with no plan must produce byte-identical IR and artifacts to v1.
- `corec cir` stays v1 (it returns before the safety passes); split applies to `ccr`/`build`.
- Every positive case needs a runtime value check; every negative case needs an IR/plan check.
- If Phase A reports a diagnostic, do not run Phase B; report the v1 diagnostic.

### Task 2: Conservative IF escape analysis

**Files:**
- Modify: `src/compiler/region_plan.cr`
- Test: `tests/selfhost/test_region_plan.py`

**Interfaces:**
- Produces: `region_plan_analyze()`.

- [ ] For each `SG_IF`, reject if any node in its subtree is `IR_RETURN`, `IR_CALL`, `IR_CALL_EXTERN`, `IR_PTR_OF`, `IR_STR_OF`, `IR_SPAWN`, `IR_YIELD`, `IR_AWAIT`, or a jump whose target label is outside the IF subtree.
- [ ] Reject if any `unsafe` SG is a descendant.
- [ ] Consider only allocations whose `subgraph_containing(alloc_node)` equals the IF SG. Allocations in nested LOOP/FOR/UNSAFE or nested IF are not counted.
- [ ] For each considered allocation bit, scan all function nodes:
  - pointer use outside the IF subtree → reject;
  - `IR_STORE_PTR`/`IR_STORE_INDEX`/`IR_STORE_FIELD` storing a value containing the bit into a declaration outside the IF or a global → reject;
  - `IR_STORE` of a value containing the bit into a global or a slot declared outside the IF → reject;
  - any other destination whose declaration region is outside the IF → reject.
- [ ] If at least one allocation is considered and no rejection, mark the IF split.

### Task 3: Plan-aware IF generation and two-phase build

**Files:**
- Modify: `src/compiler/ir_gen.cr`, `src/compiler/main.cr`, `src/compiler/dataflow.cr`

**Interfaces:**
- Consumes: `region_plan_is_split(sg)`, `region_plan_has_split()`, `ir_gen_reset_state()`.

- [ ] In `EXPR_IF`, read `sg_idx := g_sg_count` before push. If split: `sg_alloc_push(SG_IF)`, create `_arena`, emit `IR_ARENA_NEW` with a placeholder size; else `sg_push(SG_IF)`.
- [ ] At merge: if split, set the `IR_ARENA_NEW` peak from the IF's allocation total, emit `IR_ARENA_RESET` via `sg_alloc_pop_split()`, and do not add the child total to the parent. Else keep the existing `sg_alloc_set`/`sg_pop`.
- [ ] Add `sg_alloc_pop_split()` in `ir_gen.cr`.
- [ ] In `main.cr`, after Phase A `ptr_analysis_all` + `region_check_all`, call `region_plan_analyze()`.
- [ ] If `region_plan_has_split() != 0` and no Phase A diagnostics: `ir_gen_reset_state()`, `ir_gen_all()`, then rerun `ptr_analysis_all` + `region_check_all`.
- [ ] Add hidden `--dump-region-plan` printing one `split <sg>` line per marked IF.
- [ ] `corec cir` still returns before Phase A; no split there.
