## 现状根因（一句话 + file:line）

**同一 IR 站点（`ir_gen.cr:1378` `IR_STORE_PTR`）同时服务两类槽**：**聚合槽**（E-2 起权威 = **恒装箱**）与**局部槽**（权威 = **表示位**，`emit_rep_set` **只在直接写点发**，`ir_gen.cr:244`）⇒ 指针写**绕过表示位**（局部）或**绕过装箱**（聚合）⇒ 解包侧按单一假定读取 ⇒ 139（响亮）或静默错值。**别名不可静态闭合**（`q := p` 拷贝），故「在指针写点按目标类分派」的方案不可行（T2 实证：无条件装箱会把 `c1` 从正确转为静默错值）。

## 设计候选（**四条**；逐条给 布局 / 帧 / ABI / 代码生成改动面 / 读侧 / 与 box·arena 的关系 / 别名面 / 零足迹 / **可证伪判据**）

### (i) tagged slot：值与表示**同槽**（16B）
- **布局**：每个可选槽 16B（值 8B + 标签 8B；或 8B 值 + 8B 对齐的标签字）。
- **帧**：`frame.cr:51` `pf_frame_size(vc)` 现为**按变量数**求帧 ⇒ 须改为**逐槽按尺寸求和**（含 16B 槽）⇒ 帧布局/偏移全动。
- **ABI**：可选**形参/返回**成为 16B 对象 ⇒ SysV 分类变化（**本实例未实测**：16B 聚合按 SysV 通常走 MEMORY 类栈传递；**判据 = T1 实测**）⇒ `callseq.cr` 参数/返回序列 + 调用点/被调序言全动。
- **代码生成**：`IR_REF`/`IR_DEREF`/`IR_STORE_PTR` 的宽度（`ptr_access_width`，`:820`）变为 16；可选槽的 load/store 一律成对；`instr.cr`/`regalloc.cr`/`frame.cr`/`callseq.cr`/`interp.cr` 均在改动面。
- **读侧**：解包读**槽内标签**（取代表示位）⇒ 语义最统一。
- **box/arena**：可选槽可重新容纳裸值（标签说明形态）⇒ **E-2 的聚合恒装箱可放宽**（反向改动，本批不做）。
- **别名面**：**构造性闭合**（标签与值同址，任何写入路径写整槽）✓✓ —— 这是它唯一的、也是决定性的优势。
- **零足迹**：非可选程序不变（门控 `g_optrep_on`）✓；**但**含可选参数的函数 ABI 变（可选程序内）。
- **可证伪判据**：① 含可选槽函数的帧尺寸 = Σ 槽尺寸（实测帧 dump）；② 四形态经指针写后解包值正确（双路径）；③ **可选形参 >6 个溢出到栈**的调用实测正确；④ canary `95084e7b…d475` IDENTICAL；⑤ `.ccr` 四条不变；⑥ 解释器/ELF 双路径同值。

### (ii) 影子标签表：值槽不变，标签**按地址索引**走旁路
- **布局**：值槽 8B 不变（帧/ABI **零变化**）。
- **标签存储**：运行期旁路结构（地址 → 标签）。本仓**无运行期哈希表** ⇒ 需新运行期组件（`src/runtime/rt.s`）+ 每次可选槽读写在表内查询。
- **失效面（致命处）**：**栈槽复用**（不相交作用域的可选局部共用同一帧槽）· **`IR_ARENA_RESET`**（T2/T3 侦查：loop 每轮重置 ⇒ 对象地址被复用）· 重新分配 · 指针算术 ⇒ 陈旧标签可被读到。
- **代码生成**：所有可选槽的读写加查表（发射面变）；失效需显式清理（谁清？槽进入时？arena 重置时？）。
- **读侧**：解包 = 按地址查表。
- **box/arena**：不变。
- **别名面**：仅当「表恒权威且所有写路径更新表」才闭合——而上述失效面正是它不成立的场合 ⇒ **不可证**。
- **零足迹**：非可选程序不变（门控），但运行期组件常驻。
- **可证伪判据**：① 栈槽复用探针（两不相交作用域的可选局部）不得读到陈旧标签；② arena 重置后同地址再分配不得复用标签；③ 指针算术落相邻槽须有定义（拒绝或正确）；④ 帧/ABI/canary/`.ccr` 不变。

### (iii) **逃逸域化的恒装箱**（推荐）：地址被取过的可选槽 ⇒ **恒装箱**；其余保持现状表示位
- **法则**：**任何地址被取过的可选槽（局部/形参/调用结果接收槽）恒持装箱值**；其余可选槽保留现行表示位机制（可持裸值）。指针写（`IR_STORE_PTR`）在 **pointee 为可选**时限**装箱**（复用 T2 的 `box_for_slot_flag`）。
- **布局**：**零变化**（装箱值 = 8B 指针；`type_size(TYP_OPTIONAL)` 落尾 `return 8`，`ir_gen.cr:775-807`）。
- **帧**：**零变化**（`pf_frame_size` 按变量数不变）。
- **ABI**：**零变化**（8B 值语义不变；形参仍传 8B——**装箱在形参序言内完成**，见实现）。
- **代码生成改动面（小）**：① **取址面预扫**（照 `optrep_prescan`，`ir_gen.cr:3074`）标记「取址槽」（`UOP_REF` 的操作数为 ident 时；`&arr[i]`/`&全局` 走聚合/全局面已恒装箱）；② 局部**写点**（`ir_gen.cr:1320-1321`/`:2373`）对标记槽：**装箱 + 表示位钉 1**（不写裸编码）；③ 形参序言（`:2520-2530`）对标记形参：**条件装箱**（信道读得裸值则装箱）并把表示位钉 1；④ `IR_STORE_PTR`（`:1378`）：pointee 可选 ⇒ 装箱（唯一新增站点）。
- **读侧**：不变（表示位分派；标记槽恒 1 ⇒ 走装箱分支）；经指针读（`IR_DEREF`）所得值无表示位 ⇒ `rep_enc_of_expr` 回落**装箱假定**（`ir_gen.cr:470` 的 `oe_boxed()`）⇒ **正确**，因为**任何可取址的槽都恒装箱**。
- **box/arena**：不变（复用既有 `IR_MAKE_ENUM`/`alloc` 路径；无新 opcode ⇒ 解释器零改动，`interp.cr:709` 已支持 `IR_STORE_PTR`）。
- **别名面**：由不变量「**取址 ⇒ 恒装箱**」闭合（指针的**创建**是唯一取址途径：`IR_REF`/`IR_ADDR_INDEX`）。**边界**：**指针算术伪造地址**（`OP_PTR_ADD`，`ir_gen.cr:1208`；`*T?` 步长 8）可能落到**未被取址**的可选槽 ⇒ 越出本律 ⇒ 登记 + 探针（§裁决门 2）。
- **零足迹**：全部由 `g_optrep_on` 门控（非可选程序**不读**取址标记、不发装箱、`IR_STORE_PTR` 不判 pointee）⇒ canary 档（无可选）**发射面逐字节不变**。
- **成本**：被取址的可选槽每次写一次装箱（罕见面；语料零命中）。
- **可证伪判据**：① **取址面完备性** = 全仓枚举 `UOP_REF`/`IR_REF`/`IR_ADDR_INDEX` 发射点、逐条分类（ident 取址 / 元素取址 / 其它形态），**零未分类**；② 四形态经指针写后解包值正确（**双路径**）；③ **三子形态**：`c1` 保持正确、`c2` 转正确或（若不可）**响亮**、`c3` **转正确**（**判据 = 不得存在 rc=0 的错值**）；④ 非取址可选槽**仍可**持裸值（`test_optional` 48 例不回归）；⑤ canary IDENTICAL；⑥ `.ccr` 四条不变；⑦ 72 档/探针零差异。

**引理 1（指针来源枚举完备）**：全仓可产生「**槽**地址」的构造仅两种——`&ident`（`ir_gen.cr:1410` `IR_REF`）与 `&arr[i]`（`:1404` `IR_ADDR_INDEX`）。其余 `&<表达式>`（字段/临时/调用结果）经 `gen_expr` 先 LOAD ⇒ 取**临时量**地址（**非槽地址**）；`@addr(fn)`/`IR_FNADDR` 属**函数**地址（非槽）。**证据** = T1 §4.1 的七行枚举（全仓 `grep` 发射点全集 + 逐条分类，零未分类）。
