```
    Ⅱ. **ELF 腿降为弱腿**：只作「**≠7**」+ **N≥10 次采样不复现 7**，**不得**写「= 某值」。
```

```
      Ⅱ-bis（**更正，2026-09-18；以本子条为准**）：弱式**只作 pre-fix 的 RED 证据**——固定 **N=20**，
      且**必须可失败**（出现一次 `7` 即视为「未复现缺陷」）。**post-fix 一律走强式**（见 Ⅶ），
      不得拿弱式当修复判据（那等于把「修好了」降级成「没观察到旧坏值」）。
```

### A-2 修正 Ⅳ（追加 `255` 腿归属）

```
    Ⅳ. 「禁第三态」**对非确定值域不适用**（第三态即常态）⇒ 该形态改判「**必须可复现**」。
```

**在其后追加**：

```
      Ⅳ-bis：**`255` 只属 interp 腿**（`interp.cr` 的 `IR_I2F/IR_F2I` 能力边界：`corec run` 无 binary64 语义）
      ——**不得**混进 ELF 腿口径；修后本探针**无非确定问题**（构建失败是确定的）。
```

### A-3 新增 Ⅶ「两向钉子」（**两支同档共存**；整段插入）

```
    Ⅶ. **两向钉子（post-fix 强式；两支必须同档共存）**：
       · **支 1（拒）** 本探针 `g(1, d)`（apx）：`check rc=1` **且断言到具体错误码**（不是只断 rc）
         · `build rc=1` · `-o` 产物**不存在** · `<out>.ccr` **不存在**；
       · **支 2（放）** `g(d, d)`（**防误杀钉子**，见 Ⅷ-bis）· `g2(d)` · 非泛型 `dex` 形参（`g12`）：
         `check rc=0` · **`ELF == interp == 7`**。
       **为何必须两支**：只写支 1 ⇒「**一律拒**」也全绿；只写支 2 ⇒「**一律放**」也全绿。
```

### A-4 新增 Ⅷ「机械腿两项」（**必写**）

```
    Ⅷ. **机械腿（确定性；必写两项）**：
       · **冷态**：跑判据前 `corec clean-cache` **或**独立缓存目录（暖态 `.cir` 重放会假红/假绿）；
       · **点名仪器**（没点名的不算判据）：`corec cir <f> -o <out>.cir` 的 **`call <实例名>(…)`** 行
         + **`dest=_dxsc`** 计数；`corec cir <f> --dump-params` 的
         **`PARAM <实例> p<i> <name> slot=<ti> decl=<tv>`** 行。
    Ⅷ-bis. 支 2 的 `g(d, d)` **是当场抓出误杀的那条**（实测：`[S1-ARG]` 对 `T?` 恒报，含**已正确编译**的
       合法调用）⇒ **保留为钉子，不得删**。
```
