## §0 结论前置（红旗：**A 类的「排除」证不出来**）

**A 类（49 点）无法写出满足正反两条断言的判据式**——它与真异型**在类型面上逐字段同形**，本仓**也没有可用来区分的 handle 型**。

| 来源 | 清单行（同一台二进制、同一格式） | 形状 |
|---|---|---|
| **A 类**（语料真样本，`tests/suite/conc_test.cr`） | `9917 523 23 0 3 0 sched_enqueue` | **`p=3(string) ← a=0(int)`** |
| **真缺陷**（对照探针 `fn takes(s: string)` ← `n : int = 7`） | `9917 5 11 0 3 0 takes` | **`p=3(string) ← a=0(int)`** |

**三型分类（实据）**：
1. **45 点**：实参 = `cur_g := sched_get_curg()` / `recv_wait := r64(ch, 48)` ⇒ **普通 int 变量，AST 看不出 handle**（`r64` 按 `-5` 是设计旁路、其 int 返回有契约）；
2. **4 点**：`ch := go square(21)` ⇒ **变量中介**（`EXPR_GO` 的 int 先落变量再传 `chan_recv`）⇒ 与 `#2026-09-19-4` 的 `await` 那条**同型**；
3. **无 `TI_HANDLE` 常量**：`grep 'TI_HANDLE\|TI_CHAN\|TI_GOROUTINE' src/compiler/ast.cr` = **空**（handle 就是 `string`，A₂ 定的模型）。

**推理链**：抑制 49 点的唯一可实现规则 = 「按 (callee, param) 列全」（`sched_enqueue(g)` · `chan_recv/chan_send/chan_close(ch)` · `g_free(g)`）⇒ 该规则**必然让「int 变量 → `chan_recv`」不再报** ⇒ **反向断言按构造不可能存在**。
⇒ **且 (丙) 也退化**：要「刀 4 不覆盖 A 面」**也需要一条抑制规则** ⇒ 同样回到 (乙)。
⇒ **唯一出路 = (甲)：把 A 的产出侧真正改型** ⇒ **这正是维护者裁定一**（§A）。

### §5.1 ⚠ **工作区 stale 处置：强制前置（2026-09-19 由「配方」升为「前置」）**

**凡本计划涉及的任何 worktree，stale 处置一律：先 `cp -a`（或逐档 `cp`）到仓库外 ⇒ 再 `update-stale` ⇒ 再复核 sha。**

- ⇒ 这条**同样适用于 §8 施工序的每一步**（改判期间会频繁切基点）。

### §5.2 ⚠ **独立验收项：「安全面不得净减」**（裁定二专属，**不是附注**）

> **改判前生效的检查，改判后要么仍生效，要么显式登记为「已知不再生效」并给理由。**

- **背景**：`region_check`（`rc_return_escape` / `rc_store_escape` / `region_check_func`）与 `provenance_verify`（TU03 门）**只认 `TYP_PTR`**。**⚠ 但「四处同类」是初判、已被逐处实读推翻**——见 **§5.3.1**：前三处 = **真·静默失去覆盖**；**第四处（TU03）对 `&x` 从未生效**（其 `extra` 恒 0）⇒ **零损失**，正确表述是「**本处不适用**」而非「不再生效」。
- **为什么必须独立立项**：**「减少检查」不会红**——它是**静默面**，正是本批一路在收的形态（用一次静默换一次不对称）。
- **判据**：逐处列出「改判前是否生效 / 改判后是否生效」，**任一处从「生效」变「不生效」且无显式登记 ⇒ 本项红**。
- **处置二选一**：**(a)** 扩展该处接受 `TYP_REF`（等价检查）；**(b)** 显式登记「已知不再生效 + 理由 + 覆盖面损失」，并在批报告写明。

## §9 两句裁定各自的**正反两条断言**（改契约类尤其要防误杀）

| 裁定 | 正向（该变的变了） | 反向（防误杀） | 对照（防「一律」） |
|---|---|---|---|
| **一**（`Future<T>`） | `go f(x)` 的型 = `Future<T>`；`await h` 取 `T`（**运行值 + `--dump-types` 双读**） | 合法 `await` 链**不报**（`p_go.cr` 形） | 非 `go` 的普通值**不受影响** |
