## §1 逐条（现象 / 最小复现 / 机理 / 判据要件 / 突变自证 / 停条件）

### 1. ⚠ **【S】泛型实例化后 `dex?`：环按声明判、槽按实例判**（`TODO #2026-09-17-5`）

- **现象（实测）**：`check=0 · build=0 · **ELF 142 / interp 15**`（期望 **7/7**）；**scaled 实参对照 = 7/7**
  ⇒ 静默错值 **+ ELF≠interp（双路径分歧）**，与批 5 原始 RED（u11）同严重级。
- **最小复现**：
  ```core
  fn g[T](t: T, x: T?) -> int {
      return match x { Some(v) => { return @raw_int(v) / 1000000; } None => { return 0; } };
  }
  fn main() -> int { d : dex, apx = 7.0; return g(1, d); }     // 期望 7；实测 ELF 142 / interp 15
  ```
- **机理（`file:line`，读码）**：
  - 调用侧环取**泛型声明**的形参链：`ir_gen.cr:1965` `cfi := find_func(func_ni)` → `fi_ast_node(cfi)`；门在 `:1985`
    （`dex_opt_type_node(ast_data(cpn))`）——泛型声明的形参类型节点是 `T?`（inner = 泛型参数 `T`）⇒ 判据**假**
    ⇒ **apx 实参不转换**（bits 原样）。
  - callee 侧按**实例**判：monomorph 克隆 `ir_gen.cr:3703`（`alloc_node(EXPR_PARAM, …, new_type_node, …)`）
    ⇒ `W3`（`:3080`）命中 ⇒ 槽 = **`TI_DEX_S`**（GP）。
  - ⇒ 实参按 `TI_DEX` 走 **XMM**、callee 按 **GP** 读 ⇒ ELF 垃圾值（142）、interp 按位置拷贝得 bits（15）。
- **修法方向**：**A（推荐）**= 泛型重定向（`:2017+`，`gen_create_instance`）后**按实例签名再跑一遍实参环**
  （复用批 5 已验的 `W3/W4` 谓词）；**T0 必做侦查**：重定向后 `arg_vars` 与**实例形参链**的锁步对齐
  （方法接收者/`self` 占位——批 5 已在同类偏移上踩过）。**B（备选）**= 环内对泛型被调改用调用点绑定段/具体化类型（复杂，不首选）。
- **判据要件**：① 两腿同判（ELF 与 interp 一致）；② **禁第三态**（bits 源 interp ∈ {255, 锚定值}）；③ `scaled` 实参
  对照 + **非泛型直调对照**保持 7/7；④ **apx 槽自证**（`.cir` 出现 binary64 位常量）；⑤ 若语义面变更 ⇒ **§0 换代** + 哨兵三件套。
- **突变自证**：把「重定向后再跑环」退回「不跑」⇒ 本探针**必红**（ELF 回 142 或 interp 回 15）。
- **停条件**：修法若需改 **ABI 类/后端** ⇒ 停下报 lead；重定向邻域的锁步对齐若与实例缓存/mangling 冲突 ⇒ 停下报 lead。

### 2. ⚠⚠ **【S·通用】可选值 `==` 恒假（含 `None == None`）**（`TODO #2026-09-17-6`）

- **现象（实测五读数）**：`n==Some(7)` ⇒ **0** · `n==None` ⇒ **0** · **两个 `None` 变量比较 ⇒ 0** ·
  两个值为 7 的可选比较 ⇒ **1** · `n == 7`（可选 vs 内层值）⇒ **1**。
- **最小复现**：
  ```core
  fn main() -> int { n : int? = None; if n == None { return 1; } return 0; }   // 期望 1；实测 0
  ```
- **机理（本轮新证）**：`==` 走**通用二元路径**（`ir_gen.cr:1453` 的类型门）**不读 rep 位** ⇒ **逐槽比较原始值**：
  bare（rep=0）= 值本身 ⇒ `7==7` 真；**boxed（`Some`/`None` 对象）= 指针** ⇒ 指针 vs 值、指针 vs 另一指针**恒假**。
  既有「读 rep」先例（可作修法模板）：`irv_rep`（`ir_gen.cr:230`）在 match 解包（`:2424`）、`?` 解包（`:2981`）、
  写点（`:1496`）三处被读取——**比较点是缺口**。
- **判据要件**：① `Some(x)==Some(x)` **必真**；② `None==None` **必真**；③ `Some(x)==None` **必假**；
  ④ **同源自比较 `x==x` 必真**（bare/boxed 两表示都测）；⑤ 非可选 `==` 语义与产物**零变化**（canary/`.ccr` IDENTICAL）。
- **突变自证**：把比较点退回「不读 rep」⇒ `Some(7)==Some(7)` 与 `None==None` 两条**必红**。
- **停条件**：若裁决为「表示敏感相等」（保持现状）⇒ 本条**移出本批**、降级为语言语义登记（见裁门 G3）。

### 3. **【fail-closed 缺口】`extern` 形参不校验可选**（`TODO #2026-09-17-7`）

- **现象（实测）**：`extern fn e(x: dex?)` ⇒ **`check` rc=0（零诊断）**、`build` rc=0、运行期 **139**；
  对照 `extern fn e(x: int?)` ⇒ **同形同判**（非 dex 特有）。
- **最小复现**：
  ```core
  extern fn e_opt(x: dex?) -> int;
  fn main() -> int { d : dex, apx = 7.0; return e_opt(d); }    // check=0（应拒未拒）；运行期 139
  ```
- **机理（读码）**：`checker.cr:2167` `if ast_kind(fn_node) == EXPR_EXTERN { return; }` ⇒ **extern 声明的形参/体检查整段跳过**
  ⇒ 无「C ABI 可表示性」校验；`ir_gen.cr:1985` 的 `cfn_ext == 0` 守卫使实参环**对 extern 侧不扩**（无约定可依）。
- **判据要件**：① `extern` 声明含可选形参 ⇒ `check` rc=1 + 专属诊断 + **零产物**；② 非可选 `extern` 行为**逐字节不变**；
  ③ `dex?` 与 `int?` **同一拒收路径**。
- **突变自证**：撤掉新校验（或放行该形态）⇒ 探针回 `check=0` ⇒ **必红**。
- **停条件**：若实测发现 C ABI 实际支持某可选形态（e.g. 指针型可选）⇒ 停下报 lead 再定粒度。

### 4. ⚠ **【S】顶层兜底静默吞 token**（分诊/登记面；`parse_declaration` 裸 `advance_tok()`）

- **现象（实测三态）**：① 顶层多余 `}` ⇒ `check=0 · build=0 · 运行 7`（**零诊断静默接受**）；
  ② `stuct S { f: int }`（typo、未使用）⇒ `check=0 · build=0 · 7`（**声明被无声丢弃**）；
  ③ 同上但**使用** `S` ⇒ `check=1`（`error[TF01]` = **误报**）+ **build=0** ⇒ 运行期 **139**。
- **机理（`file:line`）**：`parser.cr` 的 `parse_declaration()` **末尾为裸 `advance_tok();`**（函数尾、紧随
  「New syntax global variable declaration」分支之后；实读时在 `:1540` 邻域）⇒ **无法识别的顶层 token 被静默消费**，
  既不 `add_error` 也不定位。③ 的 TF01 与**条目 6 同族**（静默丢弃 ⇒ 后续误归）。
- **判据要件**：① 无法识别的顶层 token ⇒ `check` rc=1 + 定位诊断 + **零产物**；② 合法顶层形态
  （`mod`/`@` 注解/宏/`import`/全局声明）**逐字节不变**；③ 与条目 6 **同批核对**（③ 的 TF01 属同族误报）。
- **突变自证**：恢复裸 `advance_tok()` ⇒ ①/② 两条探针回 `rc=0` ⇒ **必红**。
- **停条件**：若合法顶层形态与兜底分支**共用入口**（`mod {}`/宏体等），无法无歧义区分 ⇒ 停下报 lead 取裁粒度。

### 5. **【语义谎】标签在不适用类型上被静默忽略**（`TODO #2026-09-17-4`，已登记）

- **现象/机理/判据要件**：**已登记**（`parser.cr:819` 标签白名单不校验适用性；`ir_gen.cr:2525-2528` 是 `apx`
  唯一作用点）⇒ 本批只需**实施其判据要件**：① 不适用组合（`int, apx` / `dex?, apx` / 其它非 `dex` 声明 + `apx`）
  ⇒ 硬错 `check` rc=1 + 零产物；② 适用组合（`dex, apx`）**逐字节不变**；③ 三例探针按「显式归因 + 同批重锁 + 旧值留痕」。
- **突变自证**：把新校验退回「接受并丢弃」⇒ `int, apx` 探针回 `rc=0` ⇒ **必红**。
- **停条件**：若他批（批 6/7）已有同面在改 ⇒ 停下协调，防双改。

### 6. ⚠ **【成对·静默放大器】TF01 误报 + 豁免行（必须一起解）**

- **现象（实测）**：`diag.cr` 豁免表点名的 **5 档并发语料**（`chan`/`conc`/`go_e2e`/`go_final`/`go_parallel`）
  实跑 build **各 2 条 `error[TF01]`**（例：`chan_test.cr` 点 `fn chan_make(elemsize: int, cap: int) -> int` 的
  **合法签名**；`go_e2e_test.cr` 点 `:641/:717`）⇒ **误报**；build rc=0 是**豁免放行**的结果。
- **机理（`file:line`）**：豁免行 = `diag.cr:171-215` 的 `EC_TF_RETURN`（`GATE_SCOPE_BUILD`）条目：
  位点 = 上述 5 档、理由 = 「并发族既有误报（同族两条已修先例 `#2026-09-13-1`）」、退出 = 「逐档归因 + 修前端根因后撤」。
  **闸门**：`main.cr:155` 按 `diag_gate_exempt(ec, GATE_SCOPE_BUILD)` 决定是否阻断 ⇒ 豁免在场 = 该码不阻断。
- **为何必须成对**：**只修误报**（豁免不撤）⇒ 豁免变成**掩体**（未来真 TF01 在 build 面被静默放行）；
  **只撤豁免**（误报不修）⇒ 5 档 build 被闸 ⇒ `suite` job 红。**两个错误解都是静默/假红来源。**
- **判据要件**：① 5 档语料 **build 日志 TF01 = 0 且 rc=0**；② 豁免表**该行已删**（表纪律：**只减不增**，撤条须带根因证据）；
  ③ **负控**：注入一个**真 TF01**（合法构造）⇒ build **必须被闸**（证明撤豁免后保护在场）；④ 其余 5 条豁免行**逐条不动**（零足迹）。
- **突变自证**：恢复该豁免行 ⇒ 负控转绿（= 判据红）。
- **停条件**：若 5 档误报的**根因**落在并发语义/类型引擎深处（非单点）⇒ 拆分为「先修根因（本批）+ 撤豁免（同批尾部）」，
  若根因不可在本批内收敛 ⇒ 停下报 lead（**不得**只做一边）。

## §5 最大风险

1. **条目 1 落在泛型重定向邻域**（mangling / 实例缓存 / 形参链锁步——本仓最复杂区之一），且需 **`CIR_CACHE_VER` 换代**；
   批 5 已在同类的「接收者/self 偏移」上踩过 ⇒ T0 侦查不可省。
