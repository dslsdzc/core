### 2. （S·通用）可选值 `==` 恒假（含 `None == None`）（`TODO #2026-09-17-6`）

- 现象（实测五读数）：`n==Some(7)`，因此 0 · `n==None`，因此 0 · 两个 `None` 变量比较，因此 0 ·
  两个值为 7 的可选比较，因此 1 · `n == 7`（可选 vs 内层值），因此 1。
- 最小复现：
  ```core
  fn main() -> int:
      n : int? = none
      if n == none:
          return 1
      return 0
  // 期望 1；实测 0
  ```
- 机理（2026-09-18 重定位点 + 定性更正）：`==` 走 `gen_expr`（`ir_gen.cr:1192` 起）内的通用落点 `:1465-1467`

  行定位更正：原文引的 `:1453` 落在 `gen_expr` 内的 dex 定点分支中（`:1412` 开块、`:1453-1459` 为「缩放整数比较」），
  不是通用落点；两个非 dex 操作数（如可选）走 `:1465`。
  机理定性（重要）：本节机理属读码推断、未实测，`TODO #2026-09-17-6` 的登记原文即「机理未定位……勿据本条推断根因」；
  引用时须与「现象五读数（实测）」分层（第 1 节第 1 项 的教训 = 读码推断可被实测否定）。
- 机理无关的验证法（2026-09-18 补；取代「按机理选突变点」）：1 实施前先在改前构建上复现五读数（`0/0/0/1/1`），现象定位点，与机理无关；
  2 突变自证 =「按改前五读数反向注入探针期望值，因此必失败」+「修复后逐条取反」。
- 验收要求：1 `Some(x)==Some(x)` 必真；2 `None==None` 必真；3 `Some(x)==None` 必假；
  4 同源自比较 `x==x` 必真（bare/boxed 两表示都测）；5 非可选 `==` 语义与产物零变化（canary/`.ccr` IDENTICAL）。
- 检查强度补强（2026-09-18 实测）：1–4 全部可被「只比 tag、不比载荷」的实现满足（同 tag，因此真 / 异 tag，因此假 / `x==x`，因此真），因此
  检查全部通过而 `Some(7)==Some(8)` 仍错误为真。因此必补：
  ⓐ 载荷不等必假（`Some(7)==Some(8)`，因此假）+ 方向对称（`None==Some(7)` 必假；`x==None` ↔ `None==x` 两向同判）；
  ⓑ 混合形语义固定（`n == 7` = 可选 vs 内层值，现状 1，见现象第 5 读数；验收要求原无它，因此修法可把它改成 0 而全部通过 = 语义退化）；
  ⓒ 断言面 = 程序运行退出码：本探针修复前后 corec 都 rc=0，只差返回值，因此以 corec rc 为断言 = 真空通过（全批唯一硬性约束）；
  ⓓ 要件 5 的仪器覆盖缺口：canary/`.ccr` 四条对 `==` 面零覆盖（同族先例 = `tests/selfhost/test_apx_conversion.py:18-21` 明文
    「apx 面零覆盖……不得以『canary 还通过着』代替」），因此「非可选零变化」须由该面行为断言 + 全语料对比承担（第 5 节第 2 项 / U3）。
- 突变自证（2026-09-18 改机理无关形式）：见上方「机理无关的验证法」，不得用「把比较点退回『不读 rep』」这类预设缺陷点的突变
  （若真机理不在比较点，该突变改不到缺陷处，则探针与检查双双保持通过 = 自证失效）。
- 停条件：若裁决为「表示敏感相等」（保持现状），则本条移出本批、降级为语言语义登记（见裁门 G3）。
