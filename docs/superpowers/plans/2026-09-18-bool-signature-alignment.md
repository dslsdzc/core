## §1 问题形态（为什么这是「静默面」，不是洁癖）

自测/bridge 通道的计数惯用式是 `fails = fails + ts_check(name, <谓词>, 1|0)`：
`ts_check` 的第二/第三形参声明为 `int`，而**第二实参本就是 bool 表达式**（谓词）。旧形靠
**bool 隐式当 int(0/1)** 参与 `!=` 比较而「恰好正确」——这正是 S1P 打点报的 `形参 int ← 实参 bool`
（`p_ti=0 / a_ti=2`）。它不是错误值，而是**靠隐式转换活着的接缝**：一旦收尾（bool 不再当 int，
见 S2/S3）这批调用点会**整片翻面**，且失败信号是「自测数不准」而非编译错误 ⇒ 属**第 1 类静默**。

## §2 方法（机械改写 + oracle 枚举，不靠正则收敛）

1. **改写规则**（收紧过一次，见 §2.1）：`ts_check("名", <bool 表达式>, 1|0)` → `ts_check_b("名", <bool 表达式>, true|false)`；
   新增签名 helper：
   ```core
   fn ts_check_b(name: string, got: bool, want: bool) -> int   // type_selftest.cr
   fn ps_check_b(name: string, got: bool, want: bool) -> int   // purity_selftest.cr
   ```
   二者返回 int（1/0），**保持 `fails = fails + …` 惯用式不变** ⇒ 累加值不变（§3 零行为变化）。
2. **枚举的 oracle = 被修对象自己的输出**（S1P 清单），不是文本扫描：
   `CORE_S1P=1 ./build/corec check src/compiler/main.cr | grep -E '^991[78] '`。
   **收敛判据** = 逐桶清点（不靠「grep 到几处」的弱结论）。

### §2.1 两次**过匹配**事故（留痕：为什么规则必须是「括号形」）

| # | 规则 | 后果 | 处置 |
|---|---|---|---|
| 1 | 文本规则「凡 `ts_check(` 第二实参为 bool 形态」 | 179 处被改 ⇒ 清单出现 163+16 **新** `bool←int` 点（把 int 实参改成了 bool） | 全量回退，重新定规则 |
| 2 | 同上，未排除 `ts_isat_b2i(...)`（**int 返回型转换器**） | 62 点 | 回退后加「第二实参须以 `(` 开头且含 bool 运算符，或为 `true`/`false`」 |
| 3 | 收紧后仍漏 1 处 | — | 该处第二实参**另起一行**（多行调用），行内文本不以 `(` 开头 ⇒ 终判据 = **实参首字符**而非行首 |

**教训**：规则要**以实参为单位**表述（AST/括号配平），以「行内文本」为单位必然在**多行调用**上漏/错。

## §5 写进文档事实（lead 要求：多态槽事实）

- **清单覆盖面 = 非字面量实参面**：S1P 打点对**字面量多态**实参**主动跳过**（护栏③ `f(3)` 必须零打点，
  见套件内 `LITERAL` 腿）⇒ **「bool 桶归零」的效力边界 = 非字面量面**；字面量面不在本判据内，
  也不受本轮改写影响（171 处第二实参全是非字面量谓词表达式）。
- **方法调用面不在本点**（套件内 `METHOD_GAP` 腿锁定：`s.m(b)` 异型 0 打点）⇒ 171 处均经**直调**到点；
  方法面待 S2/S3 扩覆盖后再判——**该不可达分支不得当死码删**。
- **清单归零 ≠ 语义正确**：残桶 68 点仍是 `string↔int`（46 `0←0` + 22 `2←3`），**未修**；
  S2 路线 1 的验收须逐点给语义依据 + 零行为变化，不得只看数字。

## §6 版本位与缓存面（为什么**不动** `CIR_CACHE_VER`）

本改动**不改变任何已接受程序的 IR/`.ccr`/ELF 语义**——只改**编译器自身**的两个自测文件的调用形态；
唯一「产物面」变化是 `build/corec` 二进制本身（多一个 helper、若干调用点）。
- ⇒ **无「已接受程序 IR 变化」**，版本位**不动**（bump 的正当理由只有一条：**缓存复活坏产物**；
  判据是**身份闸**不覆盖的面，见 `cir_cache.cr` 身份闸与 TODO #2026-09-18-16「指纹不含函数体」）。
- 缓存面：`type_selftest.cr`/`purity_selftest.cr` 两文件 AST 变 ⇒ **其自身条目 miss 重建**；
  其余文件条目语义等价 ⇒ 命中无害。身份闸仍为兜底。
