# `.cir` 快照「串域」跨进程 id 缺陷——修法计划（2026-09-18）

**状态**：**计划，未实施**。登记条目 = `TODO.md` 的 `#2026-09-18-9`（含本次只读调查的实测更正层）。
**性质**：暖态（cache hit）静默错值——同一源、同一二进制，第二次构建得到**不同 IR**，两次 `build` 均 `rc=0`。

---

## §0 一句话结论

`.cir` 快照把「串操作数」存成**写侧进程的绝对 intern id**，装载侧**原样恢复、且不做任何重映射**；
而读侧进程的 intern 表布局取决于「哪些函数被生成、哪些被装载」⇒ **凡首次 intern 发生在 IR 生成期的串**
（多字段 `@fields`、合成变量名、`Some`/`None` 类合成名…）在读侧解析到**别的串**（可到垃圾字节）。

## §2 三案（含取舍与实测影响面）

### 案 (a) 内容键重映射（治本 / 保命中 / 改动最大）
- **盘面**：str 段每条串增记**写侧 id**（或改为「按 id 有序 + 段基线」），`CIR_CACHE_VER` **必须 bump**（格式变更）。
- **装载**：按序 `str_intern(内容)` 得读侧 id ⇒ 建 `old_id → new_id` 表 ⇒ **改写**指令/节点/var 名里的串槽。
- **难点（唯一硬风险）**：**哪些槽是串 id** 不能靠值域猜（立即数会撞号）⇒ 必须按 `(opcode, tk)` 派生
  （与 DFG 槽派生同源）。**漏一个发射点 ⇒ 静默错值复活** ⇒ 须做「**串槽写点完备性审计**」
  （枚举 `ir_gen.cr` 全部 `str_intern(` 后入槽点 + `irv_set_name` + `irv_name` 写点），并用注入式探针逐点收敛。
- **影响面**：`save_cir_cache` · `load_cir_cache` · 尺寸计算 · `CIR_CACHE_VER` · `tests/selfhost/test_cir_warm_path.py` · 可能的 `--dump-*` 通道。
- **收益**：暖态命中率**不退化**（批 7 刚从净负翻正）。

### 案 (b) 串域恒校验见证（fail-closed / 最低实现风险 / 失命中）
- **盘面**：落「写侧串表基线 + 每条被引用串的内容摘要（或旧 id）」，**bump VER**。
- **装载**：按序重 intern 后逐条比对；**不一致 ⇒ 拒绝（cache miss = 无害重建）**。**不重写任何操作数**。
- **代价（须实测）**：任何「生成/重生成」都会使表布局漂移 ⇒ **部分暖态大量 miss**（命中率可能回落到批 7 之前）。
  ⇒ 计划要求先测「典型一次编辑后的暖态命中率」，若跌回净负则本方案不可取。

### 案 (c) 保 id 恢复（保命中 / 免槽判定 / 需一致性见证）
- **做法**：装载期把写侧「id → 串」映射**灌进读侧 `g_strs` 的相同下标**（必要时扩容填洞、同步 hash）⇒
  **不改写任何操作数**，也不需要「槽是不是串」的判定。
- **代价/风险**：① 外来条目进入 intern 表（内存/性能）；② **跨条目一致性**——同一缓存目录里的条目可能由不同写侧
  运行写出（编辑一个文件后部分重生成），其编号空间可能冲突 ⇒ **须落一条「表前缀见证」**（如写侧 `g_str_count` 或前缀摘要），
  不兼容即 miss（把 (b) 的见证缩到「前缀」粒度）。
- **收益**：兼容时**保命中**且实现面最小（不动操作数语义）。

**建议**：**先 (c)、不成就退 (b)**；(a) 仅在「(c) 的前缀见证在真实编辑序列下命中率过低」且「(b) 打击收益」时才投入（它要求写点完备性审计，成本最高）。
**共同点（三案一致）**：盘面都要加信息 ⇒ **`CIR_CACHE_VER` 一律 bump**（照既有纪律：缓存内容语义变更必须 bump，`cache miss = 无害重建`）。

## §3 判据要件（修复批必须全绿，且**判据自带突变自证**）

1. **入口锚定**：`reproA` 形态——冷 `"x,y"`/3 **且** 暖 `"x,y"`/3（rc 同、产物 `cmp` 同）。
2. **判别实验入判据**：`firstintern` 形态——`ONE=x`（解析期已 intern）暖态**必须**正确、`TWO=x,y` 暖态**必须**正确。
3. **两腿同判 + 锚定值**：冷腿与暖腿各自断言**同一字面量锚定值**，并逐字节对拍产物（不是「都 rc=0」）。
4. **删条目回归**（本调查判别力最强的一条）：删任意缓存条目后重跑，结果**仍须**与冷态逐字节同（F5 的形态）。
5. **突变自证**：测试内提供「关掉重映射/见证」的注入（或把映射改成恒等）⇒ 判据**必红**；且突变须断言命中目标。
6. **载体**：`tests/selfhost/test_cir_warm_path.py`（既有暖态套件，已挂 `run.sh selfhost-tests` ⇒ 进门）；
   **不得**只加 `tests/suite/*.cr`（PR 门只 3/5 档，语料档在 PR 上不跑）。
7. **label 域触发器**：若本批或后续改动「跳转编码按距离选短/长」或新增直接消费 label id 的点 ⇒ 必须重跑
   `/tmp/cachedef/labels/` 的撞车实验（F10 的结构自保前提即失效）。
