# 惰性求值实现计划

> 受众：执行本计划的 agentic worker。必需子技能：`superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施。进度以复选框（`- [ ]`）跟踪。

目标：实现自动惰性求值。编译器把只在一个分支中使用的纯函数调用延后，不需要 `lazy` 关键字。

架构：副作用分析标记纯函数。数据流图上的使用次数分析找出可延后的调用。`IR_LAZY_THUNK(46)` 包装值。`IR_LAZY_FORCE(47)` 在首次访问时求值。

技术栈：Core 自举编译器、数据流分析、x86-64 ELF 后端

## 全局约束

- 不引入 `lazy` 关键字，由编译器自动优化
- `IR_LAZY_THUNK = 46`、`IR_LAZY_FORCE = 47`
- thunk 占 9 字节（1 字节已计算标志 + 8 字节值）
- 纯函数 = 无 IO、无 FFI、无 unsafe 写入、无全局状态修改
- 版本控制使用 `jj`

### 任务 3：IR Gen 发射惰性 thunk

涉及文件：
- 修改：`src/compiler/ir_gen.cr`

步骤 1：为可延后的调用发射惰性 thunk

在 `gen_expr` 中，发射纯函数调用之后检查结果是否只在一个分支中使用。若是，用 `IR_LAZY_THUNK` 包装：

```core
if is_pure_func(func_ni) && is_single_branch_use(result_var) {
    thunk_var := new_ir_var("_lazy", TI_UNIT);
    emit(IR_LAZY_THUNK, thunk_var, result_var, 0, 0, 0);
    return thunk_var;  // return thunk instead of raw value
}
```

在使用点发射 `IR_LAZY_FORCE` 取出值。

步骤 2：提交

```bash
jj commit src/compiler/ir_gen.cr -m "feat: IR gen lazy thunk emission + force"
```
