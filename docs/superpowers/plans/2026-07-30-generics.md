# 泛型完整实现 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete generics in the self-hosted Core compiler: `<T>` parsing, type derivation, monomorphization.

**Architecture:** Parser handles `<T>` syntax. Checker registers generic params + derives concrete types at call sites. `monomorph.cr` (new) manages instance cache + generates specialized copies. IR gen calls specialized versions.

**Tech Stack:** Core self-hosted compiler (parser.cr, checker.cr, monomorph.cr, ir_gen.cr)

## Global Constraints

- No trait bounds, where clauses, or associated types
- Type derivation at call sites: `identity(42)` → `T = int`
- `monomorph.cr` is a NEW file (separate from checker.cr)
- Uses `jj` for version control
- `build_type_args` is a helper function that builds a compact string representation of the concrete type arguments (e.g. "int_str" for `<int, string>`)
- Mangled specialized function name: `func_name` + `$` + type_args (e.g. `identity$int`)

In `parse_fn` (look for where `T_IDENT` after `fn` keyword), after parsing the function name, check for `<`:

```core
// After reading fn name, check for generic params
if tok_k(cur_tok()) == T_LT {
    advance_tok();  // skip <
    // Parse generic param list
    gen_params_start := g_gen_param_count;
    loop {
        if tok_k(cur_tok()) == T_GT { break; }
        if tok_k(cur_tok()) == T_IDENT {
            param_ni := tok_lx(cur_tok());
            // Register as generic param
            grow_gen_params(g_gen_param_count + 1);
            w64(g_gen_params, g_gen_param_count * 8, param_ni);
            g_gen_param_count = g_gen_param_count + 1;
            advance_tok();
        }
        if tok_k(cur_tok()) == T_COMMA { advance_tok(); continue; }
        if tok_k(cur_tok()) == T_GT { break; }
        add_error("expected '>' or identifier in generic param list");
        break;
    }
    if tok_k(cur_tok()) == T_GT { advance_tok(); }  // skip >
    // Store generic param range in the function node
    ast_set_data(func_node, gen_params_start);  // start index
    ast_set_c(func_node, g_gen_param_count - gen_params_start);  // count
}
```

// Generic monomorphization: instance cache + AST specialization.
// Each concrete instantiation of a generic function/struct produces
// a specialized copy registered in g_funcs/g_structs.

// Instance cache: maps (func_name × type_args) → specialized func index
g_gen_instances : string, mut
g_gen_instance_count : int, mut
g_gen_instance_cap : int, mut

fn grow_gen_instances(needed: int):
    if needed < g_gen_instance_cap:
        return
    nc := g_gen_instance_cap * 2
    if nc < 64:
        nc = 64
    if nc < needed:
        nc = needed + 64
    nb := alloc(nc * 24)  // 3 × 8 bytes per entry
    _dyncpy(g_gen_instances, g_gen_instance_cap * 24, nb)
    g_gen_instances = nb
    g_gen_instance_cap = nc

// Find or create a specialized instance.
// func_ni = original generic function name index
// type_args = comma-separated concrete type names (e.g. "int,string")
// Returns the specialized function index.
fn gen_find_or_create(func_ni: int, type_args: string) -> int:
    // Scan cache
    i := 0
    loop:
        if i >= g_gen_instance_count:
            break
        if r64(g_gen_instances, i * 24) == func_ni:

            if str_eq(existing_args, type_args) != 0:

    // Not found: create new instance
