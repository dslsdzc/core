# corelsp（Core 自举 LSP 服务器）实现计划

> 受众：执行本计划的 agentic worker。必需子技能：`superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施。进度以复选框（`- [ ]`）跟踪。

目标：用 Core 语言本身实现 LSP 服务器（内部自用），复用自举编译器的前端模块，产出 `build/corelsp`，覆盖 diagnostics、hover、definition、completion、documentSymbol、semanticTokens。

架构：长期运行的进程内重新执行前端检查（tokenize、res_imports、parse_all、check_all，不报错地版）；检查产物只保留诊断（带 file_id）、符号表和令牌流；五个查询功能都按「位置、令牌查找、符号表查询」的顺序处理；查询不触发检查。协议层使用手写 JSON（递归下降，同 toml.cr 模式）和 JSON-RPC 2.0 帧循环（Content-Length framing，syscall3 读写）。

技术栈：Core 语言（src/lsp/，复用 src/compiler/ 前端）、Python 3（LSP 集成测试客户端）、build_selfhost_native.py（构建第三段）。

规格：`docs/superpowers/specs/2026-08-08-lsp-design.md`（已批准）

## 全局约束

- 禁止 git，全部用 `jj`（仓库铁律 #2）；提交信息中文
- 长时间编译/构建必须 `nice -n 19` 或 `cpulimit -l 10` 限流（铁律 #6）。本计划中所有 build_selfhost_native.py 调用都已加上限流前缀
- stdout 是协议通道：检查管线必须使用不报错地版（直接调用 tokenize/res_imports/parse_all/check_all，不得调用 run_frontend()，因为它含 `println("[1/5]...")` 进度输出）；日志输出到 stderr
- 只运行前端：到 check_all 为止，不生成 IR
- 行号与列号从 1-based 转为 LSP 的 0-based（输出时减 1）；列偏移 v1 按字节近似（UTF-16 后续补充，TODO 注明）
- 关键字表唯一依据：`src/compiler/lexer.cr` 的 `lookup_keyword()`（33 个）；@ 内建名单唯一依据：`checker.cr` EXPR_AT 分发（14 个）+ parser.cr `@ffi`。不得引用 tokens.ebnf/language-syntax.md
- 构建：`python3 build_selfhost_native.py`（产出 build/corelsp）；测试：`python3 tests/selfhost/test_lsp.py`；Core 自断言测试：`./build/corec build FILE.cr -o OUT --static && ./OUT`

### 任务 2：rpc.cr 的 JSON-RPC 帧循环与生命周期

涉及文件：
- 创建：`src/lsp/rpc.cr`（帧读写 + 方法分发表）
- 修改：`src/lsp/main.cr`（完整循环）
- 测试：`tests/selfhost/test_lsp.py`（Python 客户端，任务 1 的基本结构二进制上测）

接口：
- 使用：json.cr 全套接口
- 产出：`rpc_loop() -> int`（读取帧、分发、写响应，直到 shutdown/exit）
  - 读帧：`syscall3(0, 0, buf, n)` 循环收 `Content-Length: N\r\n\r\n` 头 + N 字节体（rt.s 零改动；buf 用固定 `[u8; 65536]` 或字节缓冲，以编译器既有 IO 习惯为准）
  - 写帧：`Content-Length: len\r\n\r\n` + 体
  - 分发：方法名到处理器的映射；`initialize`/`initialized`/`shutdown`/`exit` 生命周期；未知方法回 `-32601`；`initialize` 前收到其他请求回 `-32602`
  - initialize 响应：`{"capabilities": {"textDocumentSync": 1}}`；shutdown 后 exit 正常退出（return 0）
  - JSON-RPC 错误格式：`{"jsonrpc":"2.0","id":N,"error":{"code":C,"message":"..."}}`；成功：`{"jsonrpc":"2.0","id":N,"result":...}`；通知（无 id）不回

- [ ] 步骤 1：编写 rpc.cr

读帧：循环 `syscall3(0, 0, &buf[0], 1)` 逐字节收头（或按 spec 的 `read(0, buf, 4096)` 分块，执行时选实现简单的方式，rt.s 不改）；解析头；读满 N 字节；`json_parse` 得请求节点。写帧：拼 `Content-Length` 头 + `json_stringify` 结果，`syscall3(1, 1, ...)` 写出。

- [ ] 步骤 2：补全 main.cr 的循环

`lsp_main()`：初始化全局，再调用 `rpc_loop()`。帧循环内取 `method`（`json_obj_get`）与 `id`（无 id 则为通知），然后分发。

`tests/selfhost/test_lsp.py` 基本结构（后续任务增量扩展）：
```python
import json, subprocess, sys, time

BIN = "build/corelsp"

def read_frame(proc) -> dict:
    headers = {}
    while True:
        line = proc.stdout.readline()
        if line in (b"\r\n", b"\n"):
            break
        k, _, v = line.decode().partition(":")
        headers[k.strip().lower()] = v.strip()
    if "content-length" not in headers:
        return None
    return json.loads(proc.stdout.read(int(headers["content-length"])))

def send(proc, msg: dict) -> dict:
    body = json.dumps(msg).encode()
    proc.stdin.write(f"Content-Length: {len(body)}\r\n\r\n".encode() + body)
    proc.stdin.flush()
    return read_frame(proc)

def test_lifecycle():
    proc = subprocess.Popen([BIN], stdin=subprocess.PIPE, stdout=subprocess.PIPE)
    r = send(proc, {"jsonrpc": "2.0", "id": 1, "method": "initialize",
                    "params": {"capabilities": {}}})
    assert r["result"]["capabilities"]["textDocumentSync"] == 1, r
    send(proc, {"jsonrpc": "2.0", "method": "initialized", "params": {}})
    r = send(proc, {"jsonrpc": "2.0", "id": 2, "method": "bogus/method"})
    assert r["error"]["code"] == -32601, r
    r = send(proc, {"jsonrpc": "2.0", "id": 3, "method": "shutdown"})
    assert r["result"] is None
    proc.stdin.close()
    assert proc.wait(timeout=5) == 0

def test_jsonrpc_error_codes():
    proc = subprocess.Popen([BIN], stdin=subprocess.PIPE, stdout=subprocess.PIPE)
    # initialize 前发普通请求，返回 -32602
    r = send(proc, {"jsonrpc": "2.0", "id": 9, "method": "hover", "params": {}})
    assert r["error"]["code"] == -32602, r
    send(proc, {"jsonrpc": "2.0", "id": 10, "method": "initialize", "params": {}})
    r = send(proc, {"jsonrpc": "2.0", "id": 11, "method": "shutdown"})
    proc.stdin.close(); proc.wait(timeout=5)

if __name__ == "__main__":
    test_lifecycle()
    test_jsonrpc_error_codes()
    print("lsp lifecycle: ALL PASS")
```
