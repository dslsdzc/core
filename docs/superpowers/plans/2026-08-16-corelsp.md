# corelsp（Core 自举 LSP 服务器）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Core 语言本身实现 LSP 服务器（吃自己的狗粮），复用自举编译器前端模块，产出 `build/corelsp`，覆盖 diagnostics / hover / definition / completion / documentSymbol / semanticTokens。

**Architecture:** 长期进程内重跑前端检查（tokenize → res_imports → parse_all → check_all，静默版）；检查产物只保留诊断（带 file_id）、符号表、令牌流；五个查询功能全部走「位置 → 令牌查找 → 符号表查询」模式；查询不触发检查。协议层 = 手写 JSON（递归下降，同 toml.cr 模式）+ JSON-RPC 2.0 帧循环（Content-Length framing，syscall3 读写）。

**Tech Stack:** Core 语言（src/lsp/，复用 src/compiler/ 前端）、Python 3（LSP 集成测试客户端）、build_selfhost_native.py（构建第三段）。

**Spec:** `docs/superpowers/specs/2026-08-08-lsp-design.md`（已批准）

## Global Constraints

- **禁止 git**，全部用 `jj`（仓库铁律 #2）；提交信息中文
- 长时间编译/构建必须 `nice -n 19` 或 `cpulimit -l 10` 限流（铁律 #6）——本计划所有 build_selfhost_native.py 调用已带
- **stdout 是协议通道**：检查管线必须走静默版（直接调 tokenize/res_imports/parse_all/check_all，**不得**调用 run_frontend()——其含 `println("[1/5]...")` 进度输出）；日志走 stderr
- 只跑前端：到 check_all 为止，不生成 IR
- 行/列 1-based → LSP 0-based（输出时 -1）；列偏移 v1 按字节近似（UTF-16 后补，TODO 注明）
- 关键字表唯一依据：`src/compiler/lexer.cr` 的 `lookup_keyword()`（33 个）；@ 内建名单唯一依据：`checker.cr` EXPR_AT 分发（14 个）+ parser.cr `@ffi`——**不得**引用 tokens.ebnf/language-syntax.md

### Task 2: rpc.cr——JSON-RPC 帧循环 + 生命周期

**Files:**
- Create: `src/lsp/rpc.cr`（帧读写 + 方法分发表）
- Modify: `src/lsp/main.cr`（完整循环）
- Test: `tests/selfhost/test_lsp.py`（Python 客户端，Task 1 的骨架二进制上测）

**Interfaces:**
- Consumes: json.cr 全套接口
- Produces: `rpc_loop() -> int`（读帧 → 分发 → 写响应，直到 shutdown/exit）
  - 读帧：`syscall3(0, 0, buf, n)` 循环收 `Content-Length: N\r\n\r\n` 头 + N 字节体（rt.s 零改动；buf 用固定 `[u8; 65536]` 或字节缓冲，以编译器既有 IO 习惯为准）
  - 写帧：`Content-Length: len\r\n\r\n` + 体
  - 分发：方法名 → 处理器映射；`initialize`/`initialized`/`shutdown`/`exit` 生命周期；未知方法回 `-32601`；`initialize` 前收到其他请求回 `-32602`
  - initialize 响应：`{"capabilities": {"textDocumentSync": 1}}`；shutdown 后 exit 正常退出（return 0）
  - JSON-RPC 错误格式：`{"jsonrpc":"2.0","id":N,"error":{"code":C,"message":"..."}}`；成功：`{"jsonrpc":"2.0","id":N,"result":...}`；通知（无 id）不回

- [ ] **Step 1: 写 rpc.cr**

读帧：循环 `syscall3(0, 0, &buf[0], 1)` 逐字节收头（或按 spec 的 `read(0, buf, 4096)` 分块——执行时选实现简单者，rt.s 不改）；解析头；读满 N 字节；`json_parse` 得请求节点。写帧：拼 `Content-Length` 头 + `json_stringify` 结果，`syscall3(1, 1, ...)` 写出。

`tests/selfhost/test_lsp.py` 骨架（后续任务增量扩展）：
```python
import json, subprocess, sys, time

BIN = "build/corelsp"

def read_frame(proc) -> dict:
    headers = {}
    while True:
        line = proc.stdout.readline()
        if line in (b"\r\n", b"\n"):
            break
        k, _, v = line.decode().partition(":")
        headers[k.strip().lower()] = v.strip()
    if "content-length" not in headers:
        return None
    return json.loads(proc.stdout.read(int(headers["content-length"])))

def send(proc, msg: dict) -> dict:
    body = json.dumps(msg).encode()
    proc.stdin.write(f"Content-Length: {len(body)}\r\n\r\n".encode() + body)
    proc.stdin.flush()
    return read_frame(proc)

def test_lifecycle():
    proc = subprocess.Popen([BIN], stdin=subprocess.PIPE, stdout=subprocess.PIPE)
    r = send(proc, {"jsonrpc": "2.0", "id": 1, "method": "initialize",
                    "params": {"capabilities": {}}})
    assert r["result"]["capabilities"]["textDocumentSync"] == 1, r
    send(proc, {"jsonrpc": "2.0", "method": "initialized", "params": {}})
    r = send(proc, {"jsonrpc": "2.0", "id": 2, "method": "bogus/method"})
    assert r["error"]["code"] == -32601, r
    r = send(proc, {"jsonrpc": "2.0", "id": 3, "method": "shutdown"})
    assert r["result"] is None
    proc.stdin.close()
    assert proc.wait(timeout=5) == 0

def test_jsonrpc_error_codes():
    proc = subprocess.Popen([BIN], stdin=subprocess.PIPE, stdout=subprocess.PIPE)
    # initialize 前发普通请求 → -32602
    r = send(proc, {"jsonrpc": "2.0", "id": 9, "method": "hover", "params": {}})
    assert r["error"]["code"] == -32602, r
    send(proc, {"jsonrpc": "2.0", "id": 10, "method": "initialize", "params": {}})
    r = send(proc, {"jsonrpc": "2.0", "id": 11, "method": "shutdown"})
    proc.stdin.close(); proc.wait(timeout=5)

if __name__ == "__main__":
    test_lifecycle()
    test_jsonrpc_error_codes()
    print("lsp lifecycle: ALL PASS")
```
