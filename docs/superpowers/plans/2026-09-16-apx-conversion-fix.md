## §0 形式模型与契约（**实读**）

| 形式 | 常量 | 语义 | 默认世界 |
|---|---|---|---|
| 精确（scaled） | `TI_DEX_S = 8`（`src/compiler/ast.cr:274`） | 定点缩放整数，S = 10⁶ | **跨函数/跨存储边界统一形式**（`ir_gen.cr:971-972`） |
| 近似（apx） | `TI_DEX = 1`（`ast.cr:262`） | binary64 位模式（快路径） | 仅 **`apx` 标签的 LET 槽**（`parser.cr:819`：apx 是 **LET 专属标签**） |

**关键推论（本批的立论基石）**：`apx` 是 **LET 专属标签** ⇒ **形参 / 返回值 / 结构体字段 / 数组·切片元素 / 元组元素 / 枚举载荷 / 全局槽** 这些面**一律不存在 apx 形式**，其规范存储形式**恒为精确（scaled）**。因此：
- 这些面的写点规则可**不依赖声明面**：任何 `TI_DEX` 值写入聚合/全局槽 ⇒ 必须转 scaled；
- 调用实参面**依赖形参声明**（`TI_DEX` 形参在 callee 被强制为 `TI_DEX_S`，见下）⇒ 用 `fi_param_type` 即可，无需类型表。

**转换机构（4 个 helper，全在 `src/compiler/ir_gen.cr`）**：`dex_bits_to_scaled`（`:982`）· `dex_scaled_to_bits`（`:1016`）· `dex_scale_int`（`:1033`）· `dex_store_adjust`（`:1045-1051`，**按目标槽 IR 型**分派前两者）。契约自注释在 `:973-976`：「**存储/边界处按槽位形式转换**」。

**转换调用点全集（11 处，逐条实读命中）**：`1253 / 1259 / 1272 / 1273`（二元操作数对齐）· `1349`（局部赋值）· `1366`（全局赋值）· `1703`（`@raw_int`）· `1827 / 1832`（**调用实参环**）· `2424`（LET）· `2495`（返回点）。

**两后端在调用边界零 dex 逻辑**（实读）：ELF `cs_args_dispatch`（`src/os/linux/callseq.cr:66-89`）按 `irv_type` 分类进 XMM/int；`cs_arg_on_stack`（`:95-107`）按**类型类计数**判落栈；解释器 `interp.cr:240-245` **按位置拷贝实参、无任何 dex 判断** ⇒ **环漏转一个实参 ⇒ 双路径必同错**（同一个坏 IR）。

## §2 现状根因（一句话 + `file:line`）

> **dex 形式转换契约（「存储/边界处按槽位形式转换」）只在 5 类落点接线，而跨函数边界的唯一转换通道——调用实参环 `ir_gen.cr:1806-1848`——以 `ast_kind(func_node) == EXPR_IDENT`（`:1806`）为门，方法调用（`EXPR_FIELD`）整段跳过（#80）；两后端在调用边界只做运输、零 dex 逻辑（`callseq.cr:66-107` 按 `irv_type` 分类/计数；`interp.cr:240-245` 按位置拷贝）⇒ 漏转的实参在**两条路径上一致地错**（#81）。同时聚合四类写点（字段字面量 `:2647` / 字段赋值 `:1380` / 下标赋值 `:1403`·`:1410` / 数组字面量 `:2695` / 元组 `:2822` / 枚举载荷 `:2611`）与全局运行期初值（`:3097`）**无漏斗**，聚合读点硬定型 `TI_INT`（字段 `:2513` / 元素 `:2578` / match 绑定 `:2316`）⇒ 一切「按 IR 值型触发」的下游转换连锁失效（#78，放大器）。**

**逐条支撑（全部实读）**：
1. **环是唯一实参转换通道**：转换调用点全集 11 处（§0），实参面只有 `:1827`（extern scaled→bits）与 `:1832`（Core bits→scaled），二者同在 `:1806` 的门内。
2. **环门拒方法调用**：`:1806` 要求 `ast_kind(func_node) == EXPR_IDENT`；方法调用走 `:1776-1786` 的 `EXPR_FIELD` 分支 ⇒ `:1806` 判否 ⇒ 整段 `:1812-1847` 不执行。
3. **callee 恒精确**：`:2866` 把 `dex` 形参一律改 `TI_DEX_S` ⇒ callee 侧**没有任何 binary64 类形参**（推论：`frame.cr:119-137` 的 XMM 形参保存支对声明 dex 形参**不可达**，见 §9 U5）。
4. **后端按实参 IR 型分类**：`cs_args_dispatch:70-86`（`TI_DEX` → XMM0-7 / 否则 int 寄存器）、`cs_arg_on_stack:95-107`（**按类型类计数**判落栈）、`cs_stack_args:122-138`（`TI_DEX` → `e2_sd_ld_var` + `push xmm0`）——三者**全部按 `irv_type`**。callee 侧按 **形参序号** 定位栈参（`frame.cr:133/139`：`caller_off := 16 + (pi-6)*8`）⇒ **caller 按类型类、callee 按序号**，两类判据不同源（#81 的次错候选，§9 U3）。
5. **聚合/全局写点无漏斗**：见上「逐条」列出的 7 个发射点，**全部无 `dex_store_adjust`**；`inject_global_inits`（`:3067-3103`）只有可选装箱（`:3096`）。
6. **聚合读丢型（#78）**：`:2513` / `:2578` / `:2316` 三处 `new_ir_var(..., TI_INT)` ⇒ 读结果的 IR 型恒 `TI_INT` ⇒ 下游「按值型触发」的判定（二元对齐 `:1249`、LET/赋值的 `dex_store_adjust` `:1045`、返回门 `:2494`）**全部不触发**。

## §4 探针设计表（表 B′：审计 10 条 + 本批新增 4 条）

**通用判据网（**替换「逐例锁定值」的通用面**）**：
- **C1 双形对拍**：同一数值经 **apx 形** 与 **精确形** 两条路写入/读出 ⇒ 可观测结果必须**一致**；
- **C2 面覆盖对拍**：同一值经**未覆盖面**（字段/元素/元组/载荷/全局初值/方法实参/栈参）与经**已覆盖面**（局部 LET / 直调实参 / 返回）⇒ 必须一致；
- **C3 期望值锚**：断言锚在 `@raw_int` 表达的 scaled 整数（`@raw_int` 是**唯一显式形式通道**，`ir_gen.cr:1699-1708`；不用它做锚 ⇒ 比较点自己就踩 L10）；
- **C4 非回归对照（B-10）**：已覆盖面必须保持正确（防「修法把对的搞坏」）。

**两条硬约束（探针头注必须写，来源 = 上批 N-4 教训）**：
1. 涉全局**必须 `mut`**——不可变 + 字面量初值的全局被 `find_global_const_node`（`ir_gen.cr:592-611`）折叠成 `IR_CONST`，读点不碰全局行 ⇒ **探针假绿**；
2. **`apx` 算术无解释器侧判据**（`interp.cr:263-266`/`:702-705` 对 `IR_I2F`/`IR_F2I` **显式报错 rc=255**）——一切经 `@raw_int`/边界转换的 apx 探针**没有 `corec run` 判据**（能力边界、非缺陷）⇒ 主判据 = **ELF 侧双形/双面对拍 + 期望值**。

## §5 候选方案（三条；逐条 = 改动面 / 风险 / 可证伪判据 / 零足迹）

### (i) 唯一漏斗 + 声明型触发（**维护者背书方向；推荐主体**）

- **改动面**：
  1. 新增 **`slot_form_of_decl(declared_node_or_code) -> int`**：把「声明面」映到**规范槽形式**（`TI_DEX` ⇒ `TI_DEX_S`；`apx` 标记 ⇒ `TI_DEX`；非 dex ⇒ `-1`）。**输入契约见裁-APX-2（节点级、零 `alloc_type`）**。
  2. 新增 **`dex_slot_adjust(declared_ti, val, val_node)`** = 现 `dex_store_adjust` 的**声明型版**；`dex_store_adjust(target, val, node)` **退化为薄壳**（`slot_decl_ti(target)` + apx 位）⇒ **既有 5 个调用点行为等价、零字节**。
  3. **写点接线（7 处，L2–L8）**：字段赋值 `:1380` · 结构体字面量 `:2647` · 下标赋值 `:1403`/`:1410` · 数组字面量 `:2695` · 元组 `:2822` · 枚举载荷 `:2611` · 全局初值 `:3097`。
     其中**聚合面无 apx**（§0 推论）⇒ 规则可退化为「**`TI_DEX` 值 ⇒ 转 scaled**」，**不需要声明面查表**（⇒ 零 `alloc_type` 风险，见裁-APX-2）。
  4. **调用环重写（L1）**：抽 `dex_convert_call_args(callee_ni, first_arg, arg_vars, ac, is_method, is_extern)`：
     - 直调：形参节点链（现状）**或** `fi_param_type(cfi, i)`；
     - 方法调用：**跳过 `arg_vars[0]`（self）**，被调形参链不含 self（`ir_gen.cr:1776-1786` + TODO #2026-09-16-17 已记）；
     - extern：保持 `scaled → bits`（现状正确，`callseq.cr` 的 C ABI 面不动）。
  5. **比较点声明面查表（L10，作用域内替代 #78）**：`ir_gen.cr:1246` 处，操作数节点为 `EXPR_FIELD`/`EXPR_INDEX` 时经**节点级声明面**取其声明型参与分流判定（**不改 IR 型、不改读点**）。
- **风险**：
  - **R1**：任何新增 `res_type_node`/`alloc_type` 调用 = 给 ir_gen 路径新增类型表写入 ⇒ 破 warm-cache「不可写条目」不变式（`test_warm_cache_gate.py` 的实锤：warm 命中跳过 `ir_gen_func` ⇒ `alloc_type` 行不重建）⇒ **裁-APX-2 强制节点级零 alloc**。
  - **R2**：环重写改变直调面的发射序 ⇒ 若 `fi_param_type` 与形参链结果不一致（泛型实例化 / 形参超 64 / checker 未登记）⇒ 新错值。**缓解**：T2 枚举 + 保底「链不可用 ⇒ 回落旧路径」。
  - **R3**：聚合法规约（「槽恒精确」）若与某既有语料的实际依赖冲突（例如某语料依赖「聚合元素可持 bits」）⇒ 行为变更。**缓解**：T1 全语料 `check` 对拍（腿①）零差异为硬判据。
- **可证伪判据**：B-1/B-1b/B-3a/B-3b/B-4a/B-4b/B-5/B-6/B-8/B-11 由「静默错值」转**精确值 7/1**；B-10 与精确形对照保持绿；C1 双形对拍全同。
- **零足迹**：非 dex 程序（无 `TI_DEX` 值、无 `dex` 声明）⇒ 漏斗恒 `return val` 且**不经任何类型表查询** ⇒ 发射面逐字节不变。

### (ii) 逐调用形态补转换环（审计已指出「逐点补必再漏」）

- **改动面**：只给 `EXPR_FIELD` 分支加一段复制自 `:1812-1847` 的转换（不抽函数）。
- **风险**：形参链导航（`:1839-1844`）与 self 偏移**各复制一份**⇒ 漂移双源；聚合写点仍全漏（B-3..B-6/B-11 不动）。
- **判据**：只能让 B-1 单项转正；对 B-3..B-6 **零效果** ⇒ 覆盖面必然不闭合。
- **结论**：**不推荐**（无覆盖面闭合论证；本仓已有「`IR_REF` 修完仍漏 `IR_SLICE`/`IR_AWAIT`」的同类实证）。

### (iii) (i) + 后端不对称一并修（`frame.cr` 按类型类定位栈参）—— ⚠ **不推荐；留档警示**

- **改动面**：在 (i) 之上改 `frame.cr:133/139` 的落位公式为「按类型类计数」，或改 `callseq.cr` 的分类使**实参 IR 型在环后恒等于 callee 形参型**。
- **⚠ 致命前提问题（U5，本计划读码判定）**：`frame.cr:119-137` 的 XMM 形参保存支依赖 `pty == TI_DEX`，而 `ir_gen.cr:2866` **恒把声明中的 dex 形参改写成 `TI_DEX_S`** ⇒ **callee 恒无 binary64 类形参** ⇒ 该分支**当前不可达**。⇒ (iii) 是在**维持一个当前不可达的不变量**。
- **代价**：改**后端发射序** ⇒ canary / `.ccr` / 自举链**全在弹道上**（而本批的零足迹判据正是建立在这三者 IDENTICAL 之上）。
- **判据**：B-9 转正；canary IDENTICAL。
- **结论**：**保留为 L12 的退路**（当且仅当 (i) 修完后 B-9 仍红时启用，见裁-APX-6）；**启用前必须先证伪 U5**。典型形态：「看起来更彻底、实则引入风险」——**默认动作是 (i)**。

### 推荐

**主体 = (i)**，理由：① 覆盖面有**可机械枚举的闭合判据**（T2 四表零未分类），逐点补无此性质；② 漏斗化后「聚合面」不需要声明面查表（§0 推论）⇒ 零 `alloc_type` 风险，可**逐字节证明**零足迹；③ 环重写把形参类型来源从「AST 链前扫」换成 `fi_param_type`（O(1) 槽区读）⇒ **顺带消灭审计触发模式②**；(iii) 留作 L12 退路。
