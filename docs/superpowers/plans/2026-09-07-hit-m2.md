> **状态：待执行（2026-09-07 计划定稿）**
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 表模式从「直线数据子集」升级为可运行完整 Core 程序（含函数调用/控制流/系统边界）的真实后端路径,并把 instr.cr 硬编码发射器数据化收口——「表 = 唯一平台依赖」形态达成,验收 = 表模式自举（corec 经表模式编译自己成功运行）。

**Architecture:** 运行时核 9 事件（4 数据事件保持 + jump/branch/call/ret/extern 控制/调用/系统事件）;投影模板语言 schema v2（前缀/REX/opcode/ModRM/disp/imm/rel32/两步序列）;lower_to_core 全 op 覆盖（直通优先、4 核合成兜底、标签→事件序回填）;发射收口 = 单指令编码形态入表、序列算法保留（prologue/参数拷贝/2L 慢路径 = 模板解释器代码调模板）;运行时条目最小描述 + x86 ABI 一档。执行分四段 M2a-d（依赖序强,每段可独立提交评审）。

**Tech Stack:** Core 自举编译器（src/arch/hit/hit.cr + lower_to_core.cr + core-x86.toml、src/arch/linux/ld/instr.cr + elf.cr、src/compiler/corearch.cr）、Python 测试。

**设计 spec:** `docs/superpowers/specs/2026-09-07-hit-m2-design.md`（方案拍板 + 节 1-3 逐节确认 + M2a-d 分段——本计划按段展开任务;执行时 spec 为字段/接口的权威定义源）。
