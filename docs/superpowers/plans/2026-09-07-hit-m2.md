# HIT M2 实施计划（运行时核事件集 + 全表驱动结束）

> 状态：待执行（2026-09-07 计划定稿）。
> 面向执行本计划的 agent：必须使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans，按任务逐项实现。用复选框（`- [ ]`）跟踪进度。

目标：表模式从「直线数据子集」升级为可运行完整 Core 程序的真实后端路径，覆盖函数调用、控制流和系统边界。同时完成 instr.cr 硬编码发射器的数据化改造，达成「表是唯一平台依赖」的形态。验收标准是表模式自举：corec 经表模式编译自己并成功运行。

结构：运行时核 9 个事件，保留 4 个数据事件，新增 jump/branch/call/ret/extern 五个控制、调用和系统事件。投影模板语言用 schema v2，包含前缀、REX、opcode、ModRM、disp、imm、rel32 和两步序列。lower_to_core 覆盖全部 op：直通优先，4 核合成作为后备，标签回填到事件序。发射改造结束：单指令编码形态入表，序列算法保留，prologue、参数拷贝、2L 慢路径由模板解释器代码调用模板。运行时条目做最小描述，x86 ABI 一档。执行分四段 M2a-d，依赖顺序强，每段可以独立提交评审。

技术栈：Core 自举编译器（src/arch/hit/hit.cr 加 lower_to_core.cr 加 core-x86.toml、src/arch/linux/ld/instr.cr 加 elf.cr、src/compiler/corearch.cr）、Python 测试。

设计 spec：`docs/superpowers/specs/2026-09-07-hit-m2-design.md`（方案决策、第 1-3 节逐节确认、M2a-d 分段。本计划按段展开任务，执行时以 spec 为字段和接口的定义）。
