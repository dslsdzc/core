### 刀 1 · `unify_types` 的 `T?` 规则（**独立小刀**，S3 的硬前置）

- **实施点（符号锚）**：`checker.cr` 的 `fn unify_types(pattern, concrete)`：
  现行只有三条规则（`pattern == concrete` / `TYP_GENERIC_PARAM` / `TYP_GENERIC_APPLY`）；其余落
  `type_compat_strict(concrete, pattern)` 兜底。**在兜底之前**插入 `pk == TYP_OPTIONAL` 分支：
  - ① `ck == TYP_OPTIONAL` ⇒ 递归 `unify_types(内层 pattern, 内层 concrete)`；
  - ② 否则（**裸值入可选** `T ⊆ T?`——与 `tests/selfhost/test_optional.py` 的既有语义一致）⇒ 递归 `unify_types(内层 pattern, concrete)`。
- **依据（实读）**：`test_optional.py` 记载判定点「裸值入 `T?`：`type_compat_strict` 的可选目标分支」⇒
  语义**已有**，缺的只是 `unify_types` 这一层的**内层泛型代换 + 递归**。
- **影响面（必须逐处核）**：`unify_types` 全仓 **3 个调用点**——`infer_gen_call` 的实参环（S1 块）、
  `infer_expr` 内两处（S1P 实参台账所在环 + 结构体泛型字段环；行号会漂，按符号锚）。
  **⚠ 但第三点（结构体泛型字段）机制上不受本刀影响**（复核者实读，本代理已核）：该点的守卫要求字段类型节点
  是 **`EXPR_IDENT` 泛型参数**（`is_struct_generic(si, ast_int_val(dtn))` ⇒ `alloc_type(TYP_GENERIC_PARAM,…)`），
  **`T?` 字段根本到不了该分支** ⇒ **刀 1 的实际爆炸半径 = 2 个点，不是 3 个**（另 2 点：泛型实参环 + S1P 实参环）。
- **批次可切分性（复核者两向清单，本代理已核）**：**翻红面 = 0**——全仓 `[S1-ARG]` 引用**只有 `checker.cr` 自己的 `println`**（`tests/` 零引用）⇒
  **没有任何既有用例把「`T?` 恒假/误报」钉成期望值**（与 `test_diag_gate` 的 TF07 恰成对照）；翻绿面 = 本刀预期效果。
  ⇒ **本刀属行为变更，须在批报告显式登记**（不是「无行为变化」）。
- **预期效果（判据）**：
  - 正例 C6 / C7 / J / K / M 的 **S1-ARG 误报消失**（`unify_types` 回真 ⇒ 不再打点）；
  - P0 的 arg1 走 ②：内层 `T` **已绑定** `int` ⇒ 比 `type_compat_strict(dex, int)` ⇒ **假** ⇒ 打点/（刀 4 后）硬错；
  - 实例键**不得变**（C6/J 仍 `g[dex]`、M 仍 `g2[int]`、c8 的 `g2[dex]` 仍成立、`.cir` 的 `_dxsc` 仍在场）。
- **突变自证**：撤销刀 1 ⇒ 正例五例的 S1-ARG 误报复现（可判据化：断言 `[S1-ARG]` **零命中**）。
- **风险**：三个调用点语义同改；若某处依赖"`T?` 恒假"的既有行为 ⇒ 该处须单独取裁（**停条件**见 §5）。

### 刀 2 · 全线 report-only 实参通道（**零行为**；**2026-09-18 复核轮重写：不是「从零建」，是「扩面 + 接线 + 扫面」**）

- **现状（§1.2）**：通道**已存在两条**——① 文本 `[S1-ARG]`（泛型面，无门）；② **数字台账 `9917|9918`**（`infer_expr` 的 `EXPR_CALL` 分支，非泛型 + extern，`CORE_S1P=1` 门，默认位整块不执行以保零足迹）。
- **本刀的活（三件）**：
  1. **补覆盖面（M2）**：把实参台账扩到 checker 的**四个实参承载入口**，逐形态给出「打点 / 不打点 + 理由」——
     | 入口（符号锚） | 现状 | 本刀 |
     |---|---|---|
     | `EXPR_CALL`（`infer_expr` 直调分支） | **已打点**（9917/9918） | 沿用 |
     | `EXPR_FIELD`（方法 / 模块限定调用） | **未打点** | **补**（注意接收者偏移：`arg_vars[0]`/形参链第 0 位 `self`） |
     | `EXPR_ENUM_CONSTRUCTOR` | **未打点** | **补**（构造器实参位） |
     | `EXPR_AT`（内建，含 `@raw_int` 等） | **未打点** | **补**（内建面正是 TF07 的来源位） |
     ——**打点不覆盖 = oracle 盲区 = 缺陷盲区**（M2 的核心论断）。
  2. **接线**：沿用通道 2 的既有形态（数值台账、行首可锚、默认位整块不执行），**不新增 intern 串**。
  3. **扫面**：`CORE_S1P=1` 跑自源（`corec` 45 + `corearch` + `corelsp` 31）+ 语料（`tests/suite/*.cr`、`tests/probes/*.cr`）+ 探针集（§2），
     逐档计数 + 逐条清单（callee / argN / param_ti / arg_ti / 行:列）。
- **判据一律经类型引擎**（`unify_types` / `type_compat_strict`），**不自写等值判定**（沿用 S1 的纪律）。
- **oracle 是两源（M1；口径已收窄）**：
  - **源 A** = 本通道输出（覆盖面见上表）；
  - **源 B** = **bootstrap 的 `Checker warnings (non-fatal)`**（`build_selfhost_native.py` 的打印行；条目形如
    `Function f argN: expected X, got Y (in caller)` / `Function f: expected return type X, got Y`）——**§1.3 旧版把 bootstrap 判为「不可作 oracle」的论断过宽**：
    那只是**语料面**（24/35 档 SyntaxError）的结论；**对自源面它恰是天然的第二 oracle**，且是**唯一同时看到实参位 + 返回位**的读数
    （补 S1P 的返回位盲区；2(a) 批实测 330→165，残留项曾点出过 self-hosted 面静默过的 bug）。
  - **最强用法 = 两源对拍**：按 **(callee, argN)** 对齐两份清单，**差异逐条解释**（一方有另一方无 ⇒ 要么是覆盖面缺口，要么是判据差异）⇒ 把「oracle 自证」升级为**两个独立前端互证**。
  - **规模校准**：用源 B 的条数替代/校准 §1.3 的 273 代理数（它比静态扫描更贴近自源实参面真值）。
- **自证**：带/不带该通道 ⇒ ELF 与 `.ccr` 逐字节相同（抄 #121 套件 C6 的形态）。**两条前置**：
  - **① 先 `clean-cache`**（或用独立缓存目录）——暖态 `.cir` 重放会**假红/假绿**，「逐字节同」在暖态下**不成立也不证伪**；
  - **② `.ccr` 的 STR 段 = 编译期全量 interned 串**：通道若在**必经路径**新增 `str_intern`，`.ccr` 会变 ⇒ **红的是判据不是缺陷**。
    **先例就在本函数内（S2）**：`checker.cr` 通道 2 的注释逐字写着「台账**只打数值**：字符串字面量与 `type_display`
    （内部拼串）会把新串写进输出 `.ccr` 的 STR 段 ⇒ 破『产物逐字节不变』」⇒ **照抄该纪律**（同函数内既有先例，强于外部举例）。

### 刀 3 · 分类 + 豁免表（扫面产出 → **逐条报 lead 批**）

- **默认处置 = 修调用方**（lead 裁 ②）。**豁免是例外**，且必须：**① 有契约证据**（文档 / 既有测试 / 两前端对齐，
  实读给出处）· **② 逐条报 lead 批** · **③ 每条自带判据**。**禁止按名字批量豁免**（先例 = `diag.cr` 的 `diag_gate_exempt` 逐条形态）。
- 需分类的**合法形**（预判，**须由刀 2 的 self-hosted 输出证伪/证实**）：
  1. **字面量多态**：`int` 字面量 → `dex` / `dex?` / `int?` 形参；
  2. **`auto_str` 面**：**按裁 ② 拆两步判**——若它声明 `-> string` 而调用方实参确实不是 string ⇒ **真错，修调用方**；
     若它是重载/泛型助手（形参面本就多态）⇒ 另议（须给出**该面的契约证据**再谈豁免）；
  3. **内建/内建体**：`w64` / `r64` / `load8` / `store8` 等——**倾向豁免，但要先交契约证据**（文档/测试/两前端对齐），
     证据到位才进豁免表（**不允许只凭"它是内建"**）；
  4. **`never` 实参**（发散表达式：`return`/`loop`/`panic`）；
  5. **方法调用接收者偏移**（`arg_vars[0]` 是接收者，形参链含 `self`）；
  6. **extern 面**（C ABI，形参面可能无类型信息）；
  7. **变参**面。
- 产出：**真错清单**（逐条修源码）+ **豁免表**（逐条：契约证据 + 理由 + 引入批号 + 该条自己的判据）。
- **纪律**：豁免必须**逐条**，禁止"整类放行"（否则 P0 一类的真错会被整类放掉 ⇒ 假绿）。
