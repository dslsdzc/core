### 刀 1 · `unify_types` 的 `T?` 规则（**独立小刀**，S3 的硬前置）

- **实施点（符号锚）**：`checker.cr` 的 `fn unify_types(pattern, concrete)`：
  现行只有三条规则（`pattern == concrete` / `TYP_GENERIC_PARAM` / `TYP_GENERIC_APPLY`）；其余落
  `type_compat_strict(concrete, pattern)` 兜底。**在兜底之前**插入 `pk == TYP_OPTIONAL` 分支：
  - ① `ck == TYP_OPTIONAL` ⇒ 递归 `unify_types(内层 pattern, 内层 concrete)`；
  - ② 否则（**裸值入可选** `T ⊆ T?`——与 `tests/selfhost/test_optional.py` 的既有语义一致）⇒ 递归 `unify_types(内层 pattern, concrete)`。
- **依据（实读）**：`test_optional.py` 记载判定点「裸值入 `T?`：`type_compat_strict` 的可选目标分支」⇒
  语义**已有**，缺的只是 `unify_types` 这一层的**内层泛型代换 + 递归**。
- **影响面（必须逐处核）**：`unify_types` 全仓 **3 个调用点**——`infer_gen_call` 的实参环（S1 块）、
  `infer_expr` 内两处（行号会漂，符号锚 = 该函数内的两处 unify 调用）。
- **预期效果（判据）**：
  - 正例 C6 / C7 / J / K / M 的 **S1-ARG 误报消失**（`unify_types` 回真 ⇒ 不再打点）；
  - P0 的 arg1 走 ②：内层 `T` **已绑定** `int` ⇒ 比 `type_compat_strict(dex, int)` ⇒ **假** ⇒ 打点/（刀 4 后）硬错；
  - 实例键**不得变**（C6/J 仍 `g[dex]`、M 仍 `g2[int]`、c8 的 `g2[dex]` 仍成立、`.cir` 的 `_dxsc` 仍在场）。
- **突变自证**：撤销刀 1 ⇒ 正例五例的 S1-ARG 误报复现（可判据化：断言 `[S1-ARG]` **零命中**）。
- **风险**：三个调用点语义同改；若某处依赖"`T?` 恒假"的既有行为 ⇒ 该处须单独取裁（**停条件**见 §5）。

### 刀 2 · 全线 report-only 实参通道（**零行为**：不改 rc/产物）

- **实施点**：调用位点判定的**收口处**——泛型面 = `infer_gen_call` 的实参环（复用现有 S1 块）；非泛型直调面 =
  `infer_expr` 的 EXPR_CALL 直调分支（**须实读定位**：该分支即 #2026-09-16-31 批修过的「已解析直调提前 return」邻域）。
- **判据一律经类型引擎**（`unify_types` / `type_compat_strict`），**不自写等值判定**（沿用 S1 的纪律）。
- **输出**：沿用 `[S1-ARG] line=… col=… pi=… p=<pattern> a=<actual>` 一行一例（非泛型面 `pi` 即 argN），
  **不改** rc、不改产物、不写 `.cir`/`.ccr`。
- **自证**：带/不带该通道 ⇒ ELF 与 `.ccr` 逐字节相同（抄 #121 套件 C6 的形态）。**两条前置（lead 转复核者补，2026-09-18）**：
  - **① 先 `clean-cache`**（或用独立缓存目录）——暖态 `.cir` 重放会**假红/假绿**，「逐字节同」在暖态下**不成立也不证伪**；
  - **② `.ccr` 的 STR 段 = 编译期全量 interned 串**（`ccr_str_segment_trap`）：通道若在**必经路径**上新增
    `str_intern`（哪怕只是打点用的合成串），`.ccr` 会变 ⇒ **那时红的是判据，不是缺陷**；
    对策 = 通道**不得**在必经路径新增 intern（或把该档串域变化单列、与「逐字节同」判据分离）。
- **扫面产出**：自源（`corec`/`corearch`/`corelsp` 三清单 concat）+ 语料（`tests/suite/*.cr`、`tests/probes/*.cr`）
  + 探针集（§2）逐档计数 + 逐条清单（callee / argN / pattern / actual / 行:列）。

### 刀 3 · 分类 + 豁免表（扫面产出 → **逐条报 lead 批**）

- **默认处置 = 修调用方**（lead 裁 ②）。**豁免是例外**，且必须：**① 有契约证据**（文档 / 既有测试 / 两前端对齐，
  实读给出处）· **② 逐条报 lead 批** · **③ 每条自带判据**。**禁止按名字批量豁免**（先例 = `diag.cr` 的 `diag_gate_exempt` 逐条形态）。
- 需分类的**合法形**（预判，**须由刀 2 的 self-hosted 输出证伪/证实**）：
  1. **字面量多态**：`int` 字面量 → `dex` / `dex?` / `int?` 形参；
  2. **`auto_str` 面**：**按裁 ② 拆两步判**——若它声明 `-> string` 而调用方实参确实不是 string ⇒ **真错，修调用方**；
     若它是重载/泛型助手（形参面本就多态）⇒ 另议（须给出**该面的契约证据**再谈豁免）；
  3. **内建/内建体**：`w64` / `r64` / `load8` / `store8` 等——**倾向豁免，但要先交契约证据**（文档/测试/两前端对齐），
     证据到位才进豁免表（**不允许只凭"它是内建"**）；
  4. **`never` 实参**（发散表达式：`return`/`loop`/`panic`）；
  5. **方法调用接收者偏移**（`arg_vars[0]` 是接收者，形参链含 `self`）；
  6. **extern 面**（C ABI，形参面可能无类型信息）；
  7. **变参**面。
- 产出：**真错清单**（逐条修源码）+ **豁免表**（逐条：契约证据 + 理由 + 引入批号 + 该条自己的判据）。
- **纪律**：豁免必须**逐条**，禁止"整类放行"（否则 P0 一类的真错会被整类放掉 ⇒ 假绿）。

## §4 判据（**lead 更正版裁 ① + 两向钉子**；本节为现行口径）

### 4.1 pre-fix RED 证据（**弱式，只用于证明缺陷在场**）

- **弱式（固定 N=20）**：`./OUT` 连跑 **20** 次，**出现一次 `7` 即视为「未复现缺陷」**——判据必须**可失败**。
- 基线（实测）：97 次运行命中 `142` 一次、`7` 零次 ⇒ 20 次内复现缺陷为预期。
- **弱式不得用作修复后的判据**（那等于把「修好了」降级成「没观察到旧坏值」——本批正在收的那类自降）。

### 4.2 post-fix 判据（**强式；两支同档共存 = 两向钉子**）

| 支 | 探针 | 强式（全部必须成立） |
|---|---|---|
| **支 1（拒）** | 本探针 `g(1, d)`（apx） | `check rc=1` **且断言到具体错误码**（不是只断 rc）· `build rc=1` · `-o` 产物**不存在** · `<out>.ccr` **不存在** |
| **支 2（放）** | `g(d, d)`（**防误杀钉子**）· `g2(d)` · 非泛型 `dex` 形参（`g12`） | `check rc=0` · **`ELF == interp == 7`** |

- **为何必须两支同档**：只写支 1 ⇒「**一律拒**」也全绿；只写支 2 ⇒「**一律放**」也全绿。
- **支 2 的 `g(d, d)` 是当场抓出误杀的那条**（T0 实测：`[S1-ARG]` 对 `T?` 恒报，含合法调用）——**保留为钉子，不得删**。
- 支 1 无非确定问题（构建失败是确定的）。

### 4.3 机械腿（确定性；**必写两项**）

- **冷态**：跑判据前 `corec clean-cache`，**或**用独立缓存目录——暖态 `.cir` 重放会假红/假绿（§0 引
  `#2026-09-17-13` 暖态假红 · `#2026-09-17-17` 键缺分量；另见记忆条目「暖态合成串陷阱」）。
- **点名仪器**（没点名的不算判据）：
  - `corec cir <f> -o <out>.cir` 的 **`call <实例名>(…)`** 行 + **`dest=_dxsc`** 计数（调用点转换在场性）；
  - `corec cir <f> --dump-params` 的 **`PARAM <实例> p<i> <name> slot=<ti> decl=<tv>`** 行（槽型直读）。

### 4.4 腿的归属（纪律）

- **`255` 只属 interp 腿**（`interp.cr` 的 `IR_I2F/IR_F2I` 能力边界：`corec run` 无 binary64 语义）——
  **不得**混进 ELF 腿口径。
- 非确定值纪律（保留）：**任何读数进判据前须先证 N≥10 次采样稳定**；非确定值域**不适用**「禁第三态」。

5. **突变自证**（每条判据须能被下列突变变红，且**命中目标**；**两向钉子两向都要能被咬**）：
   - M-α 撤刀 1 ⇒ 正例 C6/C7/J/K/M 的 **S1-ARG 误报复现**（断言 `[S1-ARG]` 零命中 ⇒ 红）；

   - M-γ 豁免表放宽到"dex → int 一律放行" ⇒ P0 假绿 ⇒ 判据红（证明豁免表是判据的一部分）；
