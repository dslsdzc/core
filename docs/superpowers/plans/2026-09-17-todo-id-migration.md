# TODO 标识迁移：全局单调号 `#NN` → 「日期 + 序号」`#YYYY-MM-DD-N`（2026-09-17）

**缘起（数据）**：2026-09-16 一天内发生 **5 次编号碰撞**（`#74/#75` · `#79` · `#94` · `#95` · `#98`），
根因 = **全局单调编号是共享命名空间**，而各并行批在**自己的基点**上取号 ⇒ 相撞是结构性的，不是疏忽。
**用户裁决**：改「日期 + 序号」标识（本批执行）。

## 1. 新标识格式（候选与推荐）

| 候选 | 例 | 优 | 劣 |
|---|---|---|---|
| **`#YYYY-MM-DD-N`（推荐）** | `#2026-09-16-5` | 无歧义、字典序 = 时间序、与本仓既有日期体例（计划文件名/正文日期）一致、跨世纪不歧义 | 略长（13 字符） |
| `#YYMMDD-N` | `#260916-5` | 短 | 与既有 `YYYY-MM-DD` 体例不一致；世纪/人类可读性差；与 `#NN` 旧号在视觉上更易混 |

**推荐：`#YYYY-MM-DD-N`**。

**N 的分配规则（必须确定，否则同日多条会再次相撞）**：
> **N = 该条目在 `TODO.md` 中「标题行行号」的升序序号（1 起）**，在**同一创建日期**内编号。

选它的理由：① **确定性**——任何人按同一份 `TODO.md` 重算得到同一结果（不依赖提交时间/时区/并发到达顺序）；
② **可机械复跑**（判据能重算比对）；③ TODO.md 的条目基本按创建顺序追加 ⇒ 行号序 ≈ 时间序。
**新增条目**：取「当天已有最大 N + 1」；跨日自动换日期段。

## 2. 创建日期的取法（逐条可溯源）

优先级：① **标题自载日期**（本仓惯用：`（2026-09-10 …评审登记）`）——95/99 条命中；

③ 推断（本批**未使用**——上述两法已覆盖全部 99 条）。

## 表尾约定（**迁移后新增条目**；维护者 2026-09-17 跨批裁定 · 批 5 落地）

**背景（本约定要解决的问题）**：映射表原按「每条新 id 都有旧号」设计——J3 用 `max_old = max(table)`
派生覆盖上界、只数**数字行式**（`TABLE_ROW`）。**该假设从未成立**：迁移后新建的条目
（`#YYYY-MM-DD-N`，如 `#2026-09-17-4`）从来没有旧号 ⇒ 原式**必红**，且**无法用合法数据修**。

**约定（唯一合规写法）**：

| 情形 | 旧号列 | 例 |
|---|---|---|
| `#1..#101` 的历史条目 | **数字**（封存号） | `| #91 | \`#2026-09-16-29\` | … |` |
| **迁移后新增**（从未有旧号） | **`—`** | `| — | \`#2026-09-17-4\` | 2026-09-17 | 批 5（opt-dex）G3 登记 | … |` |

⛔ **禁止**往旧号列塞数字（如 `#102`）：那会凭空造出**历史不存在**的旧号，成为新的**假引用类**
——将来任何人 `grep '#102'` 都会命中一个从未存在的号（方案 1「清单槽号」已被维护者否决）。

**判据标准（J3 新形态，`tests/harness/test_todo_id_migration.py`）**：
1. **总体性不放松**：表的新 id 集合（含 `—` 行）== 标题集合；
2. 旧号列 ∈ {数字, `—`}；数字部分仍须 `#1..#101` **全覆盖**（`#66` 空号例外）；
3. 越过封存上界 `SEALED_MAX = 101` 的数字 ⇒ 红；
4. 行数自洽 + 新 id 唯一 + 行式可解析（`malformed` 捕获「行式悄悄失效」）。
**旧约定原文与「为何放松」留痕于判据文件 `j3_problems` 头注**（不静默改史）。

**关键件 = 三条突变自证（缺一不可；任一条不红 ⇒ 停、上报）**：

| 突变 | 期望 |
|---|---|
| **M-a** 删掉一行**已迁移**条目（有旧号） | J3 **红**（映射缺号 + 总体性） |
| **M-b** 把一个已迁移条目的旧号列改成 `—` | J3 **红**（`1..101` 覆盖不完备） |
| **M-c** 给 `—` 行塞一个封存上界外的旧号（`#102`） | J3 **红**（数字列受 `SEALED_MAX` 约束） |

实测（批 5，2026-09-17）：J3 PASS（旧号 100 / `—` 1 / 新 id 103 / 标题 103）+ **M-a/M-b/M-c 三条全红**
⇒ 「放松的只是行式，保护未丢」为机械证据。
