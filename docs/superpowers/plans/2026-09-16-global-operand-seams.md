## 现状根因（一句话 + file:line）

**`g2_slot`（`src/arch/x86_64/instr.cr:55-72`）对全局行返回帧外伪 rbp 偏移**（第 71 行；`v < g_current_func_var_start` ⇒ 偏移为正 ⇒ 落在**调用者帧**），而「全局 vs 局部」的分派被要求**在每个操作数消费点各自手写**（正确者走 `e2_load_var`；遗漏者直吃 `g2_slot`）⇒ 同族缺陷按 `IR_*` 分支**逐个漏**：已修 4 处（`IR_LOAD`/`IR_LOAD_FIELD`/`IR_REF` 取址/`IR_LOAD_ENUM_TAG` 读源）后，同族仍有 **6 条活点 + 1 条次序不变量缺口（B7）+ 1 条仅表实例可达（B8）**，全族后果统一为**读静默错值 / 写静默丢写 / 个别响亮 139**，且 `corec build` rc=0、解释器路径正确 ⇒ **双路径分歧**。

**结构判断（本批的立项理由）**：这不是「六个孤立的漏点」，而是「**判定散落**」——同一形态判定（`r64(g_x86_is_global, v*8) != 0`）在 int 面已收进 `e2_load_var` 单入口，dex 面（`e2_sd_*` 五件）与写侧（三处手写 rip 序）**从未收编**。只修点 = 治标（本仓已有「修 `IR_REF` 后仍漏 `IR_SLICE`/`IR_AWAIT`」的先例）。

- **残余风险（待实证）**：若任何前端路径把全局索引传给 dest（如 `IR_REF` 的 **d 侧 1110**（`&g` 存入全局指针槽）），该点即错。裁-SEAM-1 定为**只清点不修** ⇒ T1 用「全局指针槽」探针实测复核，结果回填本表。

### T2-c **B6 可达性修正：`need_pack` 掩蔽条件**（`ir_gen.cr:1927-1952`，实读）

实参块**仅在非连续时才打包**进连续 `_arg` 临时：`first_arg_var = arg_vars[0]`，逐对检查 `cur == prev + 1`；全连续 ⇒ `need_pack = 0` ⇒ **不打包**（全局实参**直达**后端）。打包支（`need_pack != 0`）逐个 `emit(IR_STORE, -1, packed, av)`——**只搬值、不换形式**（`at := irv_type(av)` 原样）。

- **`ac == 1` 恒不打包** ⇒ 单实参调用的全局实参直达 `cs_args_dispatch` ⇒ **B6(b) 的 extern 单参形 = 寻址面可达**（探针按此形设计）。
- **多实参且索引连续**同样不打包（如相继注册的全局 `g1, g2`）⇒ 全局实参直达。
- **方法调用 `s.m(g)`**：`ac ≥ 2`（接收者 + 实参；`ir_gen.cr:1779-1786` 显式前置 `self_var`，实读），接收者（局部/临时）索引与全局索引**几乎必然不连续** ⇒ `need_pack` 触发 ⇒ 实参被打包进 `_arg` ⇒ **寻址缺陷被掩蔽**（B6(c) 的寻址面可达性**大幅收窄**；仅「接收者恰为 `g+1`」的偶合形仍可达——须 T1 实证）。
- **但第二根因（转换环缺口）不被掩蔽**：打包只搬值、不换形式 ⇒ 方法调用里 apx 实参仍以 **bits** 交付，而 callee 形参侧按 `TI_DEX_S`（`ir_gen.cr:2866`）解释 ⇒ **静默值错**（与寻址无关，任何方法调用可触发）。
- ⇒ **对裁-SEAM-3 的直接影响**：B6(c) 的 RED 三选一里「响亮 139」大概率**不出现**、「静默错值」大概率**出现** ⇒ 按加硬规则 **同批修转换环**。
- **探针设计修正**：B6(b) 用**单实参 extern**（恒不打包 = 寻址面判据）；B6(c) 用**方法调用**（值面判据），并在报告显式注明「寻址面被 `need_pack` 掩蔽」。

### T2-d 转换环修法的改动面（裁-SEAM-3 ④ 的预算判定材料）

环本体 = `ir_gen.cr:1810-1841`。放开门禁**不是**简单删 `ast_kind(func_node) == EXPR_IDENT`：

- **`func_ni` 对方法调用可用**（`:1777` 由 checker 写 `ast_data(node)`）⇒ `find_func` 可解析；
- **但实参/形参对齐差一格**：`arg_vars[0]` = 接收者（`:1783`），而被调方 `EXPR_PARAM` 链**不含 self** ⇒ 环内「arg i ↔ param i」必须对方法调用改为「arg i ↔ param i-1」（须引 `is_method` 位）；
- 环只对 `ast_type_val(cpn) == TI_DEX` 的形参动作 ⇒ **非 dex 形参零足迹**。
- **初判改动面 = 单函数 ~10-15 行 + 一个 `is_method` 位**（**未超预算** ⇒ 不触发「停下报 lead」条款）；**前置 = T1 实测确认现象（静默/响亮）+ `find_func(func_ni)` 对方法调用可用性的实测**。

## 设计候选（**三条**；逐条给 改动面 / 风险 / 可证伪判据 / 与 canary 零足迹的关系）

### (i) 纯 seam 收编（**推荐主体**）
**法则**：全局/局部判定**收进单入口**，调用点只表达「取哪个操作数」，不再表达「怎么寻址」。
- **新增三个入口**（放 `instr.cr`，紧邻 `e2_load_var`；架构轴，OS 轴 `callseq.cr` 消费）：
  1. `e2_lea_glob(buf, pos, var_idx) -> int`——`lea r11,[rip+0]`（`e2_lrb`）+ `g_x86_rip_patch_*` 登记（**与 `e2_load_var` 内联段同规约：`pos+3` = disp32 位置**）；只在 `r64(g_x86_is_global, v*8) != 0` 时调用。
  2. `e2_sd_ld_var(buf, pos, xmmn, v) -> int`——全局：`e2_lea_glob` + `movsd xmm{n}, [r11]`（`F2 0F 10 /n`，ModRM `mod=00 reg=n%8 rm=3`）；局部：**现 `e2_sd_load`/`e2_sd_load1`/`e2_sd_load_x(g2_slot(v))` 逐字节原样**（三形按 `xmmn` 分派，字节 = 现状）。
  3. `e2_sd_cvt_var(buf, pos, v) -> int`——全局：`e2_lea_glob` + `cvtsi2sd xmm0,[r11]`（`F2 48 0F 2A 03`）；局部：现 `e2_sd_cvt(g2_slot(v))` 原样。
  4. `e2_sd_st_var(buf, pos, v) -> int`——全局：`e2_lea_glob` + `movsd [r11],xmm0`（`F2 0F 11 03`）；局部：现 `e2_sd_store(g2_slot(v))` 原样。
- **调用点迁移**：B1（520/521）· B2（468）· B5（1345，**改走 `e2_load_var`**）· B4（1334/1335，**改走 `e2_load_var`**）· B6（`callseq.cr:73`/`:126` → `e2_sd_ld_var`）· B7（按裁-SEAM-4）· B8（按裁-SEAM-5）。
- **scratch 寄存器安全性论证（必须写进实现注释 + 判据）**：全局形用 **r11**（与 `e2_load_var` 同寄存器）——每次 `lea` 后**立即**消费进 xmm/寄存器，**不跨指令存活**；B1 双全局操作数 = 两次「lea r11 + movsd xmm{n}」序列，xmm0/xmm1 各自独立 ⇒ **无需第二 scratch**；`e2_push_xmm0`（`instr.cr:393-398`）在 dex 栈参序列中在装载之后 ⇒ 无 r11 冲突。
- **改动面**：`instr.cr`（+4 助手、~8 调用点）、`callseq.cr`（2 调用点 + 取裁的 B7）。**零前端、零 `.ccr`、零解释器**。
- **风险**：① 助手内分支写错 ⇒ 非全局行字节漂移（**判据 = canary + 发射面 diff 直接拦截**）；② r11 存活期假设错 ⇒ 需在 T4 用「双全局 B1 探针 + 局部对照」实测。
- **可证伪判据**：① 六点探针**双路径同值**（见 §探针设计表）；② canary IDENTICAL；③ `.ccr` 四值不变；④ 全量判据集（Global Constraints）。
- **与 canary 零足迹的关系**：canary 档 `tests/suite/ptr_arith.cr` **实读无全局、无 dex**（`cat` 全文 15 行；无 `g_` 行、无 `dex`）⇒ 新全局分支**构造性不可达**，非全局分支 = 逐字节复制现状 ⇒ **预期 IDENTICAL**（仍须实测，不得只做构造性论证）。

### (ii) seam 收编 + 完备性清单/护栏（**推荐 = (i) + 本项**）
在 (i) 之上加**两层防线**：
- **完备性清单（T2 产出，入计划/报告）**：全仓枚举 ① `g2_slot(` 调用点（实读 ~50 处）② 一切直吃偏移的 `e2_ld`/`e2_st`/`e2_li`/`e2_lb`/`e2_lr`/`e2_sd_*` 调用点 ③ `r64(g_x86_is_global, ...)` 现判定点；逐条分类 = **局部专用 / 已分派 / 全局必须分派（本批迁移）/ 待实证**，**零未分类**为完成判据（照 E-2 写点审计法）。
- **突变控制**：人为把 seam 的全局分支改坏（如把 `lea r11,[rip+0]` 的登记去掉）⇒ 六点探针必红；人为把**非全局分支**改坏 ⇒ canary 必红。两向都做才证明「判据网真的覆盖本批」。
- **改动面**：+ 审计工时（零源码）；若取「护栏」则 + 一个 debug 门（**建议只做静态清单，不做运行期护栏**——运行期断言本身就在发射路径上，零足迹证明成本高于收益）。
- **可证伪判据**：清单零未分类 + 突变双向红。

### (iii) 逐点最小修（不建 seam；照 `IR_REF`/`IR_LOAD_ENUM_TAG` 先例逐点手写全局分支）
- **改动面**：每点独立手写「全局 → lea + 补丁 + 形态专属 mov」；B1 两操作数、B2 cvt 形、B4/B5 int 形、B6 两处、B8 六处 ⇒ **7-10 段近似重复代码**。
- **风险**：**漂移源原样保留**——下一个 `IR_*` 分支仍会漏；写侧三处手写 rip 序继续与读侧分家。
- **可证伪判据**：同 (i) ①②③，但**无「漏点不再生」的机械判据**（这是它被否的决定性理由）。
- **与 canary 零足迹的关系**：同为构造性不可达 + 逐字节复制 ⇒ 预期 IDENTICAL。

### 推荐 = **(i) + (ii) 的清单层**，理由
① 根因是**判定散落**（一句话根因已示），只修点是治标——本仓已有「`IR_REF` 修完仍漏 `IR_SLICE`/`IR_AWAIT`」的实证；② dex 面五件原语**从未收编**，收编后 B1/B2/B6/B7 **共用同一入口**（形态无关），B4/B5 只是「改用已有的 `e2_load_var`」——净新增代码 ~3 个小函数；③ 零足迹可**逐字节**证明（非全局分支 = 复制现状），比逐点手写更可证（每点手写 = 每点一次漂移机会）；④ (ii) 的清单层把「还漏没漏」从人眼变成机械枚举，**成本零源码**。**(iii) 保留为退路**：若 T2 枚举发现 seam 化会触及「形态专属字节」（如 B8 的 disp 参形态）而无法保持非全局行逐字节，则对**那些点**退回 (iii)。
