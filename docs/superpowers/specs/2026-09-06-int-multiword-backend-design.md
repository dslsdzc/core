# int 多字表示设计（后端表示策略 B：64 位快路径 + 溢出扩展）

日期：2026-09-06
状态：**设计定稿；M1 已实现完成（2026-09-07，实施 plan `plans/2026-09-06-int-multiword-m1.md` 六任务收官）**——add/sub 溢出全链：快路径 jo 检测 + 固定 2-limb（128 位）多字 + tagged 槽（快值/堆对象指针 + 帧 tag）+ tag 卫生 + 128 位混合算术/比较 + return 截断语义。M2 挂账清单见 §8。
关联：`specs/2026-09-06-int-unbounded-semantics.md`（语义层定稿——int = 数学整数无溢出概念，本设计是其编码层投影）、width-out-of-language 定案（编码层宽度目标自动决定）、hw-map（表示策略 = 表投影条目域）。

## 1. 定位

- **语义层零改动**：前端/图/格照旧——int 算术是数学整数（IR 无溢出概念、无宽度）
- **表示 = 后端编码层事务**：corearch 对 int 值选择投影——快路径 64 位机器字直算（零开销）+ 溢出时自动提升多字（罕见路径付费）
- 与 dex 精确两线不混（dex = 定点精确小数，另线）

## 2. 值表示（决策点 D1：槽内形态）

现状：int 变量 = 64 位栈槽/寄存器（IR 槽模型 + 分配负编码）。

候选：
- **D1a 旁路标记**：槽仍 64 位存「快值或指向多字对象的指针」+ 每 int 槽伴生 1 位 tag（在栈上按槽扩展位图/或类型区分的并行 tag 槽）——int 槽宽变 65 位等价（栈布局扩展）
- **D1b 统一指针化**：int 值一律 = tagged 指针（小整数 = 指针内嵌 tag 如低位 1 标记；大数 = 堆多字对象）——全部 int 操作走解引用（快路径损失大——违背 B 初衷）
- **D1c 双态槽 + 静态判定**：编译期区间证明不溢出的变量 = 纯 64 槽（免 tag）；证明不了的 = tagged 槽（D1a 形态）——静态分层（与图推导衔接）

倾向 **D1a/D1c**（快路径真零开销；tag 只付给推导不出的值）。**D1c 是 D1a 的子集优化**——先 D1a 全 tagged-able 槽（实现简单），静态免 tag 优化后置。

## 3. 算术指令（决策点 D2：溢出检测位置）

快路径算术须能察觉「结果超 64 位」：
- **D2a IR 层加溢出感知**：新 IR 操作（ADD_OVF 等）或算术指令带标志——语义层加东西（违背「语义零改动」精神？——溢出检测是编码层行为，IR 若承载=格层污染）
- **D2b 后端纯发射**：corearch 对 IR 算术（64 位投影时）发射「op + 溢出跳转」；溢出 → 慢路径（运行时多字例程）——IR/图零改动，纯后端
- **D2c 检查插入 pass**：后端前 pass 按区间分析插检查指令（静态可证免插）

倾向 **D2b + D2c 渐进**（纯后端发射溢出检测；静态免检由区间 pass 后置）。

## 4. 多字运行时（决策点 D3：扩展表示）

溢出后的多字形态：
- 长度前缀数组（小端 limb 数组，符号位处理）——经典 bignum
- 运算原语在运行时（rt.s/rt.cr）还是 stdlib？——编译器后端慢路径调运行时函数
- 溢出链：add 溢出 → 分配多字对象（arena）→ 存 [原值低位, 进位扩展]——多字 add 再溢出？多字加法本身可再溢出（limb 进位链）——多字对象动态增长

范围控制建议：**M1 = 单扩展字（128 位表示 = 2×64 limb 固定）**——一次溢出到 128 位足够覆盖绝大多数「差点溢出」场景；超过 128 位再报错（编码层限制抬到 128）或动态增长（后置）。固定 2-limb = 简单正确（无动态分配连锁）。

## 5. 受波及面（后端/编码层）

- 槽模型：tagged 槽（快值 64 或 2-limb 指针）
- 算术发射：add/sub/mul/div 溢出检测 + 慢路径
- 比较/转换/打印：int_str 等须处理多字（或保证打印前值 ≤64？——不：无上限语义下大值打印合法）
- 字面量：超 64 编译期常量 → rodata 2-limb 对象 + 引用（前端 lexer 守卫：不再拒？——字面量超 64 进入 IR 常量（多字表示）——IR_CONST s1 是 i64 槽装不下 128——需 IR 常量扩展（决策点 D4）或后端从字面量串重建）
- **return 出逃边界（M1 定案）**：M1 内 return-2L 到内部调用方 = 确定性截断（低 64 wrap——return 解指针取低 limb = 数学值低 64 位，非指针垃圾；调用方以 64 位快值接回，跨函数无 2-limb 协议）；全 128 return（调用方 tag 读 + 2-limb 对象传递）= M2。main → OS exit 同机制（exit 低 8 位 = 数学值低字节——M1 验证通道；全 128 断言经测试钩子 syscall3 直读 16B）
- 验证：溢出路径行为（快路径结果 = 数学结果 64 内一致；慢路径 = 扩展精确）

## 6. 决策点清单（拍板后定稿）

1. **D1**：槽内形态（倾向 D1a tagged 槽，D1c 静态免 tag 后置）
2. **D2**：溢出检测位置（倾向 D2b 纯后端 + D2c 区间免检后置）
3. **D3**：扩展表示（倾向固定 2-limb 128 位 M1——超 128 报编码层错或动态后置）
4. **D4**：超 64 编译期字面量路径（IR_CONST 扩展 vs 后端从词素重建）
5. **范围分期**：先 add/sub（最常用溢出场景）全链（发射/槽/慢路径/打印/测试）→ mul/div/比较后续
6. **D6（M1 定案，Task 5，2026-09-07）**：tagged 变量**不排除**寄存器分配——plan 原案「多字变量只栈」的动机（多字值不可驻单寄存器）被 D1a 表示消解：槽/寄存器驻留的是快值或 2-limb 堆对象指针（128 位载荷在堆），tag 为帧字节，与值形态无关；值读写单 seam g2_slot、tag 单 seam g2_tag_off（含慢路径回存/2L 块装载/return 解指针），reg 形态状态完整。O2 实证：tagged 变量（含运行时 2L 态：循环携带/参数/双对象比较）被 CAG 分配寄存器且行为全绿（tests/selfhost/test_mw_task5.py 元断言 tagged∩REG_ASSIGN≠∅ + 16B 通道）。排除零收益有代价（tagged = 最常见 add 循环行，O2 性能）。若将来引入 reg 形态不完整机制（动态 spill/驱逐）再议。

## 7. 验证

- 快路径行为不变（64 内程序逐字节/exit 一致——全套回归）
- 慢路径：构造溢出程序（大常量乘法/循环累加）断言数学正确
- tagged 槽正确性：快/慢值混用（推导不出变量 vs 推导出）交叉
- 判定/分配器适配：tagged 槽的寄存器分配（多字值不可驻单寄存器——分配器须知——决策点 D6：多字变量不进寄存器只栈？——**已定案：不排除**，见 §6 条目 6 与 plan Task 5 执行记录）

## 8. M1 完成范围 + M2 挂账（2026-09-07 收官记录）
