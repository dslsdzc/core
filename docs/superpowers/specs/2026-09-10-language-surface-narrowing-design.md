## 1. 定长数组裁决（2026-09-10 用户拍板）

### 1.1 裁决

**`[T; N]` 退役类型构造器身份；保留为「内联容量存储」表示提示**（A+B 融合）：

- **类型系统层**：`[T; N]` 不再作为类型构造器——类型相等/子类型判定不以其为成员概念；语义面归处：
  - N 元聚合 → **product 类型**（条目 8：元组/记录 = product 自动组合）
  - N 长序列 → **序列接口 + 长度值约束**（条目 8：F11 长度走 where 三档）
  - 长度入型做验证 → **图/F11 长度来源链**（比字面量构造器强——可表达依赖长度）
- **表示层**：`[T; N]` 语法保留 = **内联容量存储的表示提示**（映射参数——与 hw-map 同层；随实例选择生效/退化；非经典范式实例可忽略或另定——"内联"在量子/光学映射中未定义是正常的）
- **自举代码**：`ast.cr` 9 处 + `kernel/term_io.cr` 1 处用法零改造（它们本就是表示提示的正当消费——编译器需内联存储）

### 1.2 裁决依据（用途拆解）

| 用途 | 语义本质 | 归处 | 需要构造器身份？ |
|---|---|---|---|
| N 元聚合（矩阵/坐标/记录） | product | 条目 8 product 自动组合 | 否 |
| N 长序列 + 索引 | 序列 + 长度 | 条目 8 序列接口 + where | 否 |
| 长度入型做验证 | 长度事实 | F11/图（更强——字面量 N 表达力不够） | 否 |
| 内联存储/免分配/布局 | **经典映射性能关切** | 映射实例（表示层） | **这是真需求——但不属语义层** |
| 语法便利 | 糖 | 表示提示 | 否 |

关键判据（与宽度原则同构）：内联存储对经典机越有用、对非经典范式越无意义——正因此它不得升格为语言语义（机器形状出语言的既有原则）。

### 1.3 连带处置

- **全局定长数组 SIGSEGV**（实测：check 过/build rc=0/run rc=139——含解释器路径）：过渡期处置 = 按表示层语义修（全局内联容量 = 静态保留 N 格）或先编译期拒绝；**修复归属 = 实施批**（见 §3 波 R1）
- **checker 落实时点**：`[T; N]` 从类型判定中降格 = **接口化轮（R2）重做 checker 类型判定时自然完成**（届时不经类型相等/子类型）；R1 只做：裁决注记（ast.cr/checker 加「表示层概念」标注）+ 全局路径处置 + 语法面文档
- **表示提示机制**（提示如何被映射层消费） = 映射侧（R3/hw-map 通道）设计时定——R1 不建机制（现状语法行为不动）

## 3. 交叉执行序（前置依赖）

```
波 R1：语言面收窄批（可立即做——纯清理 + 小侦查 + 一处处置）
  ① 定长裁决注记（ast/checker「表示层概念」标注——零行为改动）
  ② 全局定长数组 SIGSEGV 处置（按表示语义修 或 过渡期编译期拒绝）
  ③ 宽度死条目移除 + `1_000` 分歧复核 + `_f32/_f64` 后缀侦查裁决
  判据：全回归 + 自举 + 词法/语法面测试（行为零变化除外——全局定长修复是行为变化,单独标注）
波 R2：接口化主设计轮（前置：R1 完成）
  类型 = 图标注 / 接口注册表（int/dex/string 原生条目）/ 检查器删特判统一查表
  / 数组 = 序列接口 + 长度 where / 泛型 = 编译期接口具体化
  —— 定长「类型身份退役」在此落实（checker 重做时自然剔除）
波 R3：映射侧（与 x86 实例化波 2/3 合批）
  hw-map 宽度显式通道 + 表示提示机制（内联容量存储的映射消费）+ 实例参数化
```

交叉点（已核）：R1③ 的词法面与 R2 的 checker 重做同文件族（parser/ast）；R2 的接口条目在 R3 的映射实例上实现；R3 与实例化波 2 是同一件事（编码层参数化）两个名字。

## 4. 挂账与不承诺

- R1 不做：表示提示机制（R3）、checker 类型判定重构（R2）、F11/where 落地（R2）
- 全局定长数组修复若改为「编译期拒绝」先行 = 过渡措施，R2/R3 后恢复完整语义
- 本 spec 不裁 `_f32/_f64` 最终归属（R1 侦查后裁）
