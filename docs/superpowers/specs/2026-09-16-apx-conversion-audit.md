**日期**：2026-09-16 · **性质**：**只读审计**（零构建、零测试运行、零源码改动）· **体例**：照 `2026-09-16-preexisting-bug-ledger.md`

## 0. 形式模型（读码）

| 形式 | 常量 | 语义 | 默认世界 |

## 3. N-3 / N-1 同族判定（**本审计最重要结论**）

**结论（修订后）：两条为**同一根因**——**前端转换环的覆盖面缺口**（两个**触发模式**）⇒ **下一批 = 一个批次**。**
（**修订留痕**：本文件首版按「N-3 = 门 / N-1 = 前后端口径交互」判**两条独立根因**；补齐 ⑦a 与 **callee 侧**读码后**据实改判**——理由见下，旧表述不静默抹去。）

**共同根因 = 转换环（`ir_gen.cr:1806-1839`）是「Core 函数 dex 实参」的**唯一**转换点**：全仓再无其它实参转换通道（转换调用点全集见 §0），而两个后端在调用边界**只做运输、零 dex 逻辑**（ELF：`callseq.cr:66-132` 按 `irv_type` 分类 + `frame.cr:115-140` 保存；解释器：`interp.cr:240-244` **按位置拷贝实参、无任何 dex 判断**）。⇒ **环漏转一个实参 ⇒ 双路径必同错**（同一个错 IR）——与 (B) 两条实测的「双路径同错」形态一致。

**触发模式 ①（= N-3）：调用形态门**。门 `:1806` 写死 `ast_kind(func_node)==EXPR_IDENT` ⇒ `EXPR_FIELD`（方法调用）整段跳过（表 A ①c）。

**触发模式 ②（= N-1）：环内逐形参的**配对/类型读取**未命中**。机理（读码判定，高置信）：
1. 环按 `ast_type_val(cpn) == TI_DEX` 决定转换（`:1821`），`cpn` 沿「下一个 `EXPR_PARAM`」前扫（`:1839-1843`，与 F4/#21 同族的形参链导航）——**若某深度的形参类型读取未命中** ⇒ **该实参不转换**；
2. 未转换的 apx 实参在**后端**按 `irv_type == TI_DEX` 被判为 **binary64 类**（`callseq.cr:71/97/99/125`）⇒ 走 XMM / **float 栈**；而 callee 形参槽恒为 `TI_DEX_S`（`:2866`）⇒
   - **主错 = 值形式**：callee 拿到 **bits**（按 scaled 读）⇒ **静默错值**；
   - **次错（可达、未实证）= 落位公式不对称**：callee 的栈参偏移**按形参序号**算（`frame.cr:129/131`：`caller_off := 16 + (pi - 6) * 8`），caller 的落栈判定**按类型类**（`callseq.cr:89-105`）⇒ 类混合时两边对「第 7 个实参是否在栈上/第几槽」可给出**不同答案**（同一实参被放进 XMM 而 callee 从栈读）。
3. **为何两路径同错**：主错发生在**前端已定的 IR**（值形式未转换）⇒ ELF 与 interp 一致地错 ✓。

**必须实测才能逐一坐实（插桩点，供下一批用）**：
- **插桩点 A（环内）**：`:1815-1843` 每轮打印 `cpi` / `ast_type_val(cpn)` / `irv_type(arg_vars[cpi])`（转换前后）⇒ 直接看**第 9 形参是否被环看见**：若 `ast_type_val` ≠ `TI_DEX` ⇒ **模式②坐实**；若 = `TI_DEX` 且转换发生 ⇒ 模式②证伪 ⇒ 转查落位公式（次错）。
- **插桩点 B（分类 vs 落位）**：`callseq.cr:66-105` 打印每实参 `irv_type(fa+i)` + 类计数 + 落栈判定；`frame.cr:118-140` 打印每形参 `pty` + `caller_off` ⇒ **两表对照**即判「次错」是否存在。
- **改写条件**：若插桩点 A 显示环**确已转换**第 9 实参 ⇒ N-1 根因回到「落位公式不对称」（与 N-3 不同）⇒ 本行改回「两条独立根因」（判据已给，可直接改）。

## 4. 优先级建议

| 优先级 | 条目 | 理由 |
|---|---|---|
| **P0** | B-2（返回）/ B-3（字段）/ B-4（元素）/ B-5（元组）/ B-6（载荷）| **静默错值 + 双路径同错**（本项目头号敌人）；全部**普通代码可达**（无需 apx 冷门语法：B-2 只要函数返回局部 apx 值）|
| **P0** | B-1（=N-3 方法调用）| 同上；`impl` 方法是主语法 |
| **P0** | B-9（=N-1 栈参）| 同上（(B) 已实测）|
| P1 | B-7（`as`）| 静默；`as` 在 dex 上的语义**未定** ⇒ 需**先裁语义**（「`d as dex` 是恒等还是转换」）再修 |
| P1 | B-8（比较）| 静默，但**派生自 B-3/B-4** ⇒ 修好聚合面后自然收敛；保留探针防回退 |

**修法方向（**已获维护者背书 2026-09-16**——理由 = 「语义保鲜」哲学：判定应以**语言层语义（声明型/签名型）**为准，不该以已降级过的 IR 值型为准）**：把「按槽位形式转换」的**唯一漏斗**收敛到 `dex_store_adjust`（`:1044`），并让**所有**写点（含 4 类聚合写 + `as` + 返回）与**读点定型**（`:2520` 等处的 `TI_INT` 硬定型 ⇒ 应保留元素/字段的声明型）都过这一漏斗；转换触发**应以「声明型/签名型」而非「IR 值型」为准**（B-2/B-9 的共同教训：值型在多处丢失或被改写）。

## 5. 边界清单外的新发现（补）

1. **聚合读的统一类型丢失**（`:2520` `new_ir_var("field", TI_INT)`；元素读同类）⇒ 是 B-2/B-8 类「转换不触发」的**放大器**（不止 dex：可选表示的 `rep`/声明面亦受影响 —— 与 (A) 批 T3 的「声明面登记」修法**正交**，勿混）。
2. **`@raw_int` 是唯一显式形式通道**（`:1703`）：所有探针的**期望值判据都应经 `@raw_int` 表达**（否则比较面自己就踩 B-8）。
3. **extern 面已排除**（①b）：apx 实参照传 = C ABI（binary64）**正确**；但 extern **返回值**在 Core 函数里 `return` 会踩 ②a（B-2 的变体）。
