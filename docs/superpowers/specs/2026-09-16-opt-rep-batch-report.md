## 2. 根因（两条，`file:line`）

1. **表示位只在直接写点置位**：`emit_rep_set` 仅在 LET/赋值/形参序言等直接写点发射；**指针写**（`IR_STORE_PTR`，`ir_gen.cr` 赋值的 `UOP_DEREF` 分支）**绕过**表示位 ⇒ 槽的表示与其值脱钩（`c3` 分歧的直接成因）。且「指针指向哪类存储」**别名不可静态闭合** ⇒ 无条件装箱会**新增**静默错值（`c1` 由正确转错）。
2. **第二根因（计划外、预存）**：ELF 后端 `IR_REF`（`src/arch/x86_64/instr.cr:1095`）对**全局**源一律 `e2_lb(g2_slot(s1))`（= `lea r10,[rbp+off]`）——全局行的 `g2_slot` 是**帧外伪 rbp 偏移** ⇒ `&g` 取**栈上垃圾地址**：写读经指针自洽（**故被掩盖**）但与全局槽**脱钩**。**冻结基线实证**：`g_mut` ELF 1 / interp 5 · `g_refread` ELF 36 / interp 1。

## 3. 修法（纯 IR，零布局变更）

- **裁-REP-1 (iii)「逃逸域化的恒装箱」**：W1 取址预扫（`g_addr_taken_names` + `optrep_addr_prescan`，收**操作数**名索引）· W2/W3 写点（赋值/LET）装箱 + **表示位钉 1** · W4 形参序言**条件装箱** + 钉 1 · W5 `IR_STORE_PTR` 按 pointee 可选性装箱 · W6 零足迹门（全部首判 `g_optrep_on`）。
- **第二根因修复**：`IR_REF` 全局源改走 `lea r10,[rip+rel32]` + RIP 补丁（照 `IR_STORE`/`e2_load_var` 全局分支先例）。
- **T3 审计证伪出的漏点（裁-T3-1）**：**推断（无标注）可选数组/切片**的元素写点不装箱（7 形态 139/139；根因 = 元素写点取**声明表**而声明表只在**带注解** LET 登记；字面量 `Some(x)` 的 IR var 是 `TI_UNIT` 占位、`IR_SLICE` 切片 var 是 `TI_INT`）⇒ 字面量**预扫数组级可选性** + 登记、切片源可选 ⇒ 登记、**LET/全局初值把值面登记继承到绑定 var**（值 var ≠ 绑定 var；写点零改动）。

## 6. 过程事故与教训

1. **工作副本 stale 事故（零损失，两次实证）**：**他方推进 op log ⇒ 别的 workspace 会 stale**；`jj workspace update-stale` 会**以 op log 重建工作目录**、**未快照文件不留痕**（首现于 T2 计划文件，造成一次重写；T3/T5 两次因**先备份到仓库外**而零损失）。**纪律**：stale 前先 `jj status` 快照，或先把未快照文件备份到仓库外；产出即路径限定提交（「未被快照的文件不算存在」）。
2. **「值面登记 ≠ 绑定 var 登记」**：T3 首版修法无效（登记落在**值 var**、写点读**绑定 var**），由突变 M_T3_3 咬出。
3. **零足迹纪律**：新增类型面查询必须先核是否 `alloc_type`（T2 曾因未门控使非可选 `.ccr` +168B）；本批全部新增面首判 `g_optrep_on` + 仅可选面登记 ⇒ canary/`.ccr` 全程不变。
