## 0. 范围与裁决

### 0.1 论题

> **汇合点的语义必须由图决定，不得由调度决定。**
> 物理到达顺序可以决定"谁来处理"，但只有两种情形合法：① 图中已**证明**该影响不可观测（`merge_deterministic`）；② 图中已**显式声明**该影响（`race` / `select_any`）。二者之外 = 隐式竞争 = 拒绝编译。

本 spec 处理的是**执行模型层**的语义：汇合（merge）这个图事件。它不碰属性轴与义务机制本身的定义（S-A），不碰报告面的 CLI 与输出契约（S-D）——只给二者的**接口需求**（§5）。

**现状缺陷（用户 2026-09-11 裁决 = 待修）**：三处文档把 `select` 的语义写成「**最早到达的令牌**」（`docs/dataflow-design.md:102`、`docs/project-book.md:241`；`docs/dataflow-design.md:61-74` 的 load_balancer 例是该语义的实例）。这是**把物理调度顺序泄进语义**——而 `docs/execution-model.md:15` 同时宣称「DAG ⟹ 依赖偏序——无反馈，确定性」。两句互相拆台：要么 DAG 的确定性是假的（汇合点可以由物理顺序注值），要么 select 的语义是错的。按共享契约 §1.4 的「不确定性 = 显式请求」，**后者是错的那一个**。

### 0.3 裁决清单（本族的定案）

- **L1 汇合点 = 图对象，四形态 = 图标注**。汇合点 M 定义为「**跨执行流 / region 汇合**的 DFNode」——**可判定判据（C3 收窄 → 收敛批 v3 语义锚，取代原「入数据边 ≥ 2」字面**与原 region 身份锚**；B-N1）**：M 的入数据边 ≥ 2 **且**至少满足其一：
  - ① **并发汇合**：M 的输入前驱之间**无依赖路径**（在数据边 / state 边 / region 迭代序的传递闭包中互不可达），**且每个前驱各自可达一个不确定源根**——**并发根** `IR_SPAWN`（`ast.cr:556` = 27）｜**迭代根**（`SG_LOOP` / `SG_FOR` 的 `nstart → exit` 序，`dataflow.cr:213`）｜**边界根**（无配方条目，memory-model 条款 4）。
  - ② **迭代汇合**：M 的输入前驱在 **`SG_LOOP` / `SG_FOR`** 上跨**迭代边界**汇合（同一节点在两个迭代上的产出）。
  - ③ **定序汇合（`merge_ordered` 候选面）**：M 的输入前驱之间存在**跨 ≥ 1 个 region 边界**的定序路径（state 边链 / region 迭代序）——M 走 §1.5 步 3 判定（**不是**「无依赖路径」那一支）。
  - ④ **边界汇合**：M 的每个输入前驱**各自可达**边界节点（无配方条目）。
  **为何从 region 身份改锚到语义（B-N1 实测，硬性）**：今日 `sg_push` 的全部产生点 = `SG_FUNC`（`dataflow.cr:473`）、`SG_IF`（`ir_gen.cr:1622`）、`SG_LOOP`（`ir_gen.cr:1693`）、`SG_FOR`（`ir_gen.cr:1751`，经 `sg_alloc_push`）、`SG_UNSAFE`（`ir_gen.cr:2158`，同）；**`SG_FLOW` 无任何产生点 ⇒ 恒不产生**（§4.2 现状断言已改）；**`IR_PHI` 今日零发射**（只被消费：`ptr_analysis.cr:310` / `dump.cr:196` / `ent_kernel.cr:369`）。而**今日并发 = `IR_SPAWN` 且 `go` 体降为独立函数** ⇒ **两路 spawn 的产出在其消费者处汇合时，两个前驱同属调用者的 `SG_FUNC`** ⇒ 原 ① 不成立、原 ② 不适用、原 ③ 恒假、原 ④ 不适用 ⇒ **执法会静默变成 no-op，而验收面察觉不到**。语义锚使该场景可判，且不依赖 region 区间细节。
  **负控**：普通直线程序的二元节点（`a - b`、`s1 + s2 + s3` 的中间节点）**与 `SG_IF` 两分支交叉**（`SG_IF` 覆盖 `[condition, merge)`，`ir_gen.cr:1622` ⇒ 分支内取值的节点与分支外的节点在 merge 后同现时前驱分属 `SG_IF` / `SG_FUNC`）**都不满足任一条件** ⇒ 不属于汇合点，不得进入 §1.5 决策序、更不得 reject（N7 两例；原字面的过捕获 = B-C3/D18）。
  **登记（不作为今日判据）**：`IR_PHI` 及将来的 phi 形节点落地后，其出现可重启为**独立充分条件**（原判据 ②）；`SG_FLOW` 若将来落地，其容器语义同样重启为充分条件（原判据 ③）。四形态**不是四个关键字**，而是 `determinism` 轴族（契约 §1.4）上的**开放标注**：`deterministic` / `ordered(src)` / `race(k)` / `any`。**命名对照**（本文两套记法同义，避免误读为八种东西）：形态名 `merge_deterministic` ↔ 标注名 `deterministic`；`merge_ordered` ↔ `ordered(src)`；`race` ↔ `race(k)`；`select_any` ↔ `any`。形态名用于论述，标注名是图上实际标注的拼写。不加关键字、不改 Graph 本体（承契约 §1.2-1「属性不升格为语言 primitive」、定案 1「类型 = 图标注」）。标注的载体与注册通道归 S-A（**存储载体随 D4 裁决：与 R2 P4 同波进 `.ccr` 段**）；本 spec 只给**语义内容**与**必填字段**（§5.1）。
- **L2 四形态的区分量 = 观测结果对到达序的函数依赖**。设 M 的语义函数 `F_M(c, π) → obs`，其中 `c` = 输入值多重集、`π` = 物理到达序（**π 不是图对象**，这是本 spec 一切定义的前提）：恒定 → `deterministic`；仅经显式顺序源 σ 依赖 π → `ordered`；依赖但**声明允许** → `race`；只声明对**来源身份**不敏感 → `any`。未证明且未标注 → **reject**（唯一执法点——**并发面**；外部不可见面的同形执法归 S-B5，§4.1 D23）。
- **L3 观测（observation）面必须先定义，否则四形态不可判定**。`obs(·)` = ① 值输出（数据边出边上的值）；② 效应（`STORE` / 通道 send / extern 调用 / `YIELD`）；③ 控制去向（后续 region 归属，SG_IF/SG_LOOP 的走向）。**唯一不在观测面内的量 = 到达位置 / 到达时刻 / 到达顺序本身**——这就是本族的去物理化操作。任何把物理序升格为可观测值的图结构（读时钟、自旋计数、原子序号、优先级抢占痕迹）都是 π 的**代理量**，见 §2.2。
- **L4 `race` 的结果集语义 = 只承诺集合，不承诺元素**。`Obs(M) ≜ { obs(F_M(c, π)) : π ∈ Π }`——**集合本身确定**，唯一的不确定是"集合内选哪个"。声明的附加义务：**集合可枚举**（或显式声明不可枚举 → 高安全模式 reject）。
- **L5 `merge_ordered` 的顺序源白名单（首版即终版）= state 边链 ∪ region 迭代序**。两者都是**图上显式对象**。**白名单外的一切"顺序"都不是顺序源**：物理时间戳、`sleep`、线程 id、就绪队列位置、声明式优先级——它们读的是 π 的代理，落 `race` 或 reject（见 §1.2 否定例）。显式序号域（用户标注 order key）**已裁（D5）：不纳入**——守零新语法，白名单不扩。
- **L6 `select` 保留关键字拼写，语义重定为 `race(1)` 的糖衣**。存量无实现（§3.1 已核实），因此迁移是**文档语义迁移**而非代码迁移。未标注的 `select` 默认结论 = 「未证明未标注 → reject」；兼容窗口 **W1 = 1 个发布周期**（D3）内降为 warning + 自动标注 `race(1)`（§3.3；strict 档 / CI 门槛窗口内不放宽）。
- **L7 自动并发只搬运已证明的 `merge_deterministic`**（承 TODO 2026-08-30 与契约 §1.4）。搬运 = lowering，须满足 §2 的全部三条检查面。`merge_ordered` 的**保序并行已裁纳入（Q5/D21）**：前置 = 两道门槛（可判定性 + 确定性判定），lowering 须证「state 边序 = 观测序」——见 §4.3。
- **L8 本族**没有** enforce 通道（定稿结论）**。确定性**不可能**运行时强制：事后检测到"结果不同"已经太晚，事前强制 = 换实现 = 改语义形态（那是 `ordered` 的事，需要用户同意）。因此本族在四档上只落 `prove` / `proof-required` / `reject`——**enforce 档空白**。**S-A §1.9 已按此裁决**：族级 policy 取 `allow_enforce=false`（隐式竞争因此固定落 ④ reject，无需改决策树）。**不得**用"插入运行时检查"充数（§5.1-(2)）。

## 1. 四形态语义（图级定义）

### 1.0 共同图模型与判定问题

| 记号 | 含义 | 是否是图对象 |
|---|---|---|
| `M` | 汇合点：**跨执行流 / region 汇合**的 DFNode（可判定判据见 L1——**语义锚 = 输入前驱间无依赖路径 ∧ 各自可达不确定源根**；非普通二元节点） | 是（`g_df_nodes`） |
| `c` | M 的输入值多重集（无视顺序） | 否（运行时值） |
| `π ∈ Π(M)` | M 的输入令牌的**物理到达排列** | **否**——不是图对象，不可读、不可命名 |
| `obs(·)` | 观测（L3）：值 + 效应 + 控制去向 | 是（出边 + state 边 + region 归属） |
| `F_M(c, π)` | M 的语义函数（图 + 输入 → 观测） | 是（图决定其形状） |
| `σ` | 显式顺序源：图上的定序对象 | 是（state 边链 / region 迭代序） |

**判定问题**：`∀ π, π' ∈ Π(M)，obs(F_M(c, π)) = obs(F_M(c, π'))` 是否成立？

**记号前提（C3 附加）**：`c` 写作**多重集**仅在「位置绑定由图固定」时充分——入边的**位置绑定**（哪个输入接哪个操作数位）由**边身份**决定（图对象），**不是** π 的一部分、也不计入 π；若某形态的位置绑定随调度可变，则该形态不在四形态管辖内（须先修本表记号）。普通二元节点的位置绑定是编译期固定的 ⇒ **不属本族**（L1 预筛拦截；D18 选项 ③ 的记号问题在此收口）。

四个形态 = 对这个问题四种**语义承诺**，其区别只在「F 对 π 的依赖被如何处置」：

| 形态 | 承诺 |
|---|---|
| `merge_deterministic` | **恒定**：F 与 π 无关 |
| `merge_ordered` | **投影依赖**：`σ(π) = σ(π') ⟹ F(c,π) = F(c,π')`，且 σ 由**图**决定 |
| `race(k)` | **集合确定**：`Obs(M)` 是确定的有限集，元素由实现自由选 |
| `select_any` | **身份不敏感**：F 只依赖"有输入"这件事，不依赖"从哪条边来" |

这四行是**语义**，不是实现建议；下文的图表示 / 判据 / 落档 / 可见性全部从这四行导出。

### 1.1 `merge_deterministic`

**图表示**：M 携带 `deterministic` 标注（或因无标注而被分析器**证明**后赋予）。要求 M 的输入集合**闭合**：所有可能到达 M 的输入边在图上是可枚举的（无"运行时新连的边"——动态图重连须先经 §2 判据）。

**判定判据（三合取）**：

| # | 判据 | 判定面 | 手段 |
|---|---|---|---|
| (a) | **无 state 边入边**：M 不在副作用链上（kind=1 入边计数 = 0） | 结构 | 分析器自动（O(边数)） |
| (b) | **无 π 代理量**：从 M 沿 def-use + state 链可达的节点中，不存在读取到达位置/时刻/顺序的量（`now_monotonic`、自旋计数、原子序号、线程 id、就绪队列位置），也不存在以"到达次数/第几个到达"为条件的 BRANCH | 结构 | 分析器自动（**π 不可命名 ⇒ 一切"序依赖"都必然经由代理量**，故本条可判定） |
| (c) | **组合函数序无关**：M 的计算在输入多重集上良定义——组合算子满足交换 ∧ 结合（+ 幂等，若存在重复到达路径） | 值 | 引擎判定（R2：类型项/形状项）；证不出 → 用户给证明 |

**判据 (b) 的可判定性论证（本族的关键结构事实）**：π 不是图对象，图上没有"到达序号"这种输入端口。因此"依赖物理序"在实践中**只能**通过代理量实现，而代理量是图上的普通节点、可被扫描。这使「隐式竞争」成为**可判定**的（而非传统自动并行化那样靠依赖猜测——TODO 2026-08-30 记的同一论据）。

**判据 (a) 的可靠性前提（已核实，硬性——假阴性风险；2026-09-11 复核，事实比初版描述更糟）**：判据 (a)「无 state 边入边」只在 **state 链覆盖全部可观测效应**时才是充分的；否则 (a) 会**假阴性**——把实际有序依赖的汇合误判为 `deterministic`。**今日不满足该前提**（C2）：
- `df_connect_state`（`dataflow.cr:160-177`）的分类表 = `IR_STORE` / `IR_STORE_FIELD` / `IR_STORE_INDEX` / `IR_STORE_INDEX_VAR` / `IR_CALL`（函数名解析不出或非纯则计副作用），**不含 `IR_CALL_EXTERN`（`ast.cr:572` = 45）**；
- 而 `fi_ispure` 的**唯一写入点**（`checker.cr:1107` 普通函数「all functions are pure」/ `:1142` extern）**值恒 1** ⇒ `dataflow.cr:171` 的 `fi_ispure==0` 判据恒假 ⇒ **除 store 家族与不可解析调用（builtin）外没有任何调用进入 state 链**（`print` / `read_file` / `chan_send` / `sched_go` 均被标"纯"）；且链**每函数重置**（`dataflow.cr:401`）。

⇒ **外部效应今日无保证的序通道**（权威事实锚点 = `2026-09-11-policy-state-version-toctou-design.md:62` 即 S-B5 §1 事实底座；其处置面在那边）。
**本 spec 对 (a) 的实施要求（保守判定，不要求改链）**：在链覆盖修复落地前，(a) 的实施必须**降级**为「显式效应清单检查」——采用**全仓唯一一份**保守清单（承 D7/D16：**效应 = 除引擎判定纯者外的一切 `IR_CALL`/`IR_CALL_EXTERN`**；**今日等价于「所有调用」**）。措辞修正：不是仅"extern + 纯度不可判"——**任何调用**（含被乐观标为纯的可解析调用）下游的汇合**不得**仅凭 (a) 判为 `deterministic`（须另有定序通道，否则落 ③/④）。方向选择理由：**误判 deterministic 是不可修复的语义错误**（报告面事后看不见），而保守只损失优化面（由报告面呈现，可查可回收）。

### 1.2 `merge_ordered`

**图表示**：M 携带 `ordered(src)` 标注，`src ∈ {state-chain, region-order}`（L5 白名单）；且图上存在从 `src` 到 M 的**每条**入边的定序见证（witness）。标注必填字段 = src 的类型 + 见证的边集。

**判定判据**：

1. **溯源**：M 的每条入数据边可溯源到一个顺序源（state 边链的链序，或 region 迭代序 `nstart → … → exit`）；
2. **全序**：src 在 M 的输入集合上是**全序**（任意两条输入可比较；不冲突、不并列）；并列时不得静默 tie-break（那会把 π 从后门放回来）；
3. **非代理**：src 是图上显式对象，**不是** π 的代理（即 §1.1(b) 的反面检查——src 自身不得含 π 代理量）。

**否定例表（必须写清，否则"优先级 select"会被误当 ordered）**：

| 候选 | 为什么不是顺序源 |
|---|---|
| 物理时间戳 / `sleep` 时长 | 读物理时间 ⇒ π 的代理 |
| 线程 id / 就绪队列位置 | 调度器内部状态 ⇒ π 的代理 |
| **声明式优先级**（"req 优先于 signal"） | 只决定**谁赢在同时就绪时**；而"同时就绪"本身由物理决定 ⇒ 仍是 π 的函数。⇒ 落 `race`（可选：优先级作为 **tie-break 规则**记录进报告，但不消除不确定性） |
| 通道 FIFO 序 | **半合法**：同一 channel 上的 send 序是图上的（生产者之间的 state 边链），跨 channel 则不是。⇒ 只在"每个输入边各自有 state 链"时可作 src |

**义务落档**：**prove**（src 全序 + F 被唯一确定）；src 存在但覆盖不全 → **proof-required**（补顺序源或补证明）。

**观测可见性**：确定。不进不确定列表；可进"已证明（顺序源：state 边 / region 序）"列表。

### 1.3 `race`

**图表示**：M 携带 `race(k)` 标注（k = 胜者数；缺省 k=1）。**必须显式**——无标注的竞争 = 隐式竞争 = reject（§3.3 窗口内降为 warning）。

**判定判据**：`Obs(M) = { obs(F_M(c, π)) : π ∈ Π }` 良定义且**可枚举**（基数已知或可静态上界），或显式声明为不可枚举（→ 高安全模式 reject）。

**义务落档**：**① prove + 报告义务**（S-A §1.9 已裁决：显式请求 = 义务已被「程序说的是它想说的」处置，**不新增第五档**）+ **报告面强制登记**（S-D）。**prove 的证明内容不是空话**——须证明「该汇合点是此处**唯一**的不确定源」（声明不得成为隐藏相邻不确定性的挡箭牌）。**证明范围已裁（D10）= 局部**：只覆盖汇合点本身；**报告面必须显式标注「该保证未覆盖观测点」**（诚实性由报告面承担——S-D §1.7.1 硬约束 9）。升档到「到观测点整条路径」为**未来候选**（若实测证明挡箭牌不足再升；只动义务范围，不返工已有判据）。

**观测可见性**：报告面**必须**列出：① race 点 id；② 输入边集；③ k；④ 结果集 `Obs(M)` 的基数上界（或"不可枚举"标记）；⑤ provenance 链（§5.2）；⑥ **prove 范围 = 局部（未覆盖观测点）**。
**禁止**：分支体把"我是第一个到达"当作**不经 witness 通道**的可读事实（例如以到达序索引写共享输出）。
胜者**身份**作为显式出参（witness）= **已裁（D9）：允许**——witness 是图上的一条**显式值边**（不是 π 代理），登记为 `EXPLICIT` 不确定源 + 报告义务；`select` 现有分支体写法（`req = recv => …` 用了 `req`）据此可平迁，`load_balancer` 例保留。

**race 不豁免确定性**：它承诺的是"**集合**确定"。把 race 读成"此处随便"是误读——`Obs(M)` 本身是程序语义的一部分，报告面要能把它列出来。

### 1.4 `select_any`

**图表示**：M 携带 `any` 标注。语义 = `obs` 对**来源身份**不敏感：分支体的观测不依赖"哪个输入先到/到了哪个"。

**判定判据（两条路径）**：

| 路径 | 条件 | 结果 |
|---|---|---|
| (i) **等价升级** | 各分支体**观测等价**（值 + 效应 + 控制去向三项等价，由引擎的等价判定给出） | 升级为 `merge_deterministic` → **prove**，零成本 |
| (ii) 默认 | 不可证等价 | 与 `race` 同：**显式不确定** + 报告面；`Obs(M) = { 各分支体的观测 }`（有限，可枚举） |

**路径 (i) 的地位（区分设计与待论证）**：【设计已定】等价即确定的推理是直接的（分支选谁都一样 ⇒ obs 恒定）。【待论证】"观测等价"的**判定能力**——R2 引擎目前判定 `ty_sub`/`ty_equiv` 等类型项，**尚无效应等价（effect equivalence）判定器**。因此 (i) 是目标形态，落地依赖引擎的效应判定扩展；在此期间 (ii) 是实际路径。**不得**把 (i) 呈现为已可用。

**义务落档**：(i) **prove**（确定性，零成本）；(ii) **① prove + 报告义务**（同 race：证明内容 = 该点是此处唯一不确定源；**范围 = 局部，D10**——报告面标注「未覆盖观测点」）。

**观测可见性**：(i) 不进报告；(ii) 进报告，附"来源身份不敏感"说明。

### 1.5 判定序（本族的决策过程）

给定 M，按下序判定，**先到先得**：

```
0. 汇合点预筛：M 满足 L1 判据（跨执行流 / region 汇合，语义锚：① 无依赖路径 ∧ 各自可达不确定源根 / ② 迭代边界 / ③ 跨 region 定序路径 / ④ 边界根）
   → 否则**不进入本序、且不做任何判定**（既不得 reject、也不得落 ③；判据不得因「根本不识别」而空过——B-N1）
   （普通二元节点与 `SG_IF` 分支交叉均不属于本族管辖——不得 reject，C3 负控 + N7）
1. 结构预筛：无 state 边入边 ∧ 无 π 代理量 ∧ 输入集闭合    → 候选 deterministic
2. 引擎判定组合函数序无关（交换 ∧ 结合）                   → merge_deterministic   [prove]
3. 顺序源 σ 在白名单内 ∧ 对 M 的输入全序 ∧ src 非代理       → merge_ordered         [prove]
4. 顺序源存在但覆盖不全                                    → proof-required（补证明/补顺序源）
5. 有 race/any 显式标注                                    → ① prove（声明与实现一致）+ 报告义务（+ 可枚举义务）
6. 其余（未证明 ∧ 未标注）                                 → reject  ← 唯一执法点（并发面；与 S-B5 的分界见 §4.1 D23）
```

**证明优先于声明（冲突规则）**：若第 2 步已证明序无关，则即使 M 带 `race`/`any` 标注，**报告面按实际分类**（= 确定），标注降级为**冗余声明**诊断（warning，非错误）。理由：报告必须显示程序**实际**的不确定性，而不是用户**声明**的不确定性——否则 `race` 会成为"掩盖本来可证的程序"的通道，与「不确定性 = 显式请求」的意图相反（请求要显式，但不得伪装）。

## 2. 物理 ⇏ 语义：降级义务

### 2.1 「引入不确定性」的判据（定义）

> **引入**：存在同一张图 G、同一输入 c 的两次执行 e₁, e₂，使 `obs(G, c, e₁) ≠ obs(G, c, e₂)`，而 `G` 上**没有**任何节点声明 `race`/`any`，**且**差异可归因于 {发射层, 调度器, 求值顺序} 三个物理面之一。

即：`∀G, c：obs(G,c,·)` 恒定，除非 G 上有对应声明。**违反 = reject**（编译错误，属"物理⇏语义被破坏"）；无法判定 → proof-required。

**本节论题句（写进实现规则）**：被限制的**不是调度器的自由度**，而是「自由度泄漏进 `obs`」。调度器可以任意选择（性能面），只要选择不影响观测。

### 2.2 三个检查面

| 面 | 检查内容 | 例子（合法 / 非法） |
|---|---|---|
| **发射层（lowering）** | IR → 机器码 / 表条目的 lowering 不得引入序依赖 | 合法：`merge_deterministic` 的 n 输入加法降低为"按寄存器分配顺序发射的链"——加法可结合，序不影响值。**非法**：把非结合算子（浮点加/乘、饱和加法、定长截断/溢出包裹、多字 tag/2L 编码下的**饱和**路径）降低为序敏感实现；或把"先到先累加、超界即截断"当作确定性汇合 |
| **调度器** | 就绪队列顺序（round-robin / work-stealing）不得成为语义输入 | 选择函数只允许读**图上声明的顺序源**（state 边就绪标记、region 迭代指针）；**禁止**用时间片计数 / 线程 id 作 tie-break 并让该 tie-break 影响 `obs` |
| **求值顺序（编译器内部）** | pass 重排 / 内联 / CSE / 寄存器分配不得改变 merge 点的输入到达集合，或引入序依赖 | 特别：LICM / 惰性下沉**不得**把带 state 边的节点跨越 merge 点移动；CSE 合并两个 race 点会改变 `Obs(M)` 基数 ⇒ 须检查 |

**这条给编译器 pass 的可陈述不变量**：每个变换都保 `obs`。原文（TODO / pass 文档）里"凭感觉安全"的表述，应由本判据替代。

### 2.3 与「部署配置不改语义」的关系

`docs/execution-model.md:19`「执行方式（串行/并行/调度策略）由部署配置决定，图语义不变」——本节的判据正是这句话的**可检查形式**：部署配置切换调度策略后 `obs` 必须不变（除已声明点）。因此本族**加强**而非削弱该原则：把"图语义不变"从口号变成合规条件。

### 3.2 迁移目标

`select { p = recv => body }` 重定为：**多输入汇合 + 内容相关分派**，其图级默认 = **未标注**。语义不再是"最早到达"——"最早"是 `race(1)` 的**实现选择**，不是**语义承诺**。

| 情形 | 判定形态 | 落档 |
|---|---|---|
| 分支体观测等价（可证） | `select_any` → 升级 `deterministic` | prove |
| 到达顺序由 state 边 / region 序固定 | `merge_ordered` | prove |
| 分支体不等价 ∧ 无顺序源 ∧ 有显式标注 | `race(1)`（+ `any` 若身份不可观测） | ① prove + 报告义务（范围 = 局部，D10；witness 允许，D9） |
| 分支体不等价 ∧ 无顺序源 ∧ 无标注 | **reject**（窗口 W1 内：warning + 自动 `race(1)`；strict 档 / CI 门槛下窗口不放宽） | reject / 窗口内警告 |

### 3.5 `select` 是否保留关键字

**裁决：保留拼写、重定语义。**

理由：① 现状无实现 ⇒ 无迁移成本（§3.1）；② 拼写保留使既有文档/示例保持可读，改动面收敛到语义段；③ 四形态**不进关键字表**（L1：形态是图标注，源码拼写由 S-A 的标注通道承载，如 `where`/annotation）——所以"保留 select"与"不加新关键字"不冲突：`select` 是**汇合语法**（图构造），`race`/`any`/`deterministic` 是**图上标注**（属性面）。

**未采用备选**：把 `select` 收编为库函数/宏（`chan.select(...)`）。理由：汇合是**图构造**而非库调用——它改变图的拓扑（多输入边汇合点），库函数无法在类型层表达"入边集合"这一图结构。

## 4. 与既有机制的接口

### 4.1 state edges（`dataflow.cr`，kind=1）

- **双重角色**：① `merge_ordered` 的**第一顺序源**（副作用链的链序 = 图上全序）；② `merge_deterministic` 判据 (a) 的**排除面**（有 state 边入边 ⇒ 不是候选确定）。
- **方向性提醒（易错）**：state 边保证的是**序**，不是**结果与序无关**。两条边的作用方向相反——`ordered` 用序定结果，`deterministic` 用"无序可依赖"绕过序。实现时不得把"有 state 边"直接判成"确定"或"不确定"，须按 §1.5 走判定序。
- 现有构件：`df_add_edge_kind`（`:136`）、`g_last_state_node` 副作用链（`:174`）、loop exit 终止依赖（`:93`）、`ESZ_DFEDGE` = 32B（`dyn_arr.cr:102`，kind 字段已在）。
- **`select` 不是顺序源**（承接 S-A §1.9 硬约束，§5.1-(5)）：汇合点的定序**只能**来自 state 边链或 region 迭代序；`select` 的"胜出边"是 `race` 的结果，**不得**回填为顺序源用于 prove（否则把"最早到达"从后门固化为证明前提）。
- **外部效应的序缺口（已核实，与 S-B5 同源；事实面比"extern 缺口"更宽，C2）**：`IR_CALL_EXTERN`（`ast.cr:572` = 45）不在 `df_connect_state` 的分类表内，**且纯度标注今日恒"纯"**（`fi_ispure` 唯一写入点 `checker.cr:1107`/`:1142`，值恒 1）⇒ **任何可解析调用**（`print`/`read_file`/`chan_send`…）同样不入 state 链（§1.1 可靠性前提）。三个后果：① `merge_ordered(state-chain)` 无法为 extern / 调用效应定序；② 判据 (a) 出现**假阴性**通道（效应无入边却被判"无副作用"）；③ S-D 的 `D_effect` 报告会显示"确定"（S-D §1.7.1 硬约束 8 已按同一保守面登记）。
  **处置**：见 §1.1 保守判定 + **全仓唯一一份效应清单**（承 D7/D16：权威面挂 S-A policy 面 / HIT 投影，事实锚点 = `policy-state-version-toctou-design.md:62`；本 spec 只引用不复制）。本 spec 不要求在 S-E 内修链（止血 = 代码级缺陷插队修；修链 = root cause，单独立项），只要求分析器在链未覆盖时**取保守方向**。
- **与 S-B5 的执法分界（D23，2026-09-11；B 线 I3 的 S-E 侧）**：本族的「隐式竞争 → reject」与 S-B5 的「外部不可见面 → 非 prove」是**同一形状**，**不得两处各判一次**——分界**按变更源身份**（唯一真源 = `policy-state-version-toctou-design.md` §2.1）：`mutator ∈ 图节点集合` ⇒ **本族**；`mutator ∈ 边界条目 / 未知 extern` ⇒ **S-B5**；**交集非空 ⇒ 先 S-B5 的保守面，本族不重复报**（恰一条诊断）。对应**交叉负控** = S-B5 §5.4；本 spec 侧只消费该定义，不另立判据（此前「本族唯一执法点」的措辞按本条限定为「并发面唯一执法点」）。

### 4.2 region（SG_* 与 `g_df_node_region`）

### 5.2 给 S-D（`core analyze --determinism` 报告面）

**provenance 链的形状要求**（本 spec 只给形状，格式归 S-D）：

```
来源节点 ──(传播)──▶ 汇合点 ──(传播)──▶ 观测点
boundary #27  →  parser  →  branch  →  output
   ↑                ↑           ↑          ↑
 外部输入面    数据边/state边   race/any    ACTIVE_OP
 (D_external)   (图传播)        标注点    (可观测)
```

即：每条不确定性的报告项 = **从源到可观测点的一条链**，链上必须标出**汇合点**（不确定性被引入/放行的位置）与**形态**。要点：

1. **汇合点是链上的检查点**，不是链的起点——起点是外部来源（boundary），终点是可观测效应。同一汇合点可出现在多条链上，报告应能按汇合点聚合。
2. **已证明的汇合不得出现在不确定列表**（§1.5 证明优先）；"冗余声明"（标了 `race` 但已证明确定）单独列一类，供用户清理。
3. 本族**必须**提供的字段（最小面）：形态 / 汇合点 id / 输入边集 / 顺序源（`ordered`）/ k 与 `Obs(M)` 基数界（`race`）/ 见证引用 / 分类（已证明 · 已声明 · 冗余声明 · 拒绝）。**落点 = S-D §1.7.1 硬约束第 7 条**（I3/D20：此前"格式归 S-D"两侧都以为对方承载 ⇒ 现指定为 S-D 输出契约的硬约束）；`冗余声明` 类照 §1.5 证明优先规则单列。
4. `boundary #27` 式的**外部输入面**（`D_external` 轴）由 S-D/S-A 定义，本 spec 只在链中引用它，不定义它。
5. **边界节点与本族的显式标注并列（D19）**：边界节点（`unsafe` / FFI / 输入 / 测量，清单口径归 S-D O11）本身就是一类**合法的显式不确定源**——主人 = **边界节点 id**，链状态 = `EXPLICIT`，与 S-A 的轴标注登记**并列**，**不因「无标注」降为 `UNKNOWN`**。
6. **局部 prove 的呈现义务（D10）**：`race` / `select_any` 的 `EXPLICIT` 项**必须**标注「该保证未覆盖观测点」（prove 范围 = 局部）。

| N6 | **判据 (a) 假阴性**：`IR_CALL_EXTERN`（不在 state 链上）**或任何被乐观标为纯的可解析调用**（`print`/`read_file`/`chan_send`…——C2）下游的汇合 | **不得**仅凭"无 state 边入边"判为 `merge_deterministic`——须按 §1.1 的保守判定落 ③/④（除非另有定序通道）。**这是"宁可保守"的执法点**：误判确定 = 语义错误，且报告面看不见 |
| N7 | **过捕获负控（C3 + B-N1④）**：① 不含并发 / 循环的直线程序的普通二元运算（`a - b`；`s1 + s2 + s3` 的中间节点）；② **`SG_IF` 分支交叉**——分支内取值的节点与分支外取值的节点在 merge 后同现（`SG_IF` 覆盖 `[condition, merge)`，`ir_gen.cr:1622`，故前驱分属 `SG_IF` / `SG_FUNC`）；③ 同一例但**包在 `SG_LOOP` / `SG_FOR` 内**（迭代根可达 ⇒ 判据 ② 会命中）——预期与 ①② 相同 | 三例均**不得**进入 §1.5 决策序、**不得** reject、**不得**落 ③；其组合函数无需交换 / 结合证明（L1 预筛步 0 拦截）。③ 是**边界探针**：若实测落在 ③/④，须登记为 L1 判据 ② 的过捕获并把「迭代根」限定为「**跨迭代**（同一节点的两个迭代产出）」而非「在迭代内」 |
| N8 | **保序并行门槛（D21）**：`merge_ordered` 并行 lowering 未证「state 边序 = 观测序」即分派 | 该次分派**非法**——不得仅凭依赖门搬运（两道门槛） |

### 6.3 判据的表述原则（**本族的方法论立场**）

- 一切判据表述为「**图 + 输入 → 观测**」，**不得**表述为"运行 N 次结果一致"——后者是**概率证据**，不是判据（承契约 §1.2-3「义务不静默」：判据不得靠采样）。
- **判据必须非空可测（B-N1 新增，规范性）**：正控与负控都**必须**断言「本族识别出的对象（汇合点 id）出现在报告 / 诊断中」——否则判据在「**根本不识别汇合点**」时**空过为真**（正控全绿、负控不触发），执法静默退化为 no-op 而不被察觉。字段面借 S-D §1.7.1 硬约束 7（形态 / 汇合点 id / 输入边集 / …），本 spec 不另立格式。
- N5 的"双调度对拍"是对**判据"的实证手段**（用于在实施早期捕获 §2 违规），**不是**验收判据本身。两者不得混同——这条要在实施批的测试设计里写明。

## 7. 不承诺

逐条对齐共享契约 §1.3 的三类不可消残留（本族落在哪里）：

1. **错误 specification**：本族证明的是"汇合与调度无关"，**不是**"用户的 `race` 声明是合理的"。`race(k)` 的内容（此处允许竞争是否满足需求）是**需求层**的事，语言只保证它被显式化并进报告。⇒ 本族不承诺"程序的所有不确定性都是可接受的"。
2. **恶意 / 失陷外部实体**：外部输入本身的不确定性（`D_external`）**不由本族消除**。本族承诺的是：外部不确定性**进入图之后**不得被放大为隐式竞争，也不得被悄然隐藏（必须出现在 provenance 链上，§5.2）。恶意来源可以通过 boundary 提供的时序影响**哪些** race 结果出现——本族不证明其结果集之外的任何事情。
3. **需求本身允许危险行为**：**并发竞争本身可能正是需求**（负载均衡器抢单、超时竞速、取消传播）。本族**不禁止竞争**，只要求它**显式**（`race`/`any` 声明 + 报告 + 可枚举义务）。与 §1.3 的对应：本族做的是"把能力与它的代价同时写进图"，而不是禁止能力。

**本族另外明确不承诺**：

- **不承诺"Core 程序无数据竞争"**——那是内存模型面（arena/region 隔离、借用检查）的事。本族只管**可观测语义序**，不管字节级并发访问。两者**不互相蕴含**（隔离的内存上仍可有汇合语义的不确定；反之亦然）。
- **不承诺 `race` 的结果集在跨机器 / 分布式执行下可枚举**——那是 `D_mapping`（跨机器语义确定性）面，与 S-C / S-D 的衔接点。**语义 ≥ 映射**：映射换而集合语义不变，但**集合的具体元素分布**是映射的事。
- **不承诺代价模型**（并行是否值得）= S-C。

## 附录 B：术语速查（本族新增，不覆盖契约术语）

| 术语 | 定义 |
|---|---|
| **汇合点**（merge point） | **跨执行流 / region 汇合**的 DFNode（L1 收窄判据；非普通二元节点） |
| **到达序** π | 输入令牌的物理到达排列；**不是图对象**，不可命名 |
| **π 代理量** | 任何把物理序升格为可读值的图结构（时钟、自旋计数、原子序号、线程 id、优先级抢占痕迹） |
| **观测** `obs` | 值输出 + 效应 + 控制去向；**不含**到达位置/时刻/序 |
| **顺序源** σ | 图上的显式定序对象：state 边链 / region 迭代序 |
| **结果集** `Obs(M)` | `{ obs(F_M(c,π)) : π ∈ Π }`——race 承诺此集合确定 |
| **隐式竞争** | 未证明 ∧ 未标注的汇合 ⇒ reject |
| **物理⇏语义** | lowering / 调度 / 求值顺序不得把物理序泄漏进 `obs` |
