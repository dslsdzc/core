# 消息边界拷贝消除

日期：2026-09-04
状态：设计定稿（待实现）
关联：`docs/concurrency.md`、`docs/superpowers/specs/2026-07-30-concurrency-design.md`（本文修订其「值拷贝语义」条款的表述，可观察语义不变）、`docs/memory-model.md`（推论 A/B、消息区域、字节权限层）、`docs/pointer-model.md`（地址 = 映射）、`docs/memory-model-capability-lattice.md`（v4：规则封闭对象开放、无格承诺、M1 身份还原）

## 背景与问题

并发模型：goroutine 各自独立 arena，无共享可变内存，channel 边界传值。`2026-07-30` spec 将 channel 边界写为「永远拷贝值」——跨边界数据在接收端区域重建。这带来两个难点：

1. **成本**：消息是图结构（含指针），拷贝需要逐对象复制 + 指针重定位，且无法覆盖环与共享子结构的高效复制；
2. **表达力**：无配方条目（§5.3：句柄、外部资源、神谕结果等不可重算结构）无法通过重建材料跨边界。

本文目标：**在并发模型不变的前提下消除这两个难点**——不引入共享可变内存、不引入用户标注、语义保鲜线不动。

## 设计原则

1. **两层纪律**：语义本体只陈述于图的关系层面（条目/配方/共存/可能关系），经典惯例（arena、地址、memcpy、锁）一律作为映射实例参数存在——范式无关，与 capability-lattice v4 的「规则封闭、对象开放 / 无格承诺」一致。
2. **语义本体不动**：边界公理（下）是验证器唯一依据；本文不修订它，只修订「物理拷贝是唯一实现」这一条款的表述。
3. **标签永不失语义**：三个边界标签的义务不成立时静默落回 COPY——COPY 永可行。分析不精确只亏性能，永不产生假编译错误。

## 边界公理（语义本体，验证器唯一依据）

1. **接收侧**：接收条目与发送侧条目配方同源，是可独立读写的等价条目；
2. **发送侧**：发送者的条目在发送之后继续有效，任何后续读观察到发送时刻的状态。

> 修订说明：`2026-07-30` spec 的「channel 边界永远拷贝值」是实现条款；边界公理才是语义条款。本文以标签化实现替代「一律拷贝」，可观察语义不变。

## 语义层：边界标签与关系句义务

### 边界

执行边界 = 需要跨执行体传递条目的位置：channel send/recv、go 参数、yield 输出、flow 返回值。

### 标签（子区域粒度）

判定粒度 = **消息子区域**，不是整消息：闭包内每个材料子区域独立判定，一次边界携带一张**子区域标签表**——每子区域一个标签 ∈ {COPY, MOVE, SHARE}，另附身份重指表（见「无配方条目」）。整消息单标签只是全部子区域同标签的简并情形；子区域间义务互不牵连——大载荷子区域可 MOVE 而头结构子区域可 COPY，物理上只重建必须重建的部分。

| 标签 | 义务（关系句，对该子区域的条目闭包） | 发送侧仍可 | 接收侧可 |
|---|---|---|---|
| **MOVE** | 发送点之后发送侧与消息条目闭包无「可能读」 | —（无读） | 读 + 写（唯一持有） |
| **SHARE** | 发送侧此后无「可能写」∧ 接收侧无「可能写」 | 读 | 只读 |
| **COPY** | 无（义务即公理本身） | 一切照旧 | 一切照旧 |

判定顺序：先 MOVE（读集为空），再 SHARE（双侧写集为空；若连读都没有，MOVE 严格更优），否则 COPY。

「此后」陈述于图的序关系（发送节点在图上的后继可达域），不依赖全局时间——非经典范式无全局序时，标注随图结构走，由该范式自行映射。

### 归属与寿命

- **COPY** = 双 home：双方各执材料，配方同源（再生等价）；
- **MOVE** = home 迁移：材料随条目身份走；
- **SHARE** = home 常驻出生侧：接收侧只读可能关系指向同一材料；材料寿命 = 两侧共存区间上限（图活性，非 LIFO——memory-model 推论 A）。

### 无配方条目（身份重指）

无配方条目（不可重算，必须有 home、驱逐必写回，§5.3）**永不重建材料**——重建材料 = 重跑产生源 = 语义漂移。跨边界只传指认：

- 身份 = 图节点身份（M1 定论，零新概念）；
- 跨边界 = 可能关系重指：访问可能关系从发送侧条目转移到接收侧，或复制只读指认；
- 授权（consult/assume/measure 等）归治理层，是可能关系标注，非语义本体；
- 复合消息 = 材料部分按 COPY/MOVE/SHARE 判定 × 无配方成员一律进身份重指表；
- 重指表是编译期静态内容，不落运行期；
- 三个标签对身份条目无差别（COPY 也不复制它）——身份成员不参与 COPY/MOVE/SHARE 判定。

channel 本身是执行体间唯一特许共享对象（运行体通过它通信），其内部同步归属自身，不因本文新增。

### 语义保持定理

义务成立 ⟹ 标签实现与 COPY 观察等价。错误形态唯一：标签声称 MOVE/SHARE 而义务关系句不成立 = 分析不健全 = 编译器 bug，不是用户错误。

## 经典映射实例（经典行）

本章全部内容都是映射参数；其他范式行消费同样的标签与义务，映射到各自机制。

### 1. 判定实现

**结构约束（confinement by construction）**：逃逸到执行边界的分配，在 IR 区域指派阶段放入**消息子区域**（独立子区域、分档 bump、闭包自含、唯一外部入口——标记值/句柄结构）。约束是结构性的，不需要后验证明；消息混入普通区域分配时自动落 COPY。

**义务推导**：可能读/写关系 = HDFG 上别名分析（PointerAnalysis）+ 发送点前向切片 + RegionCheck 序关系的保守近似。过度近似 → 更保守标签 → 只亏性能。

**代价**：全部编译期（区域指派一遍数据流分析 + 每边界一次前向切片，稀疏图线性量级，可增量缓存）；零运行期——标签是边界标注，编译期消费。

**精度分级（工程路线）**：义务推导先保守后精确——第一版用现有别名分析 + 前向切片；后续按域敏感/路径敏感的稀疏指针分析逐步收窄过度近似，提高 M/S 命中率、压缩 COPY 闭包。每一级精度只改变「少亏多少性能」，不改变正确性边界。

### 2. 物理机制

**基址相对表示（MOVE/SHARE 的 O(1) 前提）**：arena 内部指针 = (基址, 偏移)。这是映射实例选择——语义层 (条目标识, 偏移)（2026-08-15 地址 = 映射定稿）一字不动。跨 arena 引用保持绝对句柄 + outlives 判定。块搬迁 = 换基址生效，零遍历。

- **MOVE 兑现**：提交点 = channel 入队成功（此前仍归发送者；channel 满阻塞期间不碰块）→ 摘除消息子区域 → 接收侧挂入自身 arena 池（换基址）。队列中的块无归属 = 落在 channel 自身临界区内，无新增锁。
- **SHARE 兑现**：发送侧 `drop_perm` 收窄到 Readable（字节权限层已有）+ 区域引用计数；任一侧区域重置前递减，归零归还池。冻结是**永久单向门**（Pony/Verona/Gordon 文献一致结论；无解冻）。多核并发读零同步。
- **COPY 兑现**：接收端重建材料 = 连续块搬移（消息子区域保证连续）+ 新 home 注册；环与共享子结构天然保持。无配方成员不复制——分析期自动升级进身份重指表。
  - **物理分档**：重建材料不必全量即时。小载荷（子区域 ≤ 阈值，如 4KB）走 eager memcpy——fault 开销摊不薄时不进页机制；大载荷且双侧「可能写但预期少写」走 **COW 页共享**：同一物理页映射进两个 arena 的虚拟地址（基址相对表示使双映射成立），初始双侧只读，任一侧首次写触发页分裂、复制该页后放行。
  - COW 的语义仍是 COPY，不是 SHARE 的偷换：SHARE 静态禁止接收侧写，COW 允许写、只是推迟付账——两侧各自写、各自分裂，最终是两个独立 home。
  - 模型不破：任意时刻每个物理页要么单侧可写、要么双侧只读——「无共享可变内存」在字节层面逐瞬间成立；多 M 安全（页权限由内核强制）。
  - 分档阈值与 COW 启用策略是映射实例调优参数，不进语义层。
- **区域池复用**：MOVE 出去的块经接收者用完归还池；1:1 稳态管线自动呈现双缓冲形态——角色随所有权转，不随编号固定（双缓冲/乒乓缓冲是本文机制在 1:1 稳态下的特例）。
- **调度交互**：不新增切换点类别（沿用 channel 满/空阻塞）；wait 队列等的是 G 不是块；channel 关闭时队列中的 MOVE/SHARE 块走同一条归还路径。

**跨区域引用边角**：消息闭包含指向发送者其他区域的可达引用时——被引区域无其他存活引用 → 级联 MOVE（闭包整体迁）；否则落 COPY。

### 3. 身份传递实例

channel 套 channel、传文件句柄：传标识符（指向特许共享对象的引用）+ 授权标注副本。身份可多份指认（只读共享）→ fan-out 广播引用合法。

## 验证与错误处理

### 语义层

`.corespec` 写边界公理 + 三个标签的关系句义务。验证器消费图标注，检查「标注 vs 义务」一致性——不证明物理物化本身。义务可成为规格断言。

### 经典实例层

- 编译期自检：义务自动推导 + 标注一致性自检（与 regalloc 判定同构：checker 实现期自检 + 规约双层消费同一规则）；
- 消毒模式（可选）：MOVE 后发送侧块所在页降权为只读，误写触发 fault——把分析 bug 变成运行期可抓的崩溃而非静默损坏（字节权限层已有降权机制）；
- 测试面：环、别名逃逸、跨区域引用、关闭 channel、混合身份消息、fan-out 广播、级联 MOVE——每项 = 标签 × 义务配对用例。

## 不做的事（YAGNI）

- 无解冻（冻结永久单向门）；
- 无用户标注（全部推断）；
- 无运行期标签分派（标签编译期消费）；
- 不新增共享可变内存类别（channel 仍为唯一特许共享对象）；
- 不改并发模型（go/flow/yield/await、arena 隔离、channel 传值）。

## 开放问题（实现前收敛）

1. 闭包 = 可达关系传递闭包的精确化：按 region 边界截断还是按 points-to 全图？倾向：消息子区域结构边界截断，跨区域引用显式清单；
2. 级联 MOVE 的判据细节（被引区域「无其他存活引用」如何保守判定）；
3. 基址相对表示的迁移成本评估：现有 ELF 后端绝对指针的改动面；
4. 区域池复用策略（池容量、归还时机）；
5. 消毒模式的默认开关策略；
6. COPY 物理分档阈值：eager vs COW 的分界、子区域大小分布调优；
7. COW 的 arena 支撑：页对齐子区域、双映射与页分裂路径（fault 处理）、与消毒模式（MOVE 后降权页）的机制共享与冲突检查；
8. 子区域标签表的编码与边界描述符布局（材料标签 × 身份重指 × 子区域句柄）。
