# 硬件接口表

## 概述

硬件接口表（HIT）是运行时唯一的平台依赖。`corearch` 除优化外没有平台代码，指令发射、运行时资源和系统边界全部查表。

替换表就更换目标平台或范式。同一份 Core 程序配不同的表可以直接运行。

命名使用“接口表”，不使用“映射表”。接口是语义契约，实现是范式投影。映射暗示经典绑定，接口表明范式无关。

设计状态：设计定稿。M1 最小核已完成；M2 全表驱动暂停，表数据已迁到架构轴。实施记录和 crasm 取代说明见 `docs/superpowers/implementation/2026-09-05-hardware-interface-table-audit.md`。

## 最小核

底层实现四个接口事件即可运行 Core。其余语义由编译器合成或使用扩展事件。硬件内部实现自由，契约只约束对外暴露的部分。

| 事件 | 语义 |
|---|---|
| `sub` | 算术完备单点。加法是 `x - (0 - y)`，比较使用差符号 |
| `nand` | 逻辑完备单点。全部布尔运算可以组合得到 |
| `load` | 效果事件，读世界，外部状态进入值流 |
| `store` | 效果事件，写世界，值流写入外部状态，state edge 的落点 |

事件签名没有宽度、没有寄存器、没有寻址。图边已经包含搬运，Core 不需要 mov 类事件。宽度和形状归投影。

可合成的操作全部落为扩展事件，例如 add、mul、div、移位、逻辑、比较、分支和调用。合成代价属于编译器问题，不属于契约问题。

## 表结构

### 事件条目

```text
event_id        最小核固定 1 到 4：sub=1 nand=2 load=3 store=4，扩展从 5 起
签名            输入角色数、输出角色数、副作用类（纯、effect、volatile）
语义定位点      指向规约层的可选引用
```

签名只描述接口，不描述实现。任何范式的投影都是“这个事件在范式里如何实例化”。

### 投影条目

```text
event_id -> 范式实例描述

经典离散         编码规则，例如 ISA 模板或编码序列
通道类范式       外部通道映射，接通
连续或量子类     动力学元件描述，演化
无实现           条目缺失，编译期拒绝或走 unsafe 外部入口
```

投影不一定编码成字节。投影是事件到范式资源的实例化，经典行恰好是 ISA 编码。

### 运行时条目

运行时资源也是表条目。换表即可更换 ABI 和运行时：

```text
调用资源       call 和 ret 机制，例如栈约定、续体或通道
存储资源       load 和 store 的地址语义，例如线性内存、区域或通道寻址
系统边界       extern 和入口点约定
宽度和形状     事件没有宽度，投影在这里声明整数如何落到机器字
```

优化不走表。寄存器分配、调度和 CSE 的判定在格形态层。表只描述材料，不描述放置策略。

## 大表

最小核之上，大表是平台的完整事件目录：

```text
1 到 4      最小核，必须
5 以上      扩展事件，可选加速或平台能力
            add sub mul div shl shr and or xor not cmp select const
            branch call ret atomics vector float extern
```

程序只使用最小核时，任意表都可以运行，这是可移植子集。程序使用扩展事件时，表必须包含对应投影。查表缺失时编译期拒绝，或者由编译器降级合成。

表是编译器与平台的能力协商面：`corec` 产出的事件不超过表，平台保证运行。

## 合成层

Core IR 操作合成为表事件：

- 编译器持有降低规则，例如 add 降为 sub 反减，and 降为 nand，移位降为重复，常量使用图常量注入。
- 表声明扩展事件时，优先直接发射；没有表项再合成。
- 合成层位置可以在 `corec` 的 IR 层，也可以在 `corearch` 读表后。倾向 `corearch`，因为表属于运行层，降低随表走，换表即换合成策略。

## 边界

- 优化不进表。判定和分配属于格形态层。
- 本设计不定义“图执行契约”。范式无关保证在图层，由验证清单承接。
- 合成规则的完备性证明，即一切 IR 操作可以降到四个核事件，属于验证层事项。实施期用快速验证和回归实证。

## crasm 取代

独立 `.crasm` 格式取消。HIT 框架下的替代：

| crasm 诉求 | 替代 |
|---|---|
| 跨平台统一汇编 | HIT 事件加投影表，换表即换平台，没有中间汇编语言 |
| 无限虚拟寄存器 | 寄存器概念取消。图边包含搬运，值是流引用 |
| 平台映射表 | HIT 投影条目，编译器和手写共用一张表 |
| 特权指令固定集 | HIT extern 和接口事件加 `.cr` 的 `unsafe`，不预绑硬件 |
| 寄存器生命周期验证 | 验证上移到图和格框架，值流没有生命周期问题 |

内核路线的汇编级需求等于 `.cr` 的 `unsafe` 加 HIT 接口事件。事件层的可读形态是 `.ccr` 的 NOD 文本转储，属于工具，不是语言。
