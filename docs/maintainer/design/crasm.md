# .crasm 统一汇编抽象层(已废弃)

> 定位:受众 = maintainers;状态 = **deprecated**(2026-09-05);真源 = 本页 + 下方链接。
> 本文为废弃收尾页——是什么/为什么废弃/去向;设计细节(统一指令集、特权固定集、
> 寄存器生命周期规则、硬件描述表、里程碑)不再保留,历史正文见 git 历史。

## 是什么

`.crasm` 曾是 Core 的汇编层设计:跨平台统一指令集 + 无限虚拟寄存器(`%0/%1`)+ 平台映射表,
为内核路线(MMIO、特权指令、中断)提供受控汇编入口,并刻意"难写"以限制汇编程序规模、
保障可验证性。设计于 2026-08-08,2026-08-09 定稿,从未实现。

## 为什么废弃(2026-09-05)

- **绑定经典硬件过深**:寄存器/寻址/ISA 助记符/私有平台映射表——把"汇编"概念做成了
  新格式,但汇编本质是机器码的文本投影,不值得一套独立语法
- **与 .corespec 同构问题**:独立格式 = 真源扩散(lexer/parser/ebnf/后端各维护一套),
  与同期 .corespec 退役(见 ADR-0001)是同一个决策模式

## 去向(能力被谁吸收)

- 跨平台 = 硬件接口表(HIT)事件 + 投影表
- MMIO/特权/中断 = `.cr` unsafe + HIT extern 接口事件
- 事件可读形态 = v6 NOD 文本 dump
- 详细设计:`docs/superpowers/specs/2026-09-05-hardware-interface-table.md`
