# 执行标注空间

执行标注空间定义图上的环语义、超图灵结构、模糊语义和共归纳语义。它只描述语义，不规定执行方式。执行和验证按层分配。

## 环语义：迭代与一致解

图上的环有两种语义，由标注区分：

```text
ITER  = 迭代语义，当前实现。SG_LOOP，因果循环，每一圈发生在下一圈之前
FIXPT = 一致解语义，非因果环。环上算子的不动点，值使环自洽，不按时间迭代
```

FIXPT 对应图上的 μ 和 ν 算子，即 Knaster-Tarski 最小不动点和最大不动点。验证内核已经有 W 类型和不动点理论，这里是它在图上的表示，不是新理论。

验证约定是不动点性质：可以证明“这个值是不动点”。计算在外，健全性在内。

执行方面，FIXPT 环当前没有后端。计算不动点在最坏情况下是 PSPACE 难。区域是声明性的，执行后置，与规约层相同。

设计依据是 Deutsch 的 CTC 一致性条件（1991）和非因果图灵机（arXiv 1601.06522）。非因果计算的标准图描述就是环加不动点语义。未来范式的建模细节不在本文件范围内。

## 超图灵结构

超图灵计算指图灵可计算以上的计算。描述接口不新增图结构，只使用标注空间：

| 结构 | 标注 | 含义 |
|---|---|---|
| Oracle 节点 | 节点加任意决策函数 | 节点计算函数 F，F 可以不可计算。对应图灵 1939 年的 oracle，跳变层级为 ∅、∅′、∅″ 等 |
| 超限循环 | FIXPT 标注加序数深度 | 对应无限时间图灵机（Hamkins 和 Lewis，2000）。序数时间计算，极限阶段使用 limsup 规则 |
| 连续节点 | 实数语义标注 | 对应 BSS 机器（Blum、Shub 和 Smale，1989）。精确实数运算，无限精度 |

执行属于物理问题，不在本框架范围内。Zeno 机器的能量发散、BSS 的无限精度不可验证、无限时间图灵机是超任务，物理可实现性都没有证实。

验证方面，oracle 节点不可验证，走例外通道，与 `unsafe` 同层。验证侧的对应物是 ω 规则，内核理论已经包含。

标注空间的职责是让图今天就能描述这些结构。执行和验证按层分配。

## 模糊语义

模糊语义使用格值隶属度，不用二值结果。

```text
FUZZY 标注
  图结构：通用形状加加权分支。IF 不二分，两路都执行，按隶属度加权汇合
  语义：格值隶属度 [0,1]，加 t-范数、余范数和蕴涵
        使用剩余格代数，可选 Lukasiewicz、Gödel 或 Product 三种基本 t-范数逻辑
  验证：分级蕴涵，“公式以程度 d 成立”，做定量验证，不做二元验证
  执行：dex 或 apx 数值实现，使用精确小数或近似授权
```

模糊和概率是两套语义。概率是可加测度，属于测度论。模糊是格值隶属度，属于格论，使用 min 和 max 结构。

模糊没有专属硬件。历史上的模糊芯片（Fujitsu、Togai，1980 到 1990 年代）已经停产。模糊没有物理动机，执行方式是通用设备上的软件实现，与概率相同。语义标注的价值不依赖专属硬件。

存储侧对应关系：FIXPT、oracle、BSS 和模糊融合都是图内不可重算条目，即 `recipe = unrecomputable`。统一规则见 `docs/academic/cache-semantics.md` 的规则 4b 和 2′：必须有 home，移除必须走 `PreserveRequiredState` 分支，身份等于图节点。规则不按范式枚举。寄存器分配侧见 `docs/maintainer/design/regalloc-cache-mapping.md`。

## 共归纳语义

共归纳语义不是预留接口。今天的同步数字硬件都使用这种语义。每一块同步数字电路都是余归纳流机器，时钟对应流步。工业先例是 Lustre 和 SCADE，用于 A380 飞控、地铁信号和 DO-178C 认证。Vélus 验证编译器使用 Rocq 余归纳流，覆盖 CompCert、汇编和机器码验证。

```text
CORE 标注
  图结构：环加 ν 语义，即最大不动点，属于 FIXPT 的 ν 侧
  语义：终余代数。流是 F X = D × X 的终余代数
        双相似是观察等价，属于共归纳外延性
        非良基集合使用 Aczel AFA，超集 Ω = {Ω}
        典范模型 Vc 是可及点图的商，非良基集合就是图模双相似
        保护递归使用 ▷ 算子和 Löb 不动点，保证生产率
  验证：共归纳可验证，使用双相似证明，内核提供 ν 机制
        保护递归使每个有限前缀在有限时间内可计算，在余代数意义上是良基的
        这不是例外通道，与超图灵不同
  执行：存在映射，包括同步硬件、SCADE 和数据流加速器
```

与既有框架的衔接：

- I/O 转导器就是 `CoNode (S -> T × S) × S`，I/O 抽象已经是共归纳语义。
- FIXPT 的 ν 侧，即最大不动点和双相似，已经在环语义中定义。
- 验证内核的终余代数和 W 类型对偶提供 ν 机制，共归纳验证可以直接使用。
