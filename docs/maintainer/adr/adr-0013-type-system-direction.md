# ADR-0013: 类型系统方向 14 条定案

- 日期:2026-08-30(v2 备忘定案)
- 状态:accepted(方向定稿,实施分步)
- 决策者:DslsDZC

## 背景
类型系统需要总体方向:类型推断强度、借用/可变性语义、显式边界语法的取舍长期有分叉讨论(图本体 vs 传统类型层)。

## 决策
- 方向总纲:**图本体 + 接口统一**——类型推导建立在图结构上
- 14 条定案要点:自动推导全量(用户零标注默认)+ 借用收缩(borrow 语义收窄)+ 声明式边界(显式边界语法按需)
- **宽度类型移出语言定案**:位宽/后缀为编码层概念,不进语言本体(与 dex/apx 归位一致)

## 后果
- 正面:类型标注成本趋向零;语言本体与编码层职责清晰
- 负面:自动推导全量在复杂场景的检查器实现工作量;借用收缩细节待落地
