# ADR-0013: 类型系统方向 14 条定案

- 日期：2026-08-30（v2 备忘定案）
- 状态：accepted（方向定稿，实施分步）
- 决策者：DslsDZC

## 背景

类型系统需要总体方向：类型推断强度、借用/可变性语义、显式边界语法的取舍。长期存在分叉讨论，焦点是图本体与传统类型层的关系。

## 决策

- 方向总纲：图本体 + 接口统一，类型推导建立在图结构上。
- 14 条定案要点：自动推导全量（用户零标注是默认），借用收缩（borrow 语义收窄），声明式边界（显式边界语法按需使用）。
- 宽度类型移出语言定案：位宽和后缀是编码层概念，不进语言本体（与 `dex`/`apx` 归位一致）。

## 后果

- 正面：类型标注成本趋近于零；语言本体与编码层职责清晰。
- 负面：自动推导全量在复杂场景下增加检查器实现的工作量；借用收缩的细节待实施。
