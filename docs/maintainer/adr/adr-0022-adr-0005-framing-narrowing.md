# ADR-0022: ADR-0005“层规则 = 缓存语义七条”的框定收窄（规则数不变、零新增规则）

- 日期：2026-09-20
- 状态：accepted
- 决策者：DslsDZC

## 背景

`adr-0005`（内存模型分层定稿，图、格、编码 + 能力定位 v4）的决策一节第 3 条写：

> - 规则封闭、对象开放：层规则 = 缓存语义七条，永不新建；对象（条目/方法/标注）无界

`adr-0021`（2026-09-20）把格层本体改称存在格 / Materialization Space，缓存降为该层一类映射实例。该修订只改表述用词，不改规则内容，但留下一个未解决的问题：上句“层规则”这个表述仍指向“缓存语义七条”，而“缓存”已不再作为整个层的名字。如果不处理，该行会持续暗示“该层的规则 = 缓存这一类映射的规则”，读起来比实际范围更窄。

按照 `adr/README.md` 的规则（不修改已 accepted 的历史记录；被取代的保留原文，新决策另起新号），`adr-0005` 正文不得就地改写，因此由本 ADR 表示这次表述范围收窄。

## 决策

- 表述收窄：`adr-0005:13`“层规则”的所指，自本 ADR 起读作“存在格规则 1–7”（即 `docs/academic/cache-semantics.md` 的规则 1–7），不再读作“缓存语义七条”。
- 规则数未增删，本修订不新增规则：`adr-0021` 没有增加、删除或改写任何一条规则。逐条核对：规则 1/3/4/4b/5/6/7 内容原样；规则 2 的适用范围显式收窄到 `recipe = recomputable` 的条目（该范围此前由规则 4b 以“例外”形式隐含），并新增 2′，把 2 和 4b 并成同一条检查的两个分支。检查总数不变，只是不再写成“规则 + 例外”。因此“永不新建”这一承诺仍然字面成立。
- `adr-0005` 的其余部分不受影响：三层映射结构、“无格承诺”、“能力不提升一等公民”三条都是层结构与治理层面的决策，与“该层叫什么名字”无关，原样有效。
- `adr-0005` 正文不动，只改状态行：`accepted` 改为 `accepted;部分框定被 ADR-0021 收窄`（`adr-README.md` 索引同步）。
- 历史记录的处理原则（本次一并定下）：`docs/superpowers/plans/`、`docs/superpowers/specs/`（历史设计稿）和 `docs/archive/`（归档）一律不动。它们是当时意图的记录，改写会改变记录的事实。本修订的表述变更只落在活档和 ADR（见 ADR-0021 关联）。

## 后果

正面

- “规则封闭”的承诺在原文不动的前提下维持自洽：规则数确实没变，变的是规则所属层的称谓和规则 2 的表述形式。
- 给后续同类情形一个可复用的处理方式：已 accepted 的 ADR 正文永久冻结，表述或范围的变化由新 ADR 表示，状态行互相指向。
