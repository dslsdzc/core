# ADR-0022: ADR-0005「层规则 = 缓存语义七条」的框定收窄(条款数不变、零新增规则)

- 日期:2026-09-20
- 状态:accepted
- 决策者:DslsDZC

## 背景

`adr-0005`(内存模型分层定稿,图 → 格 → 编码 + 能力定位 v4)的 §决策 第 3 条写:

> - **规则封闭、对象开放**:层规则 = **缓存语义七条**,永不新建;对象(条目/配方/标注)无界

`adr-0021`(2026-09-20)把格层本体改称 **存在格 / Materialization Space**,缓存降为该层一类映射实例。
该修订**只动框定词、不动条款内容**——但它留下了一个悬空:上句「**层规则**」这个框定词仍指向
「缓存语义七条」,而「缓存」已不再作为整个层的名字。若放着不管,该行会持续暗示
「该层的规则 = 缓存这一类映射的规则」,读起来比实际更窄。

按 `adr/README.md` 的规则(**不修改已 accepted 的历史记录;被取代的保留原文,新决策另起新号**),
`adr-0005` 正文不得就地改写 ⇒ 本 ADR 承载这次框定收窄。

## 决策

- **框定收窄**:`adr-0005:13`「层规则」的所指,自本 ADR 起读作
  **「存在格条款 1–7」**(= `docs/academic/cache-semantics.md` 的条款 1–7),
  不再读作「缓存语义七条」。
- **条款数未增删、本修订零新增规则**:`adr-0021` 没有增加、删除或改写任何一条规则。
  逐条核对:条款 1/3/4/4b/5/6/7 内容原样;条款 2 的**适用范围**显式收窄到
  `recipe = recomputable` 的条目(该范围此前由条款 4b 以「例外」形式隐含),
  并新增 **2′** 把 2 与 4b 并成同一条判据的两支。**判据总数不变,只是不再写成「规则 + 例外」。**
  ⇒ 因此「**永不新建**」这一承诺**仍然字面成立**。
- **`adr-0005` 的其余部分不受影响**:三层映射结构、「**无格承诺**」、「**能力不提升一等公民**」
  三条均为**层结构与治理**层面的决策,与「该层叫什么名字」无关,原样有效。
- **`adr-0005` 正文不动,只改状态行**:
  `accepted` → `accepted;部分框定被 ADR-0021 收窄`(`adr-README.md` 索引同步)。
- **历史留痕口径(本次一并定下)**:`docs/superpowers/plans/**`、`docs/superpowers/specs/**`
  (历史设计稿)与 `docs/archive/**`(归档)**一律不动**——它们是**当时意图的记录**,
  改写即伪造历史。本修订的框定变更**只落在活档 + ADR**(见 ADR-0021 §关联)。

## 后果

**正面**

- 「规则封闭」的承诺得以**在原文不动的前提下**维持自洽:规则数确实没变,
  变的是规则所属层的**称谓**与条款 2 的**表述形式**。
- 给了后续同类情形一个可复制的处理范式:**已 accepted 的 ADR 正文永久冻结,
  框定/范围的变化由新 ADR 承载,状态行互指**。

**负面 / 待办**

- 读者需要**两跳**才能得到当前口径(adr-0005 → 状态行 → adr-0021/adr-0022)。
  这是 ADR 不可改原则的固有代价,以「状态行就近指认」缓解。
