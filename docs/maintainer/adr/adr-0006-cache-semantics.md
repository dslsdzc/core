# ADR-0006: 缓存语义 = 存储语义本体（2026-08-15 纠偏）

- 日期：2026-08-15
- 状态：superseded by ADR-0021（2026-09-20：格层本体改称存在格 / Materialization Space，缓存降为该层一类映射实例；本 ADR 正文保留原文不改）
- 决策者：DslsDZC

## 背景

memory-model 文档此前把 CompCert v2 字节模型（块 + 字节偏移 + 每字节权限）描述为语义本体。这是文档描述错误：实现（HDFG）一直是缓存语义，节点 = 方法、边 = 值流、驱逐/再生 = 丢令牌/重跑节点。

## 决策

- 语义本体 = 缓存语义七条（值 = 方法/驱逐不变量/再生等价/边界规则 + 4b 图内不可重算/赋值 = 版本化/地址 = 映射/映射实例正确性）。
- CompCert 字节模型降级为经典映射实例（权限模型，规则 7）。
- 零代码改动，本次只修正文档。

## 后果

- 正面：范式映射表成立（经典行/寄存器行/未来量子行共享七条）；验证器规则只有一个权威。
- 负面：无（文档修正）。
