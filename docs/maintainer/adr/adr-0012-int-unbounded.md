# ADR-0012: int 无上限语义：数学整数 + 编码层快路径投影

- 日期：2026-08-23（语义修订）~ 2026-09-06（语言层定稿 + 错误码归位）
- 状态：accepted
- 决策者：DslsDZC

## 背景

如果 `int` 是 64 位机器整数，规约在无界域证明的结论可能与实际运行不一致（溢出回绕），即 `int-unbounded` 问题；同时性能需要 64 位快路径。

## 决策

- 语义层：`int` 是无上限数学整数（以数学规则定义的接口，没有溢出概念，溢出不是语义事件）。
- 编码层：64 位机器字是快路径投影；超界属于编码层事务（静态区间证明可以免检；推导不出时才检查提升；表示策略归 `hw-map` 远期处理，后端采用策略 B：64 位快路径 + 溢出扩展 2-limb）。
- 溢出类错误（`lexer` 字面量检查、CCR `i32` 字段校验）属于编码层限制错误，重新归位。
- `int` 的数学规则可以被 `.cr` 规约对照验证（把 CompCert 的做法推广到原语层）；与 `dex` 精确数值这条线互不混同（`int` 关注语义无上限，`dex` 关注表示层工程）。

## 后果

- 正面：验证结论与运行语义一致（`#ensure(x + y > x)` 无条件成立）；快路径性能保留。
- 负面：多字表示和溢出升级仍在实现中，见 int multiword 设计；IR 契约表以编码层为基准，需要持续注记（`ir-op-semantics`）。
