# ADR-0005: 内存模型分层定稿——图 → 格 → 编码 + 能力定位(v4)

- 日期:2026-08-26/27(v2 08-20 起演进,v4 定稿)
- 状态:accepted
- 决策者:DslsDZC

## 背景
内存模型讨论备忘演进多版(v1 位置抽象 → v3 三层映射总纲 → v4 定稿)。需要回答:语义保鲜的存储本体是什么、能力(能力安全概念)是否是一等公民。

## 决策
- **三层映射**:图 = 关系空间(发生什么)、格 = 状态/存储空间(如何存在)、编码 = 物理编码空间(如何实现;2026-08-27 由「二进制」更名,违反零硬件惯例)
- **超图灵性属于图不属于格**;格不重新引入程序顺序;跨范式发生在图层
- **规则封闭、对象开放**:层规则 = 缓存语义七条,永不新建;对象(条目/配方/标注)无界
- **无格承诺**:判定/定理写在比格更弱的理论(最弱理论 = 最多模型);格(Lattice)代数 = 映射实例的组织参数
- **能力不提升一等公民**(可逆):身份 = 图节点、无配方 = 标注、授权归治理层(consult/assume/measure/pass = 可能关系标注)

## 后果
- 正面:新范式只需三件事(图标注加标签/CIC 定义新结构/硬件映射),不新建格;判定对一切格成立
- 负面:能力作为独立语义概念被否决——治理层授权机制待实现
