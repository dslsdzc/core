# ADR-0011: 平台桥抽象：I/O 流/随机/哈希/时钟语义接口

- 日期：2026-08-16
- 状态：accepted（设计定案，待实现）
- 决策者：DslsDZC

## 背景

如果 I/O 和时间等系统接口直接暴露系统调用，程序语义会被平台绑定，验证无法覆盖；部署配置分离原则要求物理实现在后端。

## 决策

- 程序 I/O 语义 = 流变换（转导器：输入流到输出流）；`read`/`write` 系统调用属于物理实现，后端按部署目标隔离。
- 四个语义抽象：I/O 流、随机（概率分布）、哈希（散列函数）、时钟（单调时间序）。这些是语言层语义接口，熵源、算法和系统调用在后端。
- 在验证意义上，I/O 是一等对象，流性质可以写成规约，不是验证未检查范围。

## 后果

- 正面：程序语义与平台无关；规约可以描述输入流性质到输出流性质的变换。
- 负面：平台桥实现尚未实施（语义接口待接线）。
