# lexer.cr 伪代码
> 源文件：src/compiler/lexer.cr（393 行）
> 功能概要：将 Core 语言源码字符串切分为词法单元（Token）序列。逐字符扫描源码，识别标识符、关键字、数字字面量（含进制前缀与类型后缀）、字符串字面量（含转义；**插值 `${...}` 拆分为 part token**：段 = `T_STRING`、洞 = `T_INTERP`，洞内花括号配平）、字符字面量、单字符运算符、多字符复合运算符、注释（行注释与块注释），跳过空白字符，记录行号列号，最终追加文件结束标记（T_EOF）。

## 全局状态

- **当前源码字符串（g_source）**：待分词的源码完整文本；由外部调用者在调用分词（tokenize）前设置（可变）。
- **源码长度（g_source_len）**：分词（tokenize）结束时写入的源码长度缓存值，来自字符串长度（str_len）（g_source）（可变）。注意：当前字符（cur_char）和预读字符（peek）通过当前源码字符串（g_source）重新计算长度而不使用此缓存，以规避自举可执行与链接格式（ELF）后端的全局变量修补缺陷。
- **当前字符位置（g_pos）**：当前词法单元已处理到的字符索引；跳过空白后更新为该位置（可变）。
- **当前行号（g_line）**：当前行号，从 1 开始计数；每遇换行递增，重置当前列号（g_col）为 1（可变）。
- **当前列号（g_col）**：当前列号，从 1 开始计数；每遇非换行字符递增（可变）。
- **词法单元数组（g_tokens）**：扁平字节数组，每个词法单元占 词法单元条目大小（ESZ_TOKEN） 字节；由扩展词法单元数组（grow_tokens）动态扩展。
- **词法单元计数（g_token_count）**：已产生的词法单元总数（索引）。
- **错误数组（g_errors）**：扁平字节数组，每个错误占 8 字节（驻留字符串索引）。
- **错误计数（g_error_count）**：已收集的错误总数（索引）。

## 函数 判断数字（is_digit）
### 作用
判断给定字符码是否属于十进制数字范围（字符 '0' 至 '9'，码值 48 至 57）。返回 1（真）或 0（假）；不产生副作用，也不依赖全局状态。
### 逻辑
函数 判断数字（is_digit）（字符码（c）：整数）-> 整数
    如果 字符码 大于等于 48 且 字符码 小于等于 57，那么：
        返回 1
    返回 0
### 测试要点
1. 输入 48（字符（'0'））返回 1；输入 57（字符（'9'））返回 1
2. 输入 47（字符（'/'））返回 0；输入 58（字符（':'））返回 0
3. 输入 0、-1、255 等边界值返回 0

## 函数 判断字母（is_alpha）
### 作用
判断给定字符码是否属于标识符首字符合法集：大写字母（65 至 90）、小写字母（97 至 122）、下划线（95）。返回 1 或 0。
### 逻辑
函数 判断字母（is_alpha）（字符码（c）：整数）-> 整数
    如果 （字符码 大于等于 65 且 字符码 小于等于 90） 或 （字符码 大于等于 97 且 字符码 小于等于 122） 或 字符码 等于 95，那么：
        返回 1
    返回 0
### 测试要点
1. 大写字母（字符（'左操作数（A）'），码值 65）返回 1；大写字母（字符（'Z'），码值 90）返回 1
2. 小写字母（字符（'变量甲（a）'），码值 97）返回 1；小写字母（字符（'变量乙（z）'），码值 122）返回 1
3. 下划线（字符（'下划线（_）'），码值 95）返回 1
4. 数字（字符（'0'），码值 48）返回 0；符号（字符（'+'），码值 43）返回 0

## 函数 判断标识符字符（is_ident_char）
### 作用
判断给定字符码是否为标识符后续字符（标识符首字符之后可出现的字符）：即字母（含下划线）或数字。调用判断字母（is_alpha）和判断数字（is_digit）组合判定。
### 逻辑
函数 判断标识符字符（is_ident_char）（字符码（c）：整数）-> 整数
    如果 判断字母（is_alpha）（字符码）不等于 0 或 判断数字（is_digit）（字符码）不等于 0，那么：
        返回 1
    返回 0
### 测试要点
1. 字符（'变量甲（a）'）返回 1；字符（'5'）返回 1；字符（'下划线（_）'）返回 1
2. 空格（字符（' '））返回 0；运算符（字符（'+'））返回 0

## 函数 添加错误（add_error）
### 作用
将一条错误消息字符串记录到全局错误数组（g_errors）。消息经字符串驻留（str_intern）后以 8 字节整数索引存入，错误计数（g_error_count）递增。
### 逻辑
函数 添加错误（add_error）（消息 msg：字符串）
    令 消息索引（mi）= 字符串驻留（str_intern）（消息）
    扩展错误数组（grow_errors）（错误计数（g_error_count）+ 1）
    写 64 位（w64）（错误数组（g_errors），错误计数（g_error_count）* 8，消息索引）
    错误计数（g_error_count）= 错误计数（g_error_count）+ 1
### 测试要点
1. 调用后错误计数（g_error_count）递增 1
2. 空字符串消息正常驻留并记录
3. 多次调用后错误数组按序排列

## 函数 当前字符（cur_char）
### 作用
返回当前源码字符串（g_source）在当前字符位置（g_pos）处的单字节字符码。若已到达或超出源码末尾则返回 0（文件结束标记）。内部使用字符串长度（str_len）重新计算源码长度，而不使用源码长度（g_source_len），以规避自举可执行与链接格式（ELF）后端的全局变量修补缺陷。
### 逻辑
函数 当前字符（cur_char）-> 整数
    令 本地源码长度（src_len）= 字符串长度（str_len）（g_source）
    如果 当前字符位置（g_pos）大于等于 本地源码长度，那么：
        返回 0
    返回 按字节读取（load8）（当前源码字符串（g_source），当前字符位置（g_pos））
### 测试要点
1. 初始当前字符位置（g_pos）= 0 且源码非空时返回首字符码值
2. 当前字符位置（g_pos）等于源码长度时返回 0（文件结束）
3. 当前字符位置（g_pos）超过源码长度时返回 0

## 函数 预读字符（peek）
### 作用
返回当前字符位置（g_pos）加 1 位置的下一字符码值，不移动当前字符位置（g_pos）。用于探测复合运算符、注释起止等向前看一个字符的场景。
### 逻辑
函数 预读字符（peek）-> 整数
    令 本地源码长度（src_len）= 字符串长度（str_len）（g_source）
    如果 当前字符位置（g_pos）+ 1 大于等于 本地源码长度，那么：
        返回 0
    返回 按字节读取（load8）（当前源码字符串（g_source），当前字符位置（g_pos）+ 1）
### 测试要点
