## 函数 扩展安全：初始化（ext_safety_init）

### 作用
安全检查插件的初始化入口。检查扩展管理器是否就绪，若就绪则将自己注册到 数组访问 和 二元运算 两个钩子上。由 扩展：初始化（ext_init） 调用。

### 逻辑

    函数 扩展安全：初始化：
        如果 扩展：检查存在（ext_has）（参数 = 0） 等于 0，那么：
            返回  // 扩展管理器尚未初始化，等待
        扩展：注册（ext_reg）（钩子类型 = 钩子类型：数组访问，插件 ID = 1）  // 监听数组访问
        扩展：注册（ext_reg）（钩子类型 = 钩子类型：二元运算，插件 ID = 1）   // 监听二元运算

### 测试要点
1. 若 扩展：检查存在（ext_has） 返回 0（扩展管理器未就绪），函数直接返回不作任何注册。
2. 若扩展管理器就绪，向两个钩子类型分别注册自身（插件 ID=1）。
3. 重复调用不会导致问题：扩展管理器端以追加方式存储注册条目。

## 函数 扩展安全：数组访问检查（ext_safety_on_array_access）

### 作用
数组访问的安全检查处理函数。在 加载索引（IR_LOAD_INDEX）/ 存储索引（IR_STORE_INDEX） 指令生成前被扩展管理器调用。支持三种场景：编译期已知索引和长度则静态检查索引是否超出数组长度；仅已知长度则插入运行时边界检查指令；动态长度则不做检查（交由其他机制）。

### 逻辑

    函数 扩展安全：数组访问检查（数组变量（arr_var）：整数，索引变量（idx_var）：整数，索引字面量（idx_lit）：整数，数组长度字面量（arr_len_lit）：整数）-> 整数：
        // 场景一：字面量索引 + 字面量长度 → 编译期检查
        如果 索引字面量 大于等于 0 且 数组长度字面量 大于等于 0，那么：
            如果 索引字面量 小于 0 或 索引字面量 大于等于 数组长度字面量，那么：
                返回 1  // 编译期越界，跳过此次访问
            返回 0  // 编译期安全，继续正常流程
        // 场景二：变量索引 + 字面量长度 → 插入运行时边界检查指令
        如果 数组长度字面量 大于等于 0，那么：
            发射指令（emit）（操作码 = 边界检查指令（IR_BOUNDS_CHECK），目标 = -1，操作数1 = 索引变量，操作数2 = 数组长度字面量，操作数3 = 0，类型类别 = 0）
            返回 0
        // 场景三：两者均非字面量 → 不做编译期检查
        返回 0

### 测试要点
1. 已知索引和长度且索引在范围内（如 索引字面量=0, 数组长度字面量=5），返回 0 表示安全。
2. 已知索引和长度且索引超出数组长度（如 索引字面量=5, 数组长度字面量=5），返回 1 表示跳过访问（编译期捕获）。
3. 已知索引和长度且索引为负数（索引字面量=-1），外层条件 索引字面量 大于等于 0 不成立，跳过场景一。
4. 未知索引（索引字面量=-1）但已知长度（数组长度字面量=10），插入 边界检查指令，返回 0。
5. 索引和长度均未知（均为 -1），返回 0，不做任何检查指令插入。
6. 边界情况：数组长度字面量=0 且 索引字面量=0 时进入场景一，内部条件 索引字面量 大于等于 数组长度字面量 成立（0 大于等于 0），返回 1。
