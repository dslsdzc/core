# provenance_verify.cr 伪代码
> 源文件：src/compiler/provenance_verify.cr（90 行）
> 功能概要：来源验证（Provenance Verify）pass。在指针分析和区域检查之后运行，对每条解引用指令（IR_DEREF）验证：若偏移量编译期已知，则检查是否超出对应分配的大小；若偏移量未知但分配大小已知，则在下层指令中编码分配大小信息供后端生成运行时检查。

## 全局状态

本文件读取以下全局状态（由 HDFG、指针分析和区域分析填充）：

- 数据流节点数组（g_df_nodes）：每条 IR 指令对应一个数据流节点，包含操作码、目标、操作数 1-3 等字段。
- 指针集数组（g_pts）：每个变量的指针集位图（64 位整数，每位代表一个分配点）。
- 偏移量数组（g_offsets）：每个变量的偏移量（字节）。
- 结构图数组（g_sgs）：region 结构图，用于判断 不安全块 归属和分配点的 region 关系。
- 结构图计数（g_sg_count）：结构图条目总数。
- IR 函数个数（g_ir_func_count）：IR 层函数总数。
- HDFG各函数节点起始索引（g_df_func_node_start）：每个函数的数据流节点起始偏移。
- HDFG各函数节点计数（g_df_func_node_count）：每个函数的数据流节点个数。

领域专名保留：数据流节点条目大小（ESZ_DFNODE）、操作码字段偏移（OFF_DF_OPCODE）/ 操作数1字段偏移（OFF_DF_S1）/ 操作数2字段偏移（OFF_DF_S2）/ 操作数3字段偏移（OFF_DF_S3）/ 目标字段偏移（OFF_DF_DEST）、不安全区域（SG_UNSAFE）、类别字段偏移（OFF_SG_KIND）/ 节点起始字段偏移（OFF_SG_NSTART）/ 节点计数字段偏移（OFF_SG_NCOUNT）、标量分配（IR_ALLOC）/ 结构体分配（IR_ALLOC_STRUCT）/ 数组分配（IR_ALLOC_ARRAY）/ 解引用（IR_DEREF）。

## 函数 获取分配大小（get_alloc_size）

### 作用
根据分配节点（IR_ALLOC / IR_ALLOC_STRUCT / IR_ALLOC_ARRAY）的操作码和操作数计算分配大小（字节）。标量分配固定 8 字节，结构体为 8 + 字段数*8，数组为元素数*元素大小。无法确定则返回 -1。

### 逻辑

    函数 获取分配大小（分配节点序号 alloc_node_seq：整数）-> 整数：
        令 操作码（op） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 分配节点序号 * 数据流节点条目大小（ESZ_DFNODE） + 操作码字段偏移（OFF_DF_OPCODE））
        令 操作数1（s1） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 分配节点序号 * 数据流节点条目大小 + 操作数1字段偏移（OFF_DF_S1））
        令 操作数2（s2） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 分配节点序号 * 数据流节点条目大小 + 操作数2字段偏移（OFF_DF_S2））
        令 操作数3（s3） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 分配节点序号 * 数据流节点条目大小 + 操作数3字段偏移（OFF_DF_S3））

        如果 操作码 等于 标量分配（IR_ALLOC），那么：返回 8           // 标量 = 8 字节
        如果 操作码 等于 结构体分配（IR_ALLOC_STRUCT），那么：返回 8 + 操作数2 * 8  // 结构体大小 = 头 8 字节 + 字段
        如果 操作码 等于 数组分配（IR_ALLOC_ARRAY），那么：返回 操作数1 * 操作数2  // 元素个数 * 元素大小
        返回 -1  // 未知（交运行时检查处理）

### 测试要点
1. 标量分配 → 返回 8（标量固定大小）。
2. 结构体分配且字段数 = 0 → 返回 8（仅头部）。
3. 结构体分配且字段数 = 3 → 返回 32（8+3*8）。
4. 数组分配且元素数 = 10, 元素大小 = 4 → 返回 40。
5. 非分配指令的操作码 → 返回 -1。

## 函数 来源验证：判断 不安全块内（pv_is_in_unsafe）

### 作用
判断给定数据流节点序号是否位于某个 不安全区域（SG_UNSAFE）内。遍历结构图数组，检查节点的序号范围是否落在 不安全区域的 [起始, 起始+计数） 区间内。

### 逻辑

    函数 来源验证：判断 不安全块内（节点序号 node_seq：整数）-> 整数：
        令 结构图索引（si） = 0（可变）
        循环：
            如果 结构图索引 大于等于 结构图计数，那么：
                跳出循环
            令 结构图类别（kind） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小（ESZ_SG） + 类别字段偏移（OFF_SG_KIND））
            如果 结构图类别 等于 不安全区域（SG_UNSAFE），那么：
                令 结构图节点起始（nstart） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 节点起始字段偏移（OFF_SG_NSTART））
                令 结构图节点计数（ncount） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 节点计数字段偏移（OFF_SG_NCOUNT））
                如果 节点序号 大于等于 结构图节点起始 且 节点序号 小于 结构图节点起始 + 结构图节点计数，那么：
                    返回 1
            令 结构图索引 = 结构图索引 + 1
        返回 0

### 测试要点
1. 节点在 不安全区域的范围内：返回 1。
2. 节点在 不安全区域范围外或有其他区域类型：返回 0。
3. 结构图数组为空（无任何区域）：返回 0。

## 函数 来源验证函数（provenance_verify_func）

### 作用
对单个函数的所有数据流节点执行来源验证。遍历每条指令，对 解引用（IR_DEREF）指令：
1. 若在 不安全块内则跳过检查。
2. 获取指针变量（操作数1）的指针集位图和偏移量。
3. 对指针集中每个分配目标，调用 获取分配大小 获取其分配大小。
4. 若偏移量和分配大小均编译期已知且偏移量超出分配大小，则报错（检查错误 EC_TK_INDEX）。
5. 若仅分配大小已知但偏移量未知，则在数据流节点的操作数3字段编码分配大小供后端生成运行时检查。
6. 若两者均未知则不做检查。

### 逻辑

    函数 来源验证函数（节点起始 nstart：整数，节点计数 ncount：整数）：
        令 当前节点序号（ni） = 节点起始（可变）
        循环：
            如果 当前节点序号 大于等于 节点起始 + 节点计数，那么：
                跳出循环
            令 操作码（op） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作码字段偏移）
            令 目标变量（d_dest） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 目标字段偏移（OFF_DF_DEST））
            令 操作数1（s1） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数1字段偏移）

            如果 操作码 等于 解引用（IR_DEREF） 且 目标变量 大于等于 0 且 操作数1 大于等于 0，那么：
                // 在 不安全块内则跳过
                如果 来源验证：判断 不安全块内（pv_is_in_unsafe）（当前节点序号） 不等于 0，那么：
                    令 当前节点序号 = 当前节点序号 + 1
                    继续下一次循环

                令 指针集位图（pts） = 读 64 位（r64）（源 = 指针集数组，偏移 = 操作数1 * 8）
                令 偏移量（off） = 读 64 位（r64）（源 = 偏移量数组，偏移 = 操作数1 * 8）

                // 来源验证增强（Prov-GC）：使用增强后的偏移量数组做精确偏移量检查
                令 精确偏移量（prec_off） = 读 64 位（r64）（源 = 偏移量数组，偏移 = 操作数1 * 8）

                // 遍历指针集位图中的每一位（每个可能的分配目标）
                令 位掩码（mask） = 1（可变）
                令 位序号（bi） = 0（可变）
                循环：
                    如果 位序号 大于等于 64，那么：
                        跳出循环
                    如果 （指针集位图 / 位掩码） % 2 不等于 0，那么：
                        令 分配大小（alloc_size） = 获取分配大小（get_alloc_size）（位序号）
                        如果 分配大小 大于等于 0 且 偏移量 大于等于 0，那么：
                            如果 偏移量 大于等于 分配大小，那么：
                                // 编译期越界：偏移量 >= 分配大小
                                检查错误（check_error）（参数 = 错误码：类型索引越界（EC_TK_INDEX），
                                    消息 = "pointer out of bounds: offset " + 整数转字符串（偏移量） + " >= size " + 整数转字符串（分配大小），
                                    行号 = 0，列号 = 0）
                        否则如果 分配大小 大于等于 0，那么：
                            // 分配大小已知但偏移量未知 → 将分配大小编码到操作数3，后端生成 cmp+jae+ud2 序列
                            写 64 位（w64）（目标 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数3字段偏移，值 = 分配大小）
                        否则：
                            // 两者均未知 → 仅靠空指针陷阱保护（操作数3 = 0，快速路径）
                            不做额外操作
                    令 位掩码 = 位掩码 * 2
                    令 位序号 = 位序号 + 1

            令 当前节点序号 = 当前节点序号 + 1

### 测试要点
1. 偏移量已知且在分配大小范围外时（如 off=8, alloc_size=8），报错 错误码：类型索引越界。
2. 偏移量已知且在分配大小范围内时，不报错，不做特殊处理。
3. 分配大小已知但偏移量未知时，在操作数3位置写入 分配大小（供后端运行时检查）。
4. 分配大小和偏移量均未知时，不写入操作数3（保持为 0，null 陷阱快速路径）。
5. 不安全块内的解引用指令跳过所有检查。
6. 一个指针变量可能指向多个分配目标（指针集位图含多位），对每个分配目标分别判断。
7. 非 解引用 指令直接跳过。

## 函数 来源验证全部（provenance_verify_all）

### 作用
对所有 IR 函数逐一调用 来源验证函数（provenance_verify_func）。

### 逻辑

    函数 来源验证全部：
        // 安全检查通行证 — 始终运行
        令 函数序号（fi） = 0（可变）
        循环：
            如果 函数序号 大于等于 IR 函数个数，那么：
                跳出循环
            令 节点起始（nstart） = 读 64 位（r64）（源 = HDFG各函数节点起始索引，偏移 = 函数序号 * 8）
            令 节点计数（ncount） = 读 64 位（r64）（源 = HDFG各函数节点计数，偏移 = 函数序号 * 8）
            来源验证函数（provenance_verify_func）（节点起始，节点计数）
            令 函数序号 = 函数序号 + 1

### 测试要点
1. 无 IR 函数时循环不执行。
2. 每个函数独立调用来源验证，各自的节点范围不重叠。
3. 始终运行（不检查优化级别等标志）。
