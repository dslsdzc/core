# interp.cr 伪代码
> 源文件：src/compiler/interp.cr（384 行）
> 功能概要：HDFG解释器 —— 用于 eval 模式（-变量丙（c） 标志）。直接解释执行 数据流节点数组（g_df_nodes）[]（数据流节点数组）而非线性 IR 指令数组（g_ir_instrs）[]（IR 指令数组），运行过程中保留类型与语义信息。限制：字符串常量不调用 syscall3（分配函数（alloc）/print/syscall 相关函数返回 0）；递归/跨函数调用不支持 调用指令（IR_CALL） 嵌套，只处理 主入口（main） 到被调用函数的单层调用；遍历（for） 循环与 label/branch 跳转机制不兼容。

## 函数 IR 解释执行（ir_interpret）
签名：`函数 IR 解释执行（ir_interpret）（）-> 整数`
### 作用
查找 主函数入口名（main）函数的 HDFG节点，初始化值数组为全零，预扫描标签（供分支指令）和循环 region（供回边跳转），然后按节点顺序逐一执行所有 HDFG节点的操作码。支持约 25 种操作码的完整解释语义（包括常量和二元/一元运算、内存分配与读写、结构体字段访问、数组索引访问、分支跳转、函数调用等）。支持单层函数调用（内联执行被调用函数的 HDFG，保存/恢复标签状态）。返回 主函数入口名 函数的返回值（整数），找不到 主函数入口名 时返回 -1。
### 逻辑
    （第一阶段：查找 main 函数）
    令 主函数索引（main_idx）= -1
    令 函数索引（fi）= 0
    循环（当 函数索引 小于 IR 函数个数（g_ir_func_count）时）：
        令 函数名索引（ni）= 读 64 位（r64）（IR 函数名索引数组（g_ir_func_name_idx）, 函数索引 * 8）
        如果 字符串相等比较（str_eq）（驻留字符串获取（istr_get）（函数名索引）, 主函数入口名（main））不等于 0，那么：
            令 主函数索引 = 函数索引
            跳出循环
        令 函数索引 = 函数索引 + 1
    如果 主函数索引 小于 0，那么：返回 -1

    （读取 main 函数的 HDFG节点范围）
    令 节点起始（node_start）= 读 64 位（r64）（HDFG各函数节点起始索引（g_df_func_node_start）, 主函数索引 * 8）
    令 节点条数（node_count）= 读 64 位（r64）（HDFG各函数节点计数（g_df_func_node_count）, 主函数索引 * 8）
    如果 节点起始 小于 0 或 节点条数 小于等于 0，那么：返回 -1

    （初始化值数组）
    令 所需槽位数（need）= IR 变量总数（g_ir_var_count）+ 64
    如果 IR 解释器值容量（g_ir_vals_cap）小于 所需槽位数，那么：
        令 IR 解释器值数组（g_ir_vals）= 分配内存（need * 8）
        令 IR 解释器值容量（g_ir_vals_cap） = 所需槽位数
    令 值索引（vi）= 0
    循环（当 值索引 小于 所需槽位数 时）：
        写 64 位（w64）（IR 解释器值数组, 值索引 * 8, 0）（全部初始化为 0）
        令 值索引 = 值索引 + 1

    （第二阶段：预扫描——构建标签到节点偏移的映射）
    令 标签计数（g_label_count）= 0
    令 节点偏移（li）= 0
    循环（当 节点偏移 小于 节点条数 时）：
        令 节点操作码（n_op）= 读 64 位（r64）（数据流节点数组（g_df_nodes）, （节点起始 + 节点偏移） * 数据流节点元素大小（ESZ_DFNODE）+ 数据流节点操作码偏移（OFF_DF_OPCODE））
        令 节点操作数1（n_s1）= 读 64 位（r64）（数据流节点数组, （节点起始 + 节点偏移） * 64 + 数据流节点操作数1偏移（OFF_DF_S1））
        如果 节点操作码 等于 21（IR_LABEL），那么：
            令 标签号（ln）= 节点操作数1
            如果 标签号 大于等于 0，那么：
                扩展标签位置数组（grow_label_poses）（标签号 + 1）
                写 64 位（w64）（标签位置数组（g_label_poses）, 标签号 * 8, 节点偏移）
                如果 标签号 + 1 大于 标签计数，那么：令 标签计数 = 标签号 + 1
        令 节点偏移 = 节点偏移 + 1

    （第三阶段：预扫描——记录 main 函数范围内的循环 region）
    令 循环 region 计数（g_loop_region_count）= 0
    令 结构图索引（li）= 0
    循环（当 结构图索引 小于 结构图计数（g_sg_count）时）：
        令 region 类别（lk）= 读 64 位（r64）（结构图数组（g_sgs）, 结构图索引 * 结构图元素大小（ESZ_SG）+ 结构图类别偏移（OFF_SG_KIND））
        如果 region 类别 等于 结构图类型：循环（SG_LOOP）或 region 类别 等于 结构图类型：遍历循环（SG_FOR），那么：
            令 进入节点（l_enter）= 读 64 位（r64）（结构图数组, 结构图索引 * 48 + 结构图入口偏移（OFF_SG_ENTER））
            令 退出节点（l_exit）= 读 64 位（r64）（结构图数组, 结构图索引 * 48 + 结构图出口偏移（OFF_SG_EXIT））
            如果 进入节点 大于等于 节点起始 且 进入节点 小于 节点起始 + 节点条数，那么：
                （动态扩容循环 region 数组）
                如果 循环 region 计数 + 1 大于 循环 region 容量（g_loop_region_cap），那么：
                    令 新容量（nc）= 循环 region 容量 * 2
                    如果 新容量 小于 16，那么：令 新容量 = 16
                    令 新入口数组（nb）= 分配内存（新容量 * 8）
                    内部：动态拷贝（_dyncpy）（循环 region 入口 HDFG节点（g_loop_region_enter）, 循环 region 容量 * 8, 新入口数组）
                    令 新出口数组（nb2）= 分配内存（新容量 * 8）
                    内部：动态拷贝（循环 region 出口 HDFG节点（g_loop_region_exit）, 循环 region 容量 * 8, 新出口数组）
                    令 循环 region 入口 HDFG节点（g_loop_region_enter） = 新入口数组
                    令 循环 region 出口 HDFG节点（g_loop_region_exit） = 新出口数组
                    令 循环 region 容量 = 新容量
                （写入循环 region 的入口/出口偏移，均相对于节点起始）
                写 64 位（w64）（循环 region 入口 HDFG节点（g_loop_region_enter）, 循环 region 计数 * 8, 进入节点 - 节点起始）
                写 64 位（w64）（循环 region 出口 HDFG节点（g_loop_region_exit）, 循环 region 计数 * 8, 退出节点 - 节点起始）
                令 循环 region 计数 = 循环 region 计数 + 1
        令 结构图索引 = 结构图索引 + 1

    （第四阶段：主执行循环——按节点顺序遍历，HDFG中顺序即直线代码的有效拓扑序）
    令 指令指针（ip）= 0（在 main 函数节点数组中的偏移）
    循环（当 指令指针 小于 节点条数 时）：
        令 操作码（op）= 读 64 位（r64）（数据流节点数组, （节点起始 + 指令指针） * 64 + 0）
        令 目标（d）= 读 64 位（r64）（数据流节点数组, （节点起始 + 指令指针） * 64 + 8）
        令 操作数1（s1）= 读 64 位（r64）（数据流节点数组, （节点起始 + 指令指针） * 64 + 16）
        令 操作数2（s2）= 读 64 位（r64）（数据流节点数组, （节点起始 + 指令指针） * 64 + 24）
        令 操作数3（s3）= 读 64 位（r64）（数据流节点数组, （节点起始 + 指令指针） * 64 + 32）

        （op == 1：常量指令（IR_CONST）——将常量值写入目标变量槽位）
        如果 操作码 等于 1，那么：
            如果 目标 大于等于 0，那么：写 64 位（w64）（IR 解释器值数组, 目标 * 8, 操作数1）

        （op == 5：返回指令（IR_RETURN）——返回指定变量的值并终止解释）
        如果 操作码 等于 5，那么：
            如果 操作数1 大于等于 0，那么：返回 读 64 位（r64）（IR 解释器值数组, 操作数1 * 8）
            返回 0

        （op == 2：IR_BINARY——二元运算，操作数3 为子操作码）
        如果 操作码 等于 2，那么：
            令 左值（lv）= 读 64 位（r64）（IR 解释器值数组, 操作数1 * 8）
            令 右值（rv）= 读 64 位（r64）（IR 解释器值数组, 操作数2 * 8）
            如果 操作数3 等于 1，那么：写 64 位（IR 解释器值数组, 目标 * 8, 左值 + 右值）（加法）
            如果 操作数3 等于 2，那么：写 64 位（IR 解释器值数组, 目标 * 8, 左值 - 右值）（减法）
            如果 操作数3 等于 3，那么：写 64 位（IR 解释器值数组, 目标 * 8, 左值 * 右值）（乘法）
            如果 操作数3 等于 4，那么：写 64 位（IR 解释器值数组, 目标 * 8, 左值 / 右值）（除法）
            如果 操作数3 等于 5，那么：写 64 位（IR 解释器值数组, 目标 * 8, 左值 % 右值）（取模）
            如果 操作数3 等于 6，那么：如果 左值 等于 右值，那么写 1 到目标，否则写 0（等于比较）
            如果 操作数3 等于 7，那么：如果 左值 不等于 右值，那么写 1 到目标，否则写 0（不等于比较）
            如果 操作数3 等于 8，那么：如果 左值 小于 右值，那么写 1 到目标，否则写 0（小于比较）
            如果 操作数3 等于 9，那么：如果 左值 大于 右值，那么写 1 到目标，否则写 0（大于比较）
            如果 操作数3 等于 10，那么：如果 左值 小于等于 右值，那么写 1 到目标，否则写 0（小于等于比较）
            如果 操作数3 等于 11，那么：如果 左值 大于等于 右值，那么写 1 到目标，否则写 0（大于等于比较）
            如果 操作数3 等于 12，那么：如果 左值 不等于 0 且 右值 不等于 0，那么写 1 到目标，否则写 0（逻辑与）
            如果 操作数3 等于 13，那么：如果 左值 不等于 0 或 右值 不等于 0，那么写 1 到目标，否则写 0（逻辑或）
            如果 操作数3 等于 17，那么：写 64 位（IR 解释器值数组, 目标 * 8, 左值 + 右值 * 8）（指针加法（OP_PTR_ADD）：指针加法）
            如果 操作数3 等于 18，那么：写 64 位（IR 解释器值数组, 目标 * 8, 左值 - 右值 * 8）（指针减法（OP_PTR_SUB）：指针减法）
            如果 操作数3 等于 19，那么：写 64 位（IR 解释器值数组, 目标 * 8, （左值 - 右值） / 8）（指针差（OP_PTR_DIFF）：指针差，除以元素大小 8）

        （op == 3：一元运算指令（IR_UNARY）——一元运算）
        如果 操作码 等于 3，那么：
            令 操作数值（ov）= 读 64 位（r64）（IR 解释器值数组, 操作数1 * 8）
            如果 操作数3 等于 1，那么：写 64 位（IR 解释器值数组, 目标 * 8, -操作数值）（取负）
            如果 操作数3 等于 2，那么：如果 操作数值 等于 0，那么写 1 到目标，否则写 0（逻辑非）

        （op == 6：IR_ALLOC——分配栈空间，值初始化为 0）
        如果 操作码 等于 6，那么：
            如果 目标 大于等于 0，那么：写 64 位（IR 解释器值数组, 目标 * 8, 0）

        （op == 7：IR_ALLOC_STRUCT——分配结构体内存并清零）
        如果 操作码 等于 7，那么：
            如果 目标 大于等于 0，那么：
                令 结构体索引（si）= 查找结构体（find_struct）（操作数3）
                令 字段数（fc）= 0
                如果 结构体索引 大于等于 0，那么：令 字段数 = 结构体信息访问器：字段计数（si_field_count）（结构体索引）
                令 所需字节（need2）= 字段数 * 8 + 8
                令 缓冲区指针（bp）= 分配内存（need2）
                令 清零索引（vi2）= 0
                循环（当 清零索引 小于 所需字节 时）：存储单字节（缓冲区指针, 清零索引, 0）；令 清零索引 = 清零索引 + 1
                写 64 位（IR 解释器值数组, 目标 * 8, 缓冲区指针）

        （op == 8：IR_ALLOC_ARRAY——分配数组内存并清零）
        如果 操作码 等于 8，那么：
            如果 目标 大于等于 0，那么：
                令 元素个数（cnt）= 操作数1
                令 每元素字节数（esz）= 操作数2
                如果 每元素字节数 小于等于 0，那么：令 每元素字节数 = 8（默认每个元素 8 字节）
                令 所需字节（need2）= 元素个数 * 每元素字节数 + 8
                令 缓冲区指针（bp）= 分配内存（need2）
                令 清零索引（vi2）= 0
                循环（当 清零索引 小于 所需字节 时）：存储单字节（缓冲区指针, 清零索引, 0）；令 清零索引 = 清零索引 + 1
                写 64 位（IR 解释器值数组, 目标 * 8, 缓冲区指针）

        （op == 9：存储指令（IR_STORE）——将操作数2 的值写入操作数1 指向的槽位）
        如果 操作码 等于 9，那么：
            如果 操作数1 大于等于 0 且 操作数2 大于等于 0，那么：
                写 64 位（IR 解释器值数组, 操作数1 * 8, 读 64 位（IR 解释器值数组, 操作数2 * 8））

        （op == 10：IR_LOAD——从操作数1 指向的槽位加载值写入目标）
        如果 操作码 等于 10，那么：
            如果 目标 大于等于 0，那么：
                写 64 位（IR 解释器值数组, 目标 * 8, 读 64 位（IR 解释器值数组, 操作数1 * 8））

        （op == 11：IR_LOAD_FIELD——从结构体加载字段，操作数1 为结构体变量，操作数3 为字段索引）
        如果 操作码 等于 11，那么：
            如果 目标 大于等于 0 且 操作数1 大于等于 0，那么：
                令 结构体指针（ptr）= 读 64 位（IR 解释器值数组, 操作数1 * 8）
                如果 结构体指针 不等于 0（堆上分配），那么：
                    写 64 位（IR 解释器值数组, 目标 * 8, 读 64 位（结构体指针, 操作数3 * 8））
                否则（栈上，直接从值数组读取）：
                    写 64 位（IR 解释器值数组, 目标 * 8, 读 64 位（IR 解释器值数组, 操作数1 * 8））

        （op == 12：IR_STORE_FIELD——向结构体字段写入值）
        如果 操作码 等于 12，那么：
            如果 操作数1 大于等于 0 且 操作数2 大于等于 0，那么：
                令 结构体指针（ptr）= 读 64 位（IR 解释器值数组, 操作数1 * 8）
                如果 结构体指针 不等于 0（堆上），那么：
                    写 64 位（结构体指针, 操作数3 * 8, 读 64 位（IR 解释器值数组, 操作数2 * 8））
                否则（栈上回退）：
                    写 64 位（IR 解释器值数组, 操作数1 * 8, 读 64 位（IR 解释器值数组, 操作数2 * 8））

        （op == 13：IR_LOAD_INDEX——按字面量索引从数组加载，操作数3 为字面量索引）
        如果 操作码 等于 13，那么：
            如果 目标 大于等于 0 且 操作数1 大于等于 0，那么：
                令 数组指针（arr_ptr）= 读 64 位（IR 解释器值数组, 操作数1 * 8）
                写 64 位（IR 解释器值数组, 目标 * 8, 读 64 位（数组指针, 操作数3 * 8））

        （op == 14：存储索引指令（IR_STORE_INDEX）——按字面量索引向数组存储）
        如果 操作码 等于 14，那么：
            如果 操作数1 大于等于 0 且 操作数2 大于等于 0，那么：

                    令 被调用函数索引 = 被调用函数索引 + 1

        令 指令指针 = 指令指针 + 1（主循环末尾自增）

    返回 0（正常结束，无显式返回值时返回 0）
### 测试要点
1. 找不到 主函数入口名 函数时返回 -1
2. 主函数入口名 的节点起始为负或节点条数小于等于 0 时返回 -1
3. IR 常量指令（IR_CONST）正确将常量值写入目标变量槽位
4. IR 返回指令（IR_RETURN）正确返回值并终止解释
5. IR 二元运算指令（IR_BINARY）覆盖全部 16 种子操作码（算术 5 种、比较 6 种、逻辑 2 种、指针运算 3 种）
6. IR 分支指令（IR_BRANCH）按条件值（非零/零）选择真/假目标跳转；标签号超出范围时不跳转
7. IR 跳转指令（IR_JUMP）的循环回边检测：在所有包含当前 指令指针 的循环 region 中找到 入口 最大的（最内层），若目标标签等于该 入口 则从 region 表取 指令指针 而非标签表
8. 除零/除空等异常行为与底层运算一致（Core 整数除零行为未定义，无额外保护）
9. IR 调用指令（IR_CALL）内联执行仅支持单层调用（被调用函数内的 CALL 不被递归展开）
10. 内建指针加载函数（load_str_ptr）/ 内建指针存储函数（store_str_ptr）正确编解码 64 位指针到字节缓冲区（小端序 8 字节）
11. 调用前后标签状态完整保存/恢复，被调用函数的标签映射不与调用者混淆
12. IR 分配结构体指令（IR_ALLOC_STRUCT）查找结构体失败时字段数默认为 0，仅分配 8 字节
13. IR 分配数组指令（IR_ALLOC_ARRAY）中每元素字节数小于等于 0 时默认设为 8
14. IR 加载字段指令（IR_LOAD_FIELD）/ IR 存储字段指令（IR_STORE_FIELD）在 结构体指针 非零（堆上）时直接访问堆内存，结构体指针 为零时回退到值数组读写
