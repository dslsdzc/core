# region_check.cr 伪代码
> 源文件：src/compiler/region_check.cr
> 功能概要：区域检查（Region Check）pass。在指针分析之后运行，判定「某分配在某个使用点是否已死」——死 ⟺ 该分配落在某个**出口真的归还内存**的区域（循环（loop）/当（while）/遍历（for）/不安全（unsafe））里，且使用点在该区域关闭之后。三条检查共用这一份判定（单源）：悬垂解引用（IR_DEREF）· 返回逃逸（IR_RETURN）· 存储逃逸（IR_STORE_PTR）。
> 修订（2026-09-20）：判定原抄三份且有两处判错——① 区间是半开 [起始, 出口)，「已关闭」须用 `大于等于`，原写 `大于` ⇒ 漏掉「使用点紧跟区域」这一格；② 原把「任何区域关闭」当归还点，而如果（if）区不建 arena、函数（func）区的 arena 在函数出口才重置 ⇒ `如果 x { 数组 := [..]; 指针 := &数组[0]; } *指针` 这类合法程序被误报。另：存储逃逸的判定值原被整行丢弃（检查从不可触发）、返回逃逸误用生命周期错误码（应为逃逸错误码）。传参逃逸（把指针作参数传给外部）为**设计未实现**——本文件无调用（IR_CALL）分支，且其完整语义需要函数摘要，而指针分析的调用分支不做摘要传播。

## 全局状态

本文件读取以下全局状态（由指针分析和 数据流图填充）：

- 数据流节点数组（g_df_nodes）：数据流图指令。
- 数据流节点计数（g_df_node_count）：数据流节点总数。
- 数据流节点所属 region（g_df_node_region）：每个数据流节点归属的子图序号（由 数据流图：创建节点（df_create_node） 写入的 常时（1）显式映射）。
- 指针集数组（g_pts）：每个变量的指针集位图。
- 分配序号到节点映射（g_pa_alloc_nodes）：指针集位号（= 全局分配序号）到数据流节点序号的映射。
- 结构图数组（g_sgs）：区域结构图，含 类别（OFF_SG_KIND）、节点起始（OFF_SG_NSTART）、节点计数（OFF_SG_NCOUNT）、出口节点序号（OFF_SG_EXIT）、父区域（OFF_SG_PARENT）等字段。
- 结构图计数（g_sg_count）：结构图总数。
- IR 变量表（g_ir_vars）：取变量的类型序号（判指针类型门）。
- IR 函数个数（g_ir_func_count）、数据流图各函数节点起始索引（g_df_func_node_start）、数据流图各函数节点计数（g_df_func_node_count）。

领域专名保留：数据流节点条目大小（ESZ_DFNODE）、操作码字段偏移（OFF_DF_OPCODE）/ 目标字段偏移（OFF_DF_DEST）/ 操作数1字段偏移（OFF_DF_S1）/ 操作数2字段偏移（OFF_DF_S2）、不安全区域（SG_UNSAFE）/ 函数区域（SG_FUNC）/ 循环区域（SG_LOOP）/ 遍历区域（SG_FOR）、类别字段偏移（OFF_SG_KIND）/ 节点起始字段偏移（OFF_SG_NSTART）/ 节点计数字段偏移（OFF_SG_NCOUNT）/ 出口字段偏移（OFF_SG_EXIT）/ 父区域字段偏移（OFF_SG_PARENT）、解引用（IR_DEREF）/ 返回（IR_RETURN）/ 指针存储（IR_STORE_PTR）/ 存储（IR_STORE）/ 汇合（IR_PHI）、指针类型（TYP_PTR）、生命周期错误（EC_B_LIFETIME）/ 逃逸错误（EC_B_ESCAPE）、读 64 位（r64）、检查错误（check_error）、新 IR 变量类型（irv_type）/ 取类型类别（get_type_kind）。

## 函数 包含节点的子图（subgraph_containing）

### 作用
通过 常时（1）显式映射（g_df_node_region）查询给定数据流节点序号所属的子图序号。若节点序号无效则返回 -1。

### 逻辑

    函数 包含节点的子图（节点序号 node_seq：整数）-> 整数：
        // 显式映射：常时（1）归属查询（数据流节点所属 region 由 数据流图：创建节点（df_create_node） 写入）
        如果 节点序号 大于等于 0 且 节点序号 小于 数据流节点计数，那么：
            返回 读 64 位（r64）（源 = 数据流节点所属 region，偏移 = 节点序号 * 8）
        返回 -1

### 测试要点
1. 有效节点序号：返回其所属子图序号。
2. 节点序号为负：返回 -1。
3. 节点序号超出范围：返回 -1。
4. 节点未分配子图时 数据流节点所属 region 存储的值决定返回结果。

## 函数 判断 不安全块内（is_in_unsafe）

### 作用
判断给定数据流节点是否位于 不安全区域（SG_UNSAFE）内。不安全块内的节点跳过区域检查。

### 逻辑

    函数 判断 不安全块内（节点序号 node_seq：整数）-> 整数：
        令 结构图索引（si） = 0（可变）
        循环：
            如果 结构图索引 大于等于 结构图计数，那么：
                跳出循环
            令 结构图类别（kind） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 类别字段偏移）
            如果 结构图类别 等于 不安全区域（SG_UNSAFE），那么：
                令 结构图节点起始（nstart） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 节点起始字段偏移）
                令 结构图节点计数（ncount） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图索引 * 结构图条目大小 + 节点计数字段偏移）
                如果 节点序号 大于等于 结构图节点起始 且 节点序号 小于 结构图节点起始 + 结构图节点计数，那么：
                    返回 1
            令 结构图索引 = 结构图索引 + 1
        返回 0

### 测试要点
1. 不安全区域内返回 1；否则返回 0。
2. 与 指针分析：判断 不安全块内（pa_in_unsafe） 逻辑相同。

## 函数 区域是否归还内存（rc_sg_releases）

### 作用
判断给定区域是否在**出口归还内存**。只有出口发射 区域重置（IR_ARENA_RESET）的区域才算归还点：循环区域（SG_LOOP）/ 遍历区域（SG_FOR）/ 不安全区域（SG_UNSAFE）——它们各自在入口建区域（arena）、在出口重置（后端真调 建区域（arena_new）/ 重置区域（arena_reset））。如果（if）区只做区域入栈/出栈、不建区域；函数区域（SG_FUNC）的区域在函数出口才重置（返回给调用者仍有效）⇒ 两者都不是归还点。这是「使用点已死」判定的必要前提（修订②）。

### 逻辑

    函数 区域是否归还内存（结构图序号 sg：整数）-> 整数：
        如果 结构图序号 小于 0，那么：
            返回 0
        令 区域类别（k） = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图序号 * 结构图条目大小 + 类别字段偏移）
        如果 区域类别 等于 循环区域（SG_LOOP） 或 区域类别 等于 遍历区域（SG_FOR） 或 区域类别 等于 不安全区域（SG_UNSAFE），那么：
            返回 1
        返回 0

### 测试要点
1. 循环/遍历/不安全区：返回 1。
2. 函数区、如果区：返回 0。
3. 序号为负：返回 0。

## 函数 归还区域（rc_releasing_region）

### 作用
把分配点映射到**最近一个「出口归还内存」的区域**（含分配点自身所在区域）。沿 父区域字段偏移（OFF_SG_PARENT）向上溯源——分配在 如果（if） 内、循环内的情形，归还它的是外层的循环区，不是 如果区。返回 -1 表示没有这样的祖先（函数级分配等）⇒ 该分配在函数内不会死，不构成逃逸。

### 逻辑

    函数 归还区域（分配 AST 节点 alloc_node：整数）-> 整数：
        令 结构图序号（sg） = 包含节点的子图（subgraph_containing）（分配 AST 节点）（可变）
        循环：
            如果 结构图序号 小于 0，那么：
                返回 -1
            如果 区域是否归还内存（rc_sg_releases）（结构图序号） 不等于 0，那么：
                返回 结构图序号
            令 结构图序号 = 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图序号 * 结构图条目大小 + 父区域字段偏移）

### 测试要点
1. 分配在循环体内：返回该循环区。
2. 分配在循环内的 如果 分支里：返回外层循环区（不是 如果区）。
3. 分配在函数体（不在任何子区）：溯源到函数区 ⇒ 返回 -1。
4. 父链严格递减，循环终止。

## 函数 分配位释放点（rc_bit_exit）

### 作用
取指针集位图中第 位序号（bi） 位对应分配的释放点（= 其归还区域的出口节点序号）。返回 -1 表示该分配不被任何区域归还（含区域未关闭 = 仍存活）。

### 逻辑

    函数 分配位释放点（位序号 bi：整数）-> 整数：
        令 分配 AST 节点（alloc_node） = 读 64 位（r64）（源 = 分配序号到节点映射，偏移 = 位序号 * 8）
        令 结构图序号（sg） = 归还区域（rc_releasing_region）（分配 AST 节点）
        如果 结构图序号 小于 0，那么：
            返回 -1
        返回 读 64 位（r64）（源 = 结构图数组，偏移 = 结构图序号 * 结构图条目大小 + 出口字段偏移）

### 测试要点
1. 函数级分配：归还区域为 -1 ⇒ 返回 -1。
2. 循环内分配：返回该循环区的出口序号。
3. 区域未关闭（出口为负）：返回负值，由调用方按「未死」处理。

## 函数 分配位已死（rc_bit_dead）

### 作用
判断单个分配位在节点 当前节点序号（ni） 是否已死。区间是**半开** [节点起始, 出口)，出口 = 区域关闭后第一个节点的下标 ⇒ 「使用点在区域外」用 `大于等于`（修订①；原写 `大于` 漏掉紧邻格）。

### 逻辑

    函数 分配位已死（位序号 bi：整数，当前节点序号 ni：整数）-> 整数：
        令 释放点（ex） = 分配位释放点（rc_bit_exit）（位序号）
        如果 释放点 小于 0，那么：
            返回 0
        如果 当前节点序号 小于 释放点，那么：
            返回 0
        返回 1

### 测试要点
1. 使用点恰为出口序号（紧跟区域的第一句）：返回 1（修订①的核心格）。
2. 使用点在出口之后：返回 1。
3. 使用点在出口之前（区内）：返回 0。
4. 释放点无效（-1）：返回 0。

## 函数 点集有已死分配（rc_pts_dead）

### 作用
纯判定（不含重赋值清除规则）：指针集位图中是否存在任一分配在 当前节点序号（ni） 已死。

### 逻辑

    函数 点集有已死分配（指针集位图 pts：整数，当前节点序号 ni：整数）-> 整数：
        令 位掩码（mask） = 1（可变）
        令 位序号（bi） = 0（可变）
        循环：
            如果 位序号 大于等于 64，那么：
                跳出循环
            如果 （指针集位图 / 位掩码） % 2 等于 1，那么：
                如果 分配位已死（rc_bit_dead）（位序号，当前节点序号） 不等于 0，那么：
                    返回 1
            令 位掩码 = 位掩码 * 2
            令 位序号 = 位序号 + 1
        返回 0

### 测试要点
1. 位图为 0：不进入判断，返回 0。
2. 任一位的分配已死：返回 1。
3. 所有位都还活着：返回 0。

## 函数 重赋值清除（rc_reassign_clears）

### 作用
指针集是**流不敏感并集**——区间 [区间起点, 区间终点) 内一旦对该变量重赋值，并集就不再描述它此刻持有什么；拿失效的并集当事实用会误报（实测：循环里取 引用（REF）&数组[0]、循环后 `指针 = &种子` 再解引用被误报，而运行期合法）。判据：该区间内对 指针变量（ptr_var） 的写，只要每处写入的值都「明确不逃逸」（指针集为空 = 无受跟踪堆分配，或其指针集中的分配都还活着），且至少有一处这样的写 ⇒ 清除。任一写可能逃逸、或值未知（操作数2 为负）⇒ 不清除，保守照报。
> 已知不完整（登记）：值为跨调用结果时指针集为空（指针分析的调用分支不做摘要传播）⇒ 会被当作「明确不逃逸」而清除，该类真阳性转漏检——根因是指针集流不敏感，非本次修订引入。

### 逻辑

    函数 重赋值清除（指针变量 ptr_var：整数，区间起点 lo：整数，区间终点 hi：整数）-> 整数：
        令 见过安全写（saw_safe） = 0（可变）
        令 区间游标（i） = 区间起点（可变）
        循环：
            如果 区间游标 大于等于 区间终点，那么：
                跳出循环
            令 操作码（op） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 区间游标 * 数据流节点条目大小 + 操作码字段偏移）
            令 目标变量（d） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 区间游标 * 数据流节点条目大小 + 目标字段偏移）
            令 操作数1（s1） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 区间游标 * 数据流节点条目大小 + 操作数1字段偏移）
            令 操作数2（s2） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 区间游标 * 数据流节点条目大小 + 操作数2字段偏移）
            如果 操作码 等于 存储（IR_STORE） 且 操作数1 等于 指针变量，那么：
                如果 操作数2 小于 0，那么：
                    返回 0
                如果 点集有已死分配（rc_pts_dead）（读 64 位（r64）（源 = 指针集数组，偏移 = 操作数2 * 8），区间游标） 不等于 0，那么：
                    返回 0
                令 见过安全写 = 1
            如果 操作码 等于 汇合（IR_PHI） 且 目标变量 等于 指针变量，那么：
                如果 操作数1 小于 0 或 操作数2 小于 0，那么：
                    返回 0
                如果 点集有已死分配（rc_pts_dead）（读 64 位（r64）（源 = 指针集数组，偏移 = 操作数1 * 8），区间游标） 不等于 0，那么：
                    返回 0
                如果 点集有已死分配（rc_pts_dead）（读 64 位（r64）（源 = 指针集数组，偏移 = 操作数2 * 8），区间游标） 不等于 0，那么：
                    返回 0
                令 见过安全写 = 1
            令 区间游标 = 区间游标 + 1
        返回 见过安全写

### 测试要点
1. 区间内无写：返回 0（不清除）。
2. 区间内写入了明确不逃逸的值：返回 1（清除）。
3. 区间内写入的值本身含已死分配：返回 0（不清除，仍报）。
4. 写入值未知（操作数2 为负）：返回 0。
5. 汇合（IR_PHI）写同一变量：两源都安全才算安全写。

## 函数 变量持已死指针（rc_var_dead）

### 作用
变量级判定：判断 指针变量（ptr_var） 在节点 当前节点序号（ni） 是否持有已死指针。类型门：只对指针类型值执行（解引用读出的整数是普通数据，不是又一个指针）。逐位取释放点，命中「已死」后经 重赋值清除 决定是否真的报。

### 逻辑

    函数 变量持已死指针（指针变量 ptr_var：整数，当前节点序号 ni：整数）-> 整数：
        如果 指针变量 小于 0，那么：
            返回 0
        令 类型序号（ti） = 新 IR 变量类型（irv_type）（指针变量）
        如果 类型序号 小于 0 或 取类型类别（get_type_kind）（类型序号） 不等于 指针类型（TYP_PTR），那么：
            返回 0
        令 指针集位图（pts） = 读 64 位（r64）（源 = 指针集数组，偏移 = 指针变量 * 8）
        如果 指针集位图 等于 0，那么：
            返回 0
        令 位掩码（mask） = 1（可变）
        令 位序号（bi） = 0（可变）
        循环：
            如果 位序号 大于等于 64，那么：
                跳出循环
            如果 （指针集位图 / 位掩码） % 2 等于 1，那么：
                令 释放点（ex） = 分配位释放点（rc_bit_exit）（位序号）
                如果 释放点 大于等于 0 且 当前节点序号 大于等于 释放点，那么：
                    如果 重赋值清除（rc_reassign_clears）（指针变量，释放点，当前节点序号） 等于 0，那么：
                        返回 1
            令 位掩码 = 位掩码 * 2
            令 位序号 = 位序号 + 1
        返回 0

### 测试要点
1. 变量非指针类型：返回 0（解引用读出的整数不参与判定）。
2. 指针集为空：返回 0。
3. 有已死分配且区间内无安全重赋值：返回 1。
4. 有已死分配但区间内重赋值给活指针：返回 0。
5. 每个已死分配位各按自己的释放点取清除区间。

## 函数 区域检查：返回逃逸（rc_return_escape）

### 作用
希伯特风格（Siebert）检查：返回的指针是否指向已退出的子图分配。错误码 = 逃逸错误（EC_B_ESCAPE）（错误码参考中「函数内局部引用的引用逃逸出函数」一条，例子即 `返回 &局部`）；修订前误用 生命周期错误（EC_B_LIFETIME），属码位错配。函数级（函数区域）分配由 归还区域 自然放行——不再需要「等于函数区域则跳过」的特例。

### 逻辑

    函数 区域检查：返回逃逸（当前节点序号 ni：整数，返回变量 s1：整数）：
        如果 变量持已死指针（rc_var_dead）（返回变量，当前节点序号） 不等于 0，那么：
            检查错误（check_error）（错误码：逃逸错误（EC_B_ESCAPE），
                消息 = "region escape: returning pointer to exited subgraph allocation",
                行号 = 0，列号 = 0）

### 测试要点
1. 返回函数级分配的指针：不报（归还区域为 -1）。
2. 返回循环体内分配的指针（循环已退出）：报 逃逸错误。
3. 返回未退出区域内的分配：不报。
4. 返回非指针值：不报。

## 函数 区域检查：存储逃逸（rc_store_escape）

### 作用
希伯特风格（Siebert）检查：`*指针 = 值` 中存入的指针若指向已死分配，则写出的引用悬垂。修订前本函数体的判定值被整行丢弃（调用 区域检查：点集是否逃逸 独占一行、同行注「简化检查」），而该被调函数体内没有 检查错误 ⇒ 该检查**从不可触发**；本次接回 检查错误。
> 指针变量（存储目标）本版未用：注释所述的双边生存期比较（值的分配寿命 ≥ 目标的寿命）需要目标侧区域比较，属未实现设计，另行登记，勿当作已实现。

### 逻辑

    函数 区域检查：存储逃逸（当前节点序号 ni：整数，指针变量 ptr_var：整数，值变量 val_var：整数）：
        // 希伯特规则（Siebert）：检查存储指针是否产生悬垂引用
        如果 变量持已死指针（rc_var_dead）（值变量，当前节点序号） 不等于 0，那么：
            检查错误（check_error）（错误码：生命周期错误（EC_B_LIFETIME），
                消息 = "store escape: storing pointer to exited subgraph allocation",
                行号 = 0，列号 = 0）

### 测试要点
1. 存入的指针指向已退出子图的分配：报 生命周期错误（修订前此形态 rc=0 静默通过）。
2. 存入的指针仍活着（函数级分配等）：不报。
3. 值变量非指针类型或指针集为空：不报。

## 函数 区域检查函数（region_check_func）

### 作用
对单个函数执行区域检查。遍历所有数据流节点：
1. 对 解引用（IR_DEREF）指令：经 变量持已死指针 判定，命中则报悬垂指针错误（生命周期错误）。
2. 对 返回（IR_RETURN）指令：调用 区域检查：返回逃逸。
3. 对 指针存储（IR_STORE_PTR）指令：调用 区域检查：存储逃逸。
不安全块内的所有指令跳过检查。

### 逻辑

    函数 区域检查函数（节点起始 nstart：整数，节点计数 ncount：整数）：
        令 当前节点序号（ni） = 节点起始（可变）
        循环：
            如果 当前节点序号 大于等于 节点起始 + 节点计数，那么：
                跳出循环
            令 操作码（op） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作码字段偏移）
            令 目标变量（d） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 目标字段偏移）
            令 操作数1（s1） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数1字段偏移）
            令 操作数2（s2） = 读 64 位（r64）（源 = 数据流节点数组，偏移 = 当前节点序号 * 数据流节点条目大小 + 操作数2字段偏移）

            // 不安全块内跳过所有检查
            如果 判断 不安全块内（is_in_unsafe）（当前节点序号） 不等于 0，那么：
                令 当前节点序号 = 当前节点序号 + 1
                继续下一次循环

            // ── 悬垂解引用检查 ──
            如果 操作码 等于 解引用（IR_DEREF） 且 目标变量 大于等于 0 且 操作数1 大于等于 0，那么：
                如果 变量持已死指针（rc_var_dead）（操作数1，当前节点序号） 不等于 0，那么：
                    检查错误（check_error）（错误码：生命周期错误（EC_B_LIFETIME），
                        消息 = "dangling pointer: allocation subgraph exited before deref",
                        行号 = 0，列号 = 0）

            // ── 希伯特规则（Siebert）：过程间返回逃逸检查 ──
            如果 操作码 等于 返回（IR_RETURN） 且 操作数1 大于等于 0，那么：
                区域检查：返回逃逸（rc_return_escape）（当前节点序号，操作数1）

            // ── 希伯特规则（Siebert）：过程间存储逃逸检查 ──
            如果 操作码 等于 指针存储（IR_STORE_PTR），那么：
                区域检查：存储逃逸（rc_store_escape）（当前节点序号，操作数1，操作数2）

            令 当前节点序号 = 当前节点序号 + 1

### 测试要点
1. 空函数（节点计数 = 0）：循环不执行。
2. 解引用指令的目标分配仍在活跃子图内：不报错。
3. 解引用指令的目标分配所在子图已退出：报 生命周期错误；**使用点紧跟区域关闭处（序号恰为出口）同样报**（修订①）。
4. 分配在 如果 分支、分支之后解引用：**不报**（如果区不归还内存；修订②）。
5. 循环后把指针重赋值给活对象再解引用：不报（重赋值清除）。
6. 返回指令的操作数为指针且指向已退出子图分配：报 逃逸错误。
7. 返回函数区域级别的分配：不报错（允许返回）。
8. 指针存储存入已死指针：报 生命周期错误；存入活指针：不报。
9. 不安全块内的所有指令均跳过检查。
10. 非 解引用/返回/指针存储 指令直接跳过（含 存储（IR_STORE）与 汇合（IR_PHI），它们只作为重赋值清除的输入被扫描）。

## 函数 区域检查全部（region_check_all）

### 作用
对所有 IR 函数逐一调用 区域检查函数（region_check_func）。

### 逻辑

    函数 区域检查全部：
        // 安全检查通行证 — 始终运行
        令 函数序号（fi） = 0（可变）
        循环：
            如果 函数序号 大于等于 IR 函数个数，那么：
                跳出循环
            令 节点起始（nstart） = 读 64 位（r64）（源 = 数据流图各函数节点起始索引，偏移 = 函数序号 * 8）
            令 节点计数（ncount） = 读 64 位（r64）（源 = 数据流图各函数节点计数，偏移 = 函数序号 * 8）
            区域检查函数（region_check_func）（节点起始，节点计数）
            令 函数序号 = 函数序号 + 1

### 测试要点
1. 无 IR 函数时循环不执行。
2. 每个函数独立执行区域检查。
3. 始终运行（不检查优化级别等标志）。
