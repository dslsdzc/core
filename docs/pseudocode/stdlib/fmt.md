## 函数 字符串长度（str_len）

### 作用

读取 Core 字符串的头部信息获取字符串实际长度。字符串布局：偏移 -8 处存储分配的总字节数（含空终止符），实际长度等于总字节数减 1。

### 逻辑

令 头部信息（hdr）= 加载 64 位（源字符串（s），-8）  // 偏移 -8 处为字符串头：分配的总字节数（含空字节终止符）
如果 头部信息 小于等于 0，那么：返回 0
返回 头部信息 减 1  // 排除空终止符

### 测试要点

1. 空字符串返回 0（头部信息等于 1，减 1 等于 0）
2. 非空字符串返回正确长度（头部信息减 1 的结果）
3. 源字符串为无效指针时行为未定义（编译器假定合法）

## 函数 字符构造（chr）

### 作用

将一个整数字符码转换为单字符字符串。分配 2 字节（字符加空终止符）。

### 逻辑

令 结果字符串（res）= 分配（2）
写单字节（store8）（结果字符串，0，字符码）
写单字节（结果字符串，1，0）  // 空终止符
返回 结果字符串

### 测试要点

1. 字符码等于 65（大写字母 左操作数（A） 的编码）时返回 2 字节字符串（字符加空终止符）
2. 字符码等于 0 时返回仅含空终止符的 2 字节字符串

## 函数 取字符串第 序号（N） 字符（get_char）
签名：`函数 取字符串第 序号（N） 字符（get_char）（字符串（s）：字符串，字符索引（idx）：整数）-> 字符串`
### 作用

获取字符串中第 字符索引（idx） 位置的字符，返回单字符字符串。字符索引超出范围时返回空字符串。

### 逻辑

令 源码字符串长度（sl）= 字符串长度（s）
如果 字符索引（idx）小于 0 或 字符索引 大于等于 源码字符串长度，那么：返回 ""
令 当前字符（c）= 按字节读取（源字符串，字符索引）
令 结果字符串（res）= 分配（2）
写单字节（结果字符串，0，当前字符）
写单字节（结果字符串，1，0）
返回 结果字符串

### 测试要点

1. 字符索引等于 0 时获取首字符
2. 字符索引超出范围时返回空字符串
3. 字符索引为负数时返回空字符串
4. 空字符串上的任何索引返回空字符串

## 函数 字符串切片（str_sub）

### 作用

从源字符串中提取 起始位置（start） 到 起始位置 加 请求长度（len） 范围的子串。范围超出字符串末尾时自动截断到末尾。

### 逻辑

令 源码字符串长度（slen）= 字符串长度（s）
如果 起始位置（start）小于 0 或 起始位置 大于等于 源码字符串长度，那么：返回 ""
令 实际切片长度（actual_len），可变（mut） = 请求长度（len）
如果 起始位置 加 实际切片长度 大于 源码字符串长度，那么：
    实际切片长度 = 源码字符串长度 减 起始位置  // 截断到字符串末尾
如果 实际切片长度 小于等于 0，那么：返回 ""
令 结果字符串（res）= 分配（实际切片长度 加 1）
令 循环索引（i），可变（mut） = 0
循环（当 循环索引 小于 实际切片长度 时）：
    令 当前字符（c）= 按字节读取（源字符串，起始位置 加 循环索引）
    写单字节（结果字符串，循环索引，当前字符）
    循环索引 = 循环索引 加 1
写单字节（结果字符串，实际切片长度，0）  // 空终止符
返回 结果字符串

### 测试要点

1. 正常范围返回子串
2. 起始位置加请求长度超出字符串末尾时自动截断到末尾
3. 请求长度小于等于 0 时返回空字符串
4. 起始位置超出范围时返回空字符串

## 函数 字符串相等比较（str_eq）

### 作用

逐字节比较两个字符串是否内容完全相同。长度不等直接返回假（0）；长度相等则逐字节比较，全部一致返回真（1）。

### 逻辑

令 长度 变量甲（la）= 字符串长度（字符串 变量甲（a））
令 长度 变量乙（lb）= 字符串长度（字符串 变量乙（b））
如果 长度 变量甲 不等于 长度 变量乙，那么：返回 0  // 假
令 循环索引（i），可变（mut） = 0
循环（当 循环索引 小于 长度 变量甲 时）：
    如果 按字节读取（字符串 变量甲，循环索引）不等于 按字节读取（字符串 变量乙，循环索引），那么：返回 0
    循环索引 = 循环索引 加 1
返回 1  // 真：所有字符匹配。注意：当长度 变量甲 等于 0 时循环不执行，直接执行到此返回 1

### 测试要点

1. 两个内容相同的字符串返回 1（真）
2. 长度不等的两个字符串返回 0（假）
3. 长度相等但内容不同时返回 0（假）
4. 两个空字符串返回 1（长度均为 0，循环不执行，到达返回 1 的语句）

## 函数 字符串比较（str_cmp）

### 作用

字典序逐字节比较两个字符串。以空终止符（字节值 0）为字符串结束标记。返回值：两个字符串相等时返回 0，第一个较短时返回 -1，第一个较长或首字符较大时返回 1。

### 逻辑

令 循环索引（i），可变（mut） = 0
循环：
    令 字符 变量甲（ca）= 按字节读取（字符串 变量甲，循环索引）
    令 字符 变量乙（cb）= 按字节读取（字符串 变量乙（b），循环索引）
    如果 字符 变量甲（a） 等于 0 且 字符 变量乙（b） 等于 0，那么：返回 0  // 同时到达末尾，两字符串相等
    如果 字符 变量甲（a） 等于 0，那么：返回 -1  // 字符串 变量甲 较短
    如果 字符 变量乙（b） 等于 0，那么：返回 1   // 字符串 变量乙 较短
    如果 字符 变量甲（a） 小于 字符 变量乙（b），那么：返回 -1
    如果 字符 变量甲（a） 大于 字符 变量乙（b），那么：返回 1
    循环索引 = 循环索引 加 1

### 测试要点

1. 相同字符串返回 0
2. 字典序中较小的字符串比较时返回 -1
3. 字典序中较大的字符串比较时返回 1
4. 较短字符串为较长字符串的前缀时，较短者先到达末尾并返回 -1
5. 空字符串与任何非空字符串比较，空字符串较小并返回 -1

## 函数 字符串拼接（concat）

### 作用

将两个字符串连接为一个新字符串。分配新内存，先拷贝第一个字符串再拷贝第二个字符串。

### 逻辑

令 第一个字符串（aa）= 字符串 变量甲（a）
令 第二个字符串（bb）= 字符串 变量乙（b）
令 拼接长度 变量甲（a）（lena）= 字符串长度（第一个字符串）
令 拼接长度 变量乙（b）（lenb）= 字符串长度（第二个字符串）
令 结果字符串（res）= 分配（拼接长度 变量甲（a） 加 拼接长度 变量乙（b） 加 1）
令 循环索引（i），可变（mut） = 0
循环（当 循环索引 小于 拼接长度 变量甲（a） 时）：
    令 当前字符（c）= 按字节读取（第一个字符串，循环索引）
    写单字节（结果字符串，循环索引，当前字符）
    循环索引 = 循环索引 加 1
令 第二循环索引（j），可变（mut） = 0
循环（当 第二循环索引 小于 拼接长度 变量乙（b） 时）：
    令 当前字符（c）= 按字节读取（第二个字符串，第二循环索引）
    写单字节（结果字符串，拼接长度 变量甲（a） 加 第二循环索引，当前字符）
    第二循环索引 = 第二循环索引 加 1
写单字节（结果字符串，拼接长度 变量甲（a） 加 拼接长度 变量乙（b），0）  // 空终止符
返回 结果字符串

### 测试要点

1. 两个非空字符串正常拼接
2. 一方为空字符串时返回另一方的副本
3. 两个空字符串拼接返回空字符串

## 函数 整数转字符串（int_str）

### 作用

将整数转换为十进制字符串表示。处理负号前缀和零值特例。负数先取绝对值、计算位数、生成数字串，然后在头部插入负号并整体右移数字位。

### 逻辑

如果 输入整数（n）等于 0，那么：返回 "0"  // 零值特例
令 绝对数值（val），可变（mut） = 输入整数
令 负数标记（neg），可变（mut） = 0
如果 绝对数值 小于 0，那么：
    令 负数标记 = 1
    令 绝对数值 = 负 绝对数值  // 取绝对值。注意：对于最小负数，取负可能溢出，此处依赖编译器行为
令 临时值（tmp），可变（mut） = 绝对数值
令 位数（ndigits），可变（mut） = 0
循环：
    位数 = 位数 加 1
    临时值 = 临时值 除以 10
    如果 临时值 等于 0，那么：跳出循环
令 额外字节（extra），可变（mut） = 负数标记  // 负数需要额外一个字节存放负号
令 缓冲区（buf）= 分配（位数 加 额外字节 加 1）  // 加 1 为空终止符
令 结束位置（end），可变（mut） = 位数
令 写入位置（pos），可变（mut） = 位数 减 1  // 从最低位开始写入
循环：
    令 余数（rem）= 绝对数值 取模 10
    写单字节（缓冲区，写入位置，余数 加 48）  // 数字转字符码：'0' 的码值为 48
    绝对数值 = 绝对数值 除以 10
    如果 写入位置 等于 0，那么：跳出循环
    写入位置 = 写入位置 减 1
如果 负数标记 等于 1，那么：
    // 将所有数字右移一位，在头部插入负号
    令 右移索引（k），可变（mut） = 位数
    循环（当 右移索引 不等于 0 时）：
        令 当前字节（ci）= 按字节读取（缓冲区，右移索引 减 1）
        写单字节（缓冲区，右移索引，当前字节）  // 将位置 右移索引（k）-1 的字符移到位置 右移索引
        右移索引 = 右移索引 减 1
    写单字节（缓冲区，0，45）  // 负号的码值为 45，放在最前面
    令 结束位置 = 结束位置 加 1  // 字符串多了一个字符
写单字节（缓冲区，结束位置，0）  // 空终止符
返回 缓冲区

### 测试要点

1. 输入整数等于 0 时返回字符串 "0"（零值特例）
2. 正数正确转换为不含符号的十进制字符串
3. 负数正确转换为带负号前缀的十进制字符串
4. 最大正数正确转换
5. 最小负数正确转换（取负操作时需注意溢出）

## 函数 字符串转整数（str_int）

### 作用

将十进制字符串解析为整数。支持负号前缀，遇到非数字字符时停止解析。

### 逻辑

令 源码字符串长度（slen）= 字符串长度（s）
如果 源码字符串长度 等于 0，那么：返回 0
令 循环索引（i），可变（mut） = 0
令 负数标记（neg），可变（mut） = 0
令 首字符（c0）= 按字节读取（源字符串，0）
如果 首字符 等于 45，那么：  // 负号的码值为 45
    令 负数标记 = 1
    令 循环索引 = 1  // 跳过负号
令 结果数值（res），可变（mut） = 0
循环（当 循环索引 小于 源码字符串长度 时）：
    令 当前字符（c）= 按字节读取（源字符串，循环索引）
    如果 当前字符 小于 48 或 当前字符 大于 57，那么：跳出循环  // 非数字字符，停止解析
    结果数值 = 结果数值 乘以 10 加（当前字符 减 48）
    循环索引 = 循环索引 加 1
如果 负数标记 等于 1，那么：返回 负 结果数值
返回 结果数值

### 测试要点

1. 纯数字字符串正确解析为对应整数
2. 带负号前缀的字符串正确解析为负数
3. 字符串 "0" 返回 0
4. 空字符串返回 0
5. 含非数字后缀的字符串在遇到首個非数字字符时停止解析
6. 仅有负号无后续数字时返回 0

## 函数 字符串格式化（format）

### 作用

简单的字符串插值：将格式串中的首个参数占位标记替换为第一个参数。占位标记由三个字节组成：左花括号（码值 123）、数字 0（码值 48）、右花括号（码值 125）。

### 逻辑

令 模板长度（fl）= 字符串长度（fmt_str）
令 参数零长度（a0l）= 字符串长度（a0）
令 输出缓冲区（out_buf）= 分配（模板长度 加 参数零长度 加 16）  // 预分配足够大
令 写位置（ri），可变（mut） = 0  // 输出缓冲区写入位置
令 读位置（fi），可变（mut） = 0  // 格式化模板读取位置
循环（当 读位置 小于 模板长度 时）：
    令 当前字符（c）= 按字节读取（格式化模板，读位置）
    如果 当前字符 等于 123 且 读位置 加 2 小于 模板长度 且 按字节读取（格式化模板，读位置 加 1）等于 48 且 按字节读取（格式化模板，读位置 加 2）等于 125，那么：
        // 遇到完整的占位标记序列（左花括号 数字0 右花括号）
        令 参数索引（ai），可变（mut） = 0
        循环（当 参数索引 小于 参数零长度 时）：
            写单字节（输出缓冲区，写位置，按字节读取（第一个参数，参数索引））
            写位置 = 写位置 加 1
            参数索引 = 参数索引 加 1
        读位置 = 读位置 加 3  // 跳过占位标记三个字节
    否则：
        写单字节（输出缓冲区，写位置，当前字符）
        写位置 = 写位置 加 1
        读位置 = 读位置 加 1
写单字节（输出缓冲区，写位置，0）  // 空终止符
返回 输出缓冲区

### 测试要点

1. 格式串含占位标记且参数为非空字符串时，占位标记被正确替换
2. 格式串不含占位标记时原样返回
3. 格式串含多个占位标记时全部替换为同一参数
4. 不完整的占位标记（如缺少闭合花括号）时原样输出

## 函数 字符串格式化（二元）（format2）

### 作用

二元格式化——当前仅回退到一元格式化。未来扩展支持两个占位标记。

### 逻辑

返回 字符串格式化（格式化模板（fmt_str），第一个参数（a0））  // 当前仅处理首个参数占位标记，第二个参数被忽略

### 测试要点

1. 当前行为与调用字符串格式化（格式化模板，第一个参数）完全一致，第二个参数被忽略

## 函数 整数格式化（format_int）

### 作用

将整数转换为字符串后进行格式化插值。

### 逻辑

返回 字符串格式化（格式化模板（fmt_str），整数转字符串（val））

### 测试要点

1. 整数值等于 42 时占位标记被替换为 "42"
2. 整数值等于 0 时占位标记被替换为 "0"
3. 整数值为负数时正确显示带负号的格式结果
