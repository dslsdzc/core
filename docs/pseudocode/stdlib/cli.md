## 函数 扩展 CLI 命令数组（grow_cli_cmds）

### 作用

按需扩展命令数组容量（每条 16 字节）。若当前容量已足够则直接返回。

### 逻辑

函数 扩展 CLI 命令数组（grow_cli_cmds）（所需条目数（needed）：整数）
    令 当前容量（cur_cap）= CLI 命令容量
    如果 所需条目数 小于 当前容量，那么：返回  // 容量足够
    令 新容量（nc）= 当前容量 乘以 2
    如果 新容量 小于 8，那么：令 新容量 = 8
    如果 新容量 小于 所需条目数，那么：令 新容量 = 所需条目数 加 8
    令 新缓冲区（nb）= 分配（alloc）（新容量 乘以 16）  // 每条命令 16 字节
    内部：动态拷贝（_dyncpy）（CLI 命令数组, 当前容量 乘以 16, 新缓冲区）
    令 CLI 命令数组 = 新缓冲区
    令 CLI 命令容量 = 新容量

### 测试要点

1. 初始容量 0 → 扩容到 8
2. 容量翻倍策略
3. 旧数据拷贝到新缓冲区

## 函数 内部：判断 CLI 标志（_cli_is_flag）

### 作用

判断一个参数字符串是否为标志（以 "-" 开头）。长度小于 2 的字符串视为非标志。

### 逻辑

函数 内部：判断 CLI 标志（_cli_is_flag）（参数字符串 arg：字符串）-> 整数
    令 字符串长度（slen）= 字符串长度（str_len）（参数字符串）
    如果 字符串长度 小于 2，那么：返回 0  // 假：太短不可能是标志
    令 首字符（c0）= 取字符串第 N 字符（get_char）（参数字符串, 0）
    如果 字符串相等比较（str_eq）（首字符, "-"）不等于 0，那么：返回 1  // 真：以 '-' 开头
    返回 0  // 假

### 测试要点

1. 输入以 "-" 开头的短标志名 → 返回 1（真）
2. 输入以 "--" 开头的长标志名 → 返回 1（真）
3. 输入不以 "-" 开头的普通参数（如子命令名）→ 返回 0（假）
4. 输入单字符 "-"（长度 小于 2）→ 返回 0
5. 输入空字符串（长度 小于 2）→ 返回 0

### 作用

去掉标志字符串前的破折号前缀：以 "--" 开头的去掉两个破折号变成纯名称，以 "-" 开头的去掉一个破折号变成纯名称。无破折号的字符串原样返回。

### 逻辑

函数 内部：剥离 CLI 破折号（_cli_strip_dashes）（参数字符串 arg：字符串）-> 字符串
    令 字符串长度（slen）= 字符串长度（str_len）（参数字符串）
    如果 字符串长度 等于 0，那么：返回 ""
    令 起始位置（start）= 0
    如果 字符串相等比较（str_eq）（取字符串第 N 字符（get_char）（参数字符串, 0）, "-"）不等于 0，那么：
        令 起始位置 = 1  // 跳过第一个 '-'
        如果 字符串长度 大于 1 且 字符串相等比较（str_eq）（取字符串第 N 字符（get_char）（参数字符串, 1）, "-"）不等于 0，那么：
            令 起始位置 = 2  // 跳过第二个 '-'（即 "--" 前缀）
    返回 字符串切片（str_sub）（参数字符串, 起始位置, 字符串长度 减 起始位置）

### 测试要点

1. 输入以 "--" 开头的长标志名 → 返回去掉前缀后的纯名称
2. 输入以 "-" 开头的短标志名 → 返回去掉前缀后的纯名称
3. 输入不以 "-" 开头的普通参数 → 原样返回（无变化）
4. 输入空字符串 → 返回空字符串
