# scheduler.cr 伪代码

> 源文件：src/stdlib/scheduler.cr（154 行）
> 功能概要：协作式纤程调度器，为并发原语（协程启动（go） 语句）提供调度支持。每个并发任务节点是一个拥有独立竞技场的纤程（Fiber）。调度器以轮转方式遍历可运行纤程，纤程协作出让，无抢占。

## 函数 调度创建（sched_create）

### 作用

旧式扩展调度表：为动态库扩展创建指定条目数的分发表，每条目 8 字节。分配并返回条目数乘以 8 字节的缓冲区。

### 逻辑

函数 调度创建（sched_create）（条目数（n）：整数）-> 字符串
    返回 分配（条目数 乘以 8）

### 测试要点

1. 条目数为 0 时返回空缓冲区
2. 条目数为 10 时返回 80 字节缓冲区

## 函数 调度设置（sched_set）

### 作用

将整数值以小端序逐字节写入分发表条目数组中指定条目索引对应的 8 字节条目位置。从最低字节开始写入。

### 逻辑

函数 调度设置（sched_set）（分发表条目（entries）：字符串，条目索引（idx）：整数，整数值（val）：整数）-> 无返回
    令 字节偏移（p）= 条目索引 乘以 8
    令 待写入值（v）= 整数值
    令 循环索引（i）= 0
    循环（当 循环索引 小于 8 时）：
        写单字节（分发表条目，字节偏移 加 循环索引，待写入值 取模 256）
        待写入值 = 待写入值 除以 256
        循环索引 = 循环索引 加 1

### 测试要点

1. 整数值为任意 64 位值时正确以小端序写入 8 个字节
2. 整数值为 0 时写入 8 个零字节
3. 条目索引在数组范围内时正确计算偏移

## 函数 调度获取（sched_get）

### 作用

以小端序从分发表条目数组中指定条目索引对应的 8 字节条目位置读取整数值。从高字节向低字节读取，遇到有符号字节时做符号扩展（若当前字节小于 0，则加上 256 转为无符号范围）。

### 逻辑

函数 调度获取（sched_get）（分发表条目（entries）：字符串，条目索引（idx）：整数）-> 整数
    令 字节偏移（p）= 条目索引 乘以 8
    令 结果值（r）= 0
    令 循环索引（i）= 7
    循环（当 循环索引 大于等于 0 时）：
        令 当前字节（b）= 按字节读取（分发表条目，字节偏移 加 循环索引）
        如果 当前字节 小于 0，那么：当前字节 = 当前字节 加 256
        结果值 = 结果值 乘以 256 加 当前字节
        循环索引 = 循环索引 减 1
    返回 结果值

### 测试要点

1. 正确以小端序读取 64 位整数
2. 遇到负数字节时做符号扩展后计算正确

## 函数 运行队列压入（runq_push）

### 作用

将纤程索引压入运行队列的环形缓冲区尾部。队列满时自动扩容为原容量的 2 倍，并将环形缓冲区展开为线性数组后重新建立环形结构。

### 逻辑

函数 运行队列压入（runq_push）（纤程索引（fi）：整数）-> 无返回
    如果 运行队列计数 大于等于 运行队列容量，那么：
        令 新容量（nc）= 运行队列容量 乘以 2
        令 新缓冲区（nb）= 分配（新容量 乘以 8）
        令 拷贝索引（ci）= 0
        令 环形位置（pos）= 运行队列头索引
        循环（当 拷贝索引 小于 运行队列计数 时）：
            写 64 位（新缓冲区，拷贝索引 乘以 8，读 64 位（运行队列数组，环形位置 乘以 8））
            环形位置 = （环形位置 加 1）取模 运行队列容量
            拷贝索引 = 拷贝索引 加 1
        令 运行队列数组 = 新缓冲区
        令 运行队列头索引 = 0
        令 运行队列尾索引 = 运行队列计数
        令 运行队列容量 = 新容量
    写 64 位（运行队列数组，运行队列尾索引 乘以 8，纤程索引）
    令 运行队列尾索引 = （运行队列尾索引 加 1）取模 运行队列容量
    令 运行队列计数 = 运行队列计数 加 1

### 测试要点

1. 正常压入时尾部索引前移，计数递增
2. 队列满时自动扩容为原容量的 2 倍，原有内容正确拷贝且保持顺序
3. 扩容后头部索引重置为 0，尾部索引设为扩容前计数

## 函数 运行队列弹出（runq_pop）

### 作用

从运行队列环形缓冲区头部弹出一个纤程索引。队列空时返回 -1。

### 逻辑

函数 运行队列弹出（runq_pop）-> 整数
    如果 运行队列计数 小于等于 0，那么：返回 -1
    令 纤程索引（fi）= 读 64 位（运行队列数组，运行队列头索引 乘以 8）
    令 运行队列头索引 = （运行队列头索引 加 1）取模 运行队列容量
    令 运行队列计数 = 运行队列计数 减 1
    返回 纤程索引

### 测试要点

1. 队列为空时返回 -1
2. 正常弹出时返回头部元素
3. 弹出后头部索引前移，计数递减

## 函数 纤程启动（fiber_spawn）

### 作用

启动一个新纤程：先扫描纤程表中是否有状态为空闲（值为 0）的槽位可复用，有则复用；若无空闲槽位且表已满则扩容为原容量的 2 倍，然后在表尾分配新槽位。设置纤程的函数索引、独立竞技场和可运行状态（值为 1），并将其压入运行队列。

### 逻辑

函数 纤程启动（fiber_spawn）（函数索引（fn_idx）：整数）-> 整数
    令 循环索引（i）= 0
    循环（当 循环索引 小于 纤程计数 时）：
        如果 读 64 位（纤程数组，循环索引 乘以 32 加 16）等于 空闲（0），那么：
            写 64 位（纤程数组，循环索引 乘以 32，函数索引）
            写 64 位（纤程数组，循环索引 乘以 32 加 8，新建竞技场（））
            写 64 位（纤程数组，循环索引 乘以 32 加 16，可运行（1））
            运行队列压入（循环索引）
            返回 循环索引
        循环索引 = 循环索引 加 1
    如果 纤程计数 大于等于 纤程容量，那么：
        令 新容量（nc）= 纤程容量 乘以 2
        令 新缓冲区（nb）= 分配（新容量 乘以 32）
        内部：动态拷贝（纤程数组，纤程容量 乘以 32，新缓冲区）
        令 纤程容量 = 新容量
        令 纤程数组 = 新缓冲区
    令 纤程索引（fi）= 纤程计数
    令 纤程计数 = 纤程计数 加 1
    令 槽位偏移量（off）= 纤程索引 乘以 32
    写 64 位（纤程数组，槽位偏移量，函数索引）
    写 64 位（纤程数组，槽位偏移量 加 8，新建竞技场（））
    写 64 位（纤程数组，槽位偏移量 加 16，可运行（1））
    写 64 位（纤程数组，槽位偏移量 加 24，0）
    运行队列压入（纤程索引）
    返回 纤程索引

### 测试要点

1. 扫描到空闲槽位时复用该槽位
2. 无空闲槽位且表已满时扩容为原容量的 2 倍
3. 无空闲槽位且表未满时在表尾分配新槽位
4. 新纤程的状态设为可运行（值为 1）
5. 新纤程启动后被压入运行队列
6. 每个纤程获得独立的竞技场

## 函数 纤程让出（fiber_yield）

### 作用

当前纤程协作让出处理器：若当前纤程处于可运行状态（值为 1），则将其重新压入运行队列等待下次调度。等待中或已完成的纤程不重新入队。

### 逻辑

函数 纤程让出（fiber_yield）-> 无返回
    如果 当前纤程 小于 0，那么：返回
    令 槽位偏移量（off）= 当前纤程 乘以 32
    如果 读 64 位（纤程数组，槽位偏移量 加 16）等于 可运行（1），那么：
        运行队列压入（当前纤程）

### 测试要点

1. 无当前纤程时直接返回
2. 可运行状态的纤程重新入队以供后续调度
3. 等待中（值为 2）或已完成（值为 3）的纤程不重新入队
4. 让出后处理器可能切换到其他纤程

## 函数 纤程等待（fiber_wait）

### 作用

将当前纤程标记为等待状态（值为 2），并在数据字段（偏移 24 字节处）记录等待目标。

### 逻辑

函数 纤程等待（fiber_wait）（等待目标（target）：整数）-> 无返回
    如果 当前纤程 小于 0，那么：返回
    令 槽位偏移量（off）= 当前纤程 乘以 32
    写 64 位（纤程数组，槽位偏移量 加 16，等待中（2））
    写 64 位（纤程数组，槽位偏移量 加 24，等待目标）

### 测试要点

1. 状态变更为等待中（值为 2）
2. 数据字段记录等待目标
3. 无当前纤程时直接返回
4. 等待中的纤程不会被调度器选取执行

## 函数 纤程唤醒（fiber_wake）

### 作用

将处于等待状态（值为 2）的指定纤程唤醒：状态改为可运行（值为 1），清零数据字段，压入运行队列。仅处理等待中的纤程，已可运行或已完成的纤程不做处理。

### 逻辑

函数 纤程唤醒（fiber_wake）（纤程索引（fi）：整数）-> 无返回
    如果 纤程索引 小于 0，那么：返回
    令 槽位偏移量（off）= 纤程索引 乘以 32
    如果 读 64 位（纤程数组，槽位偏移量 加 16）等于 等待中（2），那么：
        写 64 位（纤程数组，槽位偏移量 加 16，可运行（1））
        写 64 位（纤程数组，槽位偏移量 加 24，0）
        运行队列压入（纤程索引）

### 测试要点

1. 仅唤醒处于等待中状态的纤程
2. 已可运行的纤程不会重复入队
3. 唤醒后数据字段归零
4. 纤程索引为负数时直接返回

## 函数 纤程结束（fiber_done）

### 作用

标记纤程为已完成状态（值为 3），并重置其竞技场以回收内存（纤程栈等资源位于该竞技场中）。

### 逻辑

函数 纤程结束（fiber_done）（纤程索引（fi）：整数）-> 无返回
    如果 纤程索引 小于 0 或 纤程索引 大于等于 纤程计数，那么：返回
    令 槽位偏移量（off）= 纤程索引 乘以 32
    令 竞技场标识（ai）= 读 64 位（纤程数组，槽位偏移量 加 8）
    如果 竞技场标识 大于等于 0，那么：重置竞技场（竞技场标识）
    写 64 位（纤程数组，槽位偏移量 加 16，已完成（3））

### 测试要点

1. 竞技场被重置以回收纤程栈内存
2. 状态变更为已完成（值为 3）
3. 纤程索引超出范围时直接返回
4. 无竞技场（竞技场标识为 -1）时跳过重置步骤

## 函数 调度运行（sched_run）

### 作用

调度器主循环：不断从运行队列弹出可运行纤程并执行。当前为占位实现（解释器模式下纤程立即标记为完成），原生后端会通过分发表调用存储在纤程表中的实际函数指针。循环结束后将当前纤程重置为 -1。

### 逻辑

函数 调度运行（sched_run）-> 无返回
    循环：
        令 纤程索引（fi）= 运行队列弹出（）
        如果 纤程索引 小于 0，那么：跳出循环
        令 当前纤程 = 纤程索引
        令 槽位偏移量（off）= 纤程索引 乘以 32
        如果 读 64 位（纤程数组，槽位偏移量 加 16）不等于 可运行（1），那么：
            继续下一次循环
        纤程结束（纤程索引）
    令 当前纤程 = -1
