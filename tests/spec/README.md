# 规约语法判据语料（批 6：正式规约语法 `#check` / `#ensure`）

**性质**：**是**编译单元（由 `tests/selfhost/test_spec_grammar.py` 逐档驱动：`build --static`，
负例断言 rc=1 + 诊断码 + **零产物**）。**不进**腿①（`tools/baseline/parity_run.sh`，74→75 档）与
腿②（`tests/probes/`，29 档）两套语料——那两套是**既有行为回归网**，其**计数不变**本身就是
「本批对旧面零扰动」的最强证据（维护者 2026-09-17 确认）。

**★ 命名法**：`t2_*` = 语法面（T2）· `t3_*` = 检查面（T3）· `t4_*` = dump 通道（T4）·
`delta_*` = `.ccr` 零足迹对拍对（`_plain` / `_annot` **成对使用**，见下）。
正控 = 期望 rc=0 + 有产物；负控 = 期望 rc=1 + **零产物**。

## `delta_*` 对的用法（判据 D，**不可拆**）

`delta_d9_plain.cr` / `delta_d9_annot.cr`（及 `d0` 对）是**同一程序 ± 注解**的最小对拍对，
用于 `.ccr` 零足迹的**三段式**判据：

1. **ELF 逐字节同**（±注解）；
2. **`.ccr` 除 STR 外 7 段逐字节同**；
3. **STR Δ 恰为公式值**：`Δ = Σ(4 + len(m))`，`m` 遍历**注解独有词素**（否则不被驻留的标识符/关键字）。

**机制（勿删）**：`src/compiler/lexer.cr` 的 `add_tok_str` 对**每个** IDENT/关键字词素都调
`str_intern` —— **既有行为、非本批引入**。⇒ 「±注解逐字节全同」**不可构造**（注解里的新词素
必然进 STR）；最强可构造形就是上面三段式。**多一字节即红**。
`d0` 是**零 Δ 用例**（注解词素已在程序别处驻留 ⇒ Δ 必须 = 0），它保证判据不倒过来逼出非零 Δ。

## 增删纪律

- 正控只增不减；负控若因**能力变更**转正（如未来支持注解内调用 ⇒ `t3_neg_call_banned.cr`），
  须在套件里**登记死亡证据**并把用例移入正控，不得直接删除。
- 新增语料须同步 `tests/selfhost/test_spec_grammar.py` 的对应组与计数注。
